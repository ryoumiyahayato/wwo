### 当前选择的技术理由

以独立主体为财产和决策单元，可以解释谁缺钱、谁缺料、谁知情、谁承担在途责任，且复用已经运行的Formal机制。城市负责组织查询和联系，而不是先收走所有企业库存；这适合当前要验证真实劳动、交付与上下游反馈的目标。城市目录分组还允许同城供应者共用一次通路查询，不抹平每家报价、受众与库存。

相对全对全企业连接或预建每主体/商品的全世界路径矩阵，稀疏图和有限候选节省预加载与失效成本；代价是查询、缓存失效与大图上限，且只保留快/便宜两类候选会漏掉某些折中路线。相对纯聚合月度市场，当前链路保留了合同、产权、工时和缺货原因，但日界规划/采购与历史增长更贵，不能未经测量直接扩到全球。

这些理由不表示原城市/腹地方案应被淘汰。较大范围可以保留城市/区域目录、采用层级路径或多精度调度；聚落腹地也可按真实可达性、运输成本和已知关系形成，而不一定是固定行政树。它们都是**待讨论方案**，尚未实现、未证明更优，不纳入本轮正式决定。

### 判断行为与算法预期

已知公告只增加候选，不保证立即成交；已知通路不保证当前空闲运力；有订单不保证准时到达；有现金不保证原料、劳动或设备齐全。因此主体缺货、亏损、不买、等待或拒单可能是正确约束结果，不自动属于算法失败。应回到实际报价、现金预留、批次、入段采用和交付收据判断。新增有限里昂Shared输入的两矿在36日确因tools0而等待维修；原legacy输入仍实际完成矿产→钢→工具→维护。分别验证两个完整输入，不放宽资金/容量或延长窗口来强求相同产出。

但机制自身违背时间或责任规则属于缺口。例如原历史directory恢复曾用当前Shared未来窗口拒绝过去合法知识；已沿原消息与路径修正Shared窗的as-of时点，并用窗内/窗后冷恢复、继续运行及当前拒单闭环，不应把这个缺陷解释成主体正常市场选择。普通自营投资的另一处信息丢失也已修正：最新询价不能抹掉同买方实际未履行SALE，fresh row只作本窗观察锚点，数量仍取原有资金承诺的pending/transit，不把未付款询价当收入。修复没有建立完整历史政策世界，非Shared管理上下文仍保持原约束。有限开发配置窗耗尽、部分线路未接Shared、未验球面GUI与帧率也必须明确列为限制，不用36日案例覆盖。

### 从可解释机制到可参与的决定

玩家需要从球形城市入口知道本人在哪里、有何权限、企业缺什么、下一步能付什么代价，而不是先读节点ID或全网统计。城市默认暴露原岗位/个人订单与已知报价入口；获权站点用原库存、已订未交、配方批次、已结算产出和资金责任回答处境，技术记录按需展开。城市没有因此成为钱包、库存或调度中心。

既有站点会自动补料，故“少点一次采购按钮”不是独立节约现金策略。当前可行对照复用真实经营动作：先暂停研磨需求，一种选择手动备粮并承担货款/运费预留与等待，另一种暂缓购买保留现金；真实到货后恢复活动，比较明确时点的实际产出。恢复会重新触发原自动补料，不能借此声称已实现独立人工/自动经营模式。尚未发运的采购可依原cancel申请撤销，释放对应预留；在途与已采用责任保留。便宜/快路线之外不虚构可替供应商。

原有普通人物也必须有实际知情入口。默认区域新开局增加的是两条已存在巴黎岗位的通知，不是空额或免费就业；本人仍须竞争原岗位、登记真实工时，由原雇主按合同付薪。受雇不授予企业私账或经营权。家庭公告只证明其可知身份，只有真实合同、交付与付款才证明交易；普通玩家不能凭公共城市标识观察他人私售。当前UI只展示本人/获权企业交易方范围内的真实结果，没有新增全市成交新闻层。

新增有界玩家用例已在原正式入口运行55/0：同快照先备6粮与暂不买，实际到货后同刻恢复，第5日A累计产4面粉、B为0；A货款6、运费6不是净利润。原真实铁路中断分支取消待发2、释放预留4，已采用4粮仍实到且无新采用。NPC家庭实际交10面粉、收30货款，16面包追溯其原料；本人登记144工时、雇主已实际付140，未把未到期工资或新通知当免费现金。这些是headless领域与离树导航结果，不是三段原GUI实机验收；图形守卫仍busy，未导出候选或promote。

## 1. 总体依赖

```text
住户需求与劳动力
  ↕ 工资、消费、迁移
企业生产与现金流 ↔ 区域市场 ↔ 交通与国际贸易
  ↕ 税收、合同、监管         ↕ 知识、设备、人才
国家财政与制度执行 ↔ 技术形成、扩散与采用
  ↕ 外交利益、动员、征用     ↕ 军工、补给、通信
外交危机 → 战争 → 占领/破坏 → 市场、住户、制度与技术反馈
```

市场、战争和技术不是独立小游戏。每项结果必须回到人物、住户、企业、组织和机构的真实资源与状态。

## 2. 区域市场

首版采用区域市场。每个市场区域按月结算：

```text
RegionalMarket
  market_id
  region_ids[]
  commodity_states[]
  labor_market_state
  transport_links[]
  import_orders[]
  export_orders[]
  price_history_summary
  disruption_records[]
```

基础商品类别：食品、衣物、住房、燃料、日用品、工具、机器设备、奢侈品。首版不继续拆成数十种微型商品。

每类商品保存生产、需求、库存、进口、出口、运输成本、成交量和价格。价格由供需缺口、可用库存、进口替代、运输和政策共同决定，并有数据驱动的单周期变化边界，避免瞬时爆炸。

## 3. 市场结算顺序

```text
企业提交产出与投入需求
→ 住户按实际生活水平提交消费需求
→ 政府与组织提交项目/军需需求
→ 现有库存与跨区运输形成可用供给
→ 按市场规则撮合聚合交易
→ 记录价格、成交、未满足需求和资金流
→ 企业利润、工资能力、住户满足度与税收更新
```

资金从买方账户流向卖方账户。进口和出口对应外国市场账户或贸易结算主体，不允许无来源生成财富。

## 4. 劳动市场与就业

区域劳动市场聚合职业、技能、工资、岗位和失业。企业根据产能、订单、工资成本与现金流创建或取消岗位；人物根据可达性、资格、工资、稳定性和住户需求求职。

就业合同是人物与企业间的正式连接。企业现金不足可能欠薪、减产、裁员、借款或破产；这些结果反馈到消费、压力、工会与政治。

## 6. 基础设施

铁路、港口、道路、河运和通信网络改变：

- 运输成本、容量与可靠性。
- 市场接入和企业利润。
- 通勤、旅行和迁移。
- 新闻与技术传播。
- 动员、军队移动和补给。

基础设施有位置、容量、维护、所有者/责任机构和损坏状态。没有下游效果的地图装饰不进入首版数据优先级。

## 7. 国际贸易

跨市场贸易读取价格差、运输成本、容量、关税、国境、战争、制裁和支付能力。首版使用聚合贸易订单，不逐商船模拟全部商品。

国际贸易同时传播企业关系、信息、人才和技术，并可能形成外交利益冲突。

## 8. 战争升级链

战争不能随机突然发生。正式状态链：

```text
利益冲突
→ 外交争端
→ 外交危机
→ 威胁、制裁、谈判或联盟活动
→ 军事准备
→ 动员
→ 宣战、退让或妥协
→ 战争
→ 停火/和谈
→ 和平条约与战后执行
```

冲突来源包括领土、市场、资源、债务、同盟、民族、殖民、政权安全和国内政治压力。每个阶段都提供人物、组织和国家在其权限内的反应机会。

## 11. 前线与作战

前线结果读取兵力、装备、训练、指挥、补给、基础设施、地形、士气、天气、战争支持、计划准备和多方向压力。任何一个攻击/防御总值都不能独立决定全部结果。

作战按战区周期和事件边界结算，不为每名普通士兵创建逐小时战术节点。控制变化产生原因记录并反馈人口、市场、机构和通信。

## 12. 不同身份的战争体验

- 平民：配给、物价、军需工作、征兵、伤亡消息、迁移和政治活动。
- 边境居民：撤离、财产损失、短缺、占领、合作或抵抗。
- 企业人物：合同、扩产、原料、运输、征用和战争利润/破产风险。
- 普通军人：训练、单位关系、调动、任务、伤病和晋升。
- 军官：按指挥层级获得计划、调动与补给请求权限。
- 政府人物：按职位参与动员、军费、战争目标、外交和和谈。

普通人物能观察战争并承受结果，但不能直接控制全国军队。

## 13. 技术三阶段

### 知识形成

大学、研究机构、企业实践、军队、发明者和外国知识产生研究积累。

### 知识扩散

## 14. 被动与定向研究

满足前置条件后，国内实践、外国扩散和科研积累会产生被动进度，避免关键技术被一次随机事件永久锁死。

定向研究需要现代科研机构、预算、管理制度和专业人才。投入有边际递减；职位人物只能为自己有权限的国家、企业、大学或军队选择方向。

技术可通过许可、购买、专家、留学、企业合作、战争缴获和间谍引进。特殊事件可加速或发现应用，但不能成为永久随机门槛。

## 15. 市场—战争—技术闭环

- 市场为军队提供税基、军费、装备、食品和运输。
- 战争破坏生产、运输和人口，改变价格、就业、债务和国家合法性。
- 技术提高生产、通信、医疗和军事能力，但需要市场设备与制度采用。
- 国家政策影响教育、研究、关税、动员和基础设施，但受财政与执行能力限制。
- 人物通过工作、企业、组织、职位和军事服务进入闭环，而非直接拥有系统。

## 17. 首版与保留接口

市场首版必须：8 类商品、区域价格/库存/运输、住户消费、企业现金流、就业和破产基础链。只保留全球金融、数十商品、逐运输工具和复杂汇率接口。

战争首版必须：升级链、和平/战争状态、动员、陆军战区/前线、补给、人物战争体验和权限。海军、空军、复杂外交条约和战术战斗先保留接口。

技术首版必须：因果前置、被动扩散、机构定向研究、组织/地区采用和引进。完整全球科技内容、专利市场和间谍科技网先保留接口。
