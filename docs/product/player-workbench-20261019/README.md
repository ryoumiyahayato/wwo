日期：2026-10-19。性质：产品建设清单与可操作的界面原型；不是新的游戏版本，不占用 R58 编号。

## 先看什么

- [主体缺口与实施顺序](FRAMEWORK_BACKLOG.md)：排除军事、经济、组织三大算法，列出可以继续推进的18项工作。
- [接下来三份正式游戏产物](NEXT_THREE_DELIVERIES.md)：把总清单收敛为人物首页、真实行动过程、五槽恢复与初次进入三批施工，附已有接口和本次核对依据。
- [UI接入说明](UI_INTEGRATION.md)：说明怎样复用现有 MainShell、PersonView、Presenter、旅行与存档入口。
- [人物手册交互原型](prototype.html)：今日处境、行程与安排、地点档案、消息与记录、显示与帮助。
- [新增：存档与恢复交互样例](save-recovery.html)：五槽选择、创建/最后保存/格式区别、未知创建版本、不支持格式、读取失败和候选恢复的成功/失败流程样例。

两份HTML均可保存到同一目录后在桌面浏览器打开，不需要安装依赖或联网。GitHub文件页展示源代码，不会直接运行HTML。全部样例ID使用 `demo:` 前缀；它们不是历史记录或正式世界对象。原型不包含旅行、金钱、时间推进或存档算法。

人物手册能进行页面切换、名称搜索、分类筛选、查看详情、临时收藏、已读切换、行程状态样例切换、字号和对比度调整。新增存档页显示的是手动推进的流程样例，不读取文件，不生成假进度，不承诺某个真实旧存档能被本版恢复。
