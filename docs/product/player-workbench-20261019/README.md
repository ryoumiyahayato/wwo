# WWO：地图之外的主体建设与人物手册

日期：2026-10-19。性质：产品建设清单与可操作的界面原型；不是新的游戏版本，不占用 R58 编号。

## 先看什么

- [主体缺口与实施顺序](FRAMEWORK_BACKLOG.md)：排除军事、经济、组织三大算法，列出可以继续推进的18项工作。
- [UI接入说明](UI_INTEGRATION.md)：说明怎样复用现有 MainShell、PersonView、Presenter、旅行与存档入口。
- [交互原型源文件](prototype.html)：单个HTML文件，保存到本地后用桌面浏览器打开，不需要安装依赖或联网。GitHub文件页展示源代码，不会直接运行HTML。

原型包含今日处境、行程与安排、地点档案、消息与记录、显示与帮助。能进行页面切换、名称搜索、分类筛选、查看详情、临时收藏、已读切换、行程状态样例切换、字号和对比度调整。所有样例ID使用 `demo:` 前缀；它们不是历史记录或正式世界对象。原型不包含旅行、金钱、时间推进或存档算法。

## 已经做过的原型检查

在本会话容器内使用Chromium与Playwright，将本HTML的内容载入浏览器，实际操作页面切换、搜索、过滤、收藏、详情与Esc关闭、消息已读、行程状态样例、字号和对比度。检查了1250×720、960×640、720×800与390×844视口的横向溢出，并查看了浏览器渲染结果。未发现这些操作中的JavaScript页面错误。

本环境限制 `file://` 导航，因此上述验证使用内存载入同一HTML；没有更改浏览器管理策略。原型没有外部资源请求。较小窗口使用滚动阅读，不以缩小全部字体强塞内容。

没有运行Godot游戏，没有导出EXE，没有访问用户存档，没有进行全仓回归或性能测试。浏览器原型可用不等于Godot接入已完成；也不证明R57地图、存档或玩法已经验收。
