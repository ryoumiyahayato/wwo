# Formal product legacy classification — Player Experience R2

This classification prevents repository age from being confused with runtime
authority. It is intentionally about the Formal product dependency graph, not a
claim that retained code is production-ready.

## ACTIVE_FORMAL

- `scenes/formal/` and `scripts/formal/`.
- The historical globe implementation inherited through
  `holographic_workspace_historical_admin_runtime.gd`, including the admitted
  source geometry, flag texture, projection, clipping, LOD, city marker and
  cache layers.
- The explicitly admitted historical economy evidence read by
  `formal_world_economic_evidence_catalog.gd`. These data files are inputs to
  Formal composition; Alpha runtime services are not.

## FIXTURE_ONLY

- Standalone holographic workspace scenes, captures and probes.
- V2.2/V2.3 review scenes and their isolated regression tests.
- Test organization and military fixtures.

These files must not be reachable from the Formal title, world scene or
application scripts.

## RETAINED_FOR_MIGRATION

- V2.2 employment and ledger implementations.
- Alpha enterprise implementation.
- V2.3 relationship, communication and travel implementations.
- VNext personal wallet and travel candidates.

Retention does not grant Formal ownership. Phase L's dependency test rejects
imports from the Formal product roots.

## DEAD_SUPERSEDED

The shared old shell's runtime character-switch action and personal unread /
mark-read presentation were removed. Formal PlayerState and organization/world
observation already replace those product semantics. Prototype character data
is now behind an explicit hook which the Formal application disables before
the source is opened.

The following product dependencies are forbidden:

- V2.2/V2.3 scenes or scripts;
- Alpha runtime scenes or scripts;
- `data/world_map/characters.json`;
- the old `world_map_canvas.gd` renderer;
- the standalone holographic spike scene.

Employment, wallet, wage, enterprise, relationships, communication and travel
remain unavailable in Formal until separate owner, composition, persistence and
command contracts are admitted.
