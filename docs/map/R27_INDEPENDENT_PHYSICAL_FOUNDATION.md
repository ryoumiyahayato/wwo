# WWO R27 — Independent Physical Geography Foundation

基线：本机R26。引擎：Godot 4.6.3 Compatibility。日期：2026-10-16。

本轮将有效物理底图从历史政治底网和补陆/裁水差集替换为独立 Natural Earth 陆地。政治几何保留历史身份查询和边界职责，政治颜色成为可选显示输入。没有新增第二地球、相机、全局视口或地图管理器。

未启动游戏。未做自动测试、回归、性能/内存采样、FPS基准、哈希核验、安全审计、CI或额外探针。没有Git操作。导出结果及资产字节数列在第9节，不代表画质或性能验收。

## 1. 原依赖的具体位置

| 阶段 | R26及以前的实际依赖 | R27处理 |
|---|---|---|
| 原始资料 | Natural Earth物理资料与CShapes历史政治资料原本独立 | 原件全部保留，不修改任何源顶点或历史身份 |
| 离线制作 | build_geographic_foundation.pack_physical 生成 P−C 补陆和带球面弦长补偿的 C−P 裁水；可使用政治显示footprint；旧资产还带9000米内借色索引 | 移除该生成分支，生成完整P及分片P补集。政治交集另存可选文件，不参与P的构成 |
| 加载 | StrategicSpatialLoader 读取差集；GeographyLoader读取CShapes，后者给基础填充 | 原GeographyLoader只保留历史输入。StrategicSpatialLoader读取独立物理资源；未请求墨层时不读取政治分区 |
| 三角化 | GlobeProjection准备C政治面；LocalSpatialLod安装预制差集，三者共同形成视觉陆地 | 物理全覆盖离线约束三角化；运行时只细分球面显示边。C面仅保留CPU历史查询 |
| 渲染 | GlobeRenderer提交不透明政治陆地，再叠物理补陆与裁水。背景DEM也可推断一层陆地 | 唯一物理填充 + 可选墨层；旧差集、政治基础GPU面和DEM海陆推断全部退出 |

R26删除借色不等于几何解耦。本轮替换的是陆地的形成路径。此前法国问题不应再解释成俄国或跨180°问题；R25的地点误判已由R26记录更正，本轮没有法国专用偏移、缓冲或海色遮挡补丁。

## 2. 唯一物理来源及格式

- 现有 `local-artifacts/paris-land-pilot-r1/research/ne_10m_land_v512.geojson`，10,157,965字节。
- 现有 `local-artifacts/global-strategic-r1/source/ne_10m_lakes.geojson`，5,043,554字节。仅沿用已采用的Syvash自然水域扣除，不增加水文身份。
- 固定Natural Earth v5.1.2来源目录，Public Domain。其1:10,000,000是概化比例尺，不是10米精度。实际物理子层版本依现有来源记录；不称1900年精确海岸。

先联合完整物理陆地并保留多组件、外环与内孔；在全球统一生成原有1500米粗档、300米中档显示LOD，保留拓扑。度坐标容差沿用原值 `tol/111195`，高纬实际地面距离较小，不提高简化容差。显示精度网格为1e−9度，不改变原始文件。

沿用24个90×30度粗分片及每片18个15×10度中分片，共456片。纯海洋片也有完整水域引用；不再因没有政治差集而缺少覆盖描述。分片是显示打包单元，不是国家、行政、经济或军事身份。

每片 `.json` 保留原来源／事实目录格式。`.geom` 为zlib压缩UTF-8 JSON，分别存：

- `land_reference`：`INDEPENDENT_PHYSICAL_LAND`，完整MultiPolygon与预制受约束三角形；岛屿、半岛、海湾、多组件和孔来自P。
- `ocean_reference`：`INDEPENDENT_PHYSICAL_WATER_MASK`，分片矩形减P的MultiPolygon，`REFERENCE_MASK_ONLY`；只供CPU水域判定和显示线裁切，没有海洋补丁GPU面。
- `coast`：同一个全球简化P的边界与分片相交。分片裁切边不作岸线；±180°、±90°的平面闭合边也不作真实岸线。保留原极地闭合过滤、经度展开与两扇面地平线裁切。

海洋视觉仍使用原半球海面和REGION背景。湖泊／内陆海继续使用已有独立水文来源和批次；没有把NE land宣称为完整全球湖泊调查，也没有补造河口宽度、历史水位或海湾细节。

## 3. 历史墨层：分区显示而非再次定义陆地

可选 `.ink.geom` 与物理来源分开记录。它读取原 `cshapes_1900_snapshot.json`、`arabia_gulf_geography_1900.json` 及既有阿拉伯政治显示掩码，求它们与已确定P的精确交集，剩余P标为未知。重叠部分使用固定显示优先次序，非新的主权裁决。

这是完整P的可选绘制分区。没有附近国家搜索、距离借色、政治面外扩或最近国家归属。无交集的物理陆地仍存在，只不着政治色。没有采用旧差集生成器的政治footprint输入。

运行时：未请求墨层时直接使用P的预制三角形；请求墨层时将本次加载对象的绘制三角形替换为完整分区，原P的MultiPolygon不变。不会将完整P面与完整C面同时绘制，也不会保留两套完整GPU填充。临时解码的未选三角形随加载局部引用退出。

国旗UV继续用原历史几何 `uv_bounds/flag_bounds`；已有地区显示框继续用 `region_frames`。不因现代物理海岸改变旗帜构图。材质的物理底色、relief、政治墨层和国旗在同一面Shader合成；地形和地态不写入政治身份。

`.ink.geom` 记录来源路径、角色 `DISPLAY_INTERSECTION_ONLY_NOT_SOVEREIGNTY` 和CC BY-NC-SA 4.0约束；NE物理贡献仍为Public Domain。该分区只是当前历史资料的显示衍生，不是新历史证据。未来政治几何来源发生有效修订，需要重制对应分区；普通日期或颜色变化不做布尔运算。

## 4. WORLD、REGION、LOCAL与资源交接

路径：`data/strategic/index.json → StrategicSpatialLoader → LocalSpatialLod.prepare → GlobeSurfaceBatch → LocalSpatialLayer`。WORLD远景准备24个粗档物理片；近景只准备视野相交的原有界粗/中档窗口。原逻辑会把极区经度包围框候选直接截成前64片，可能丢掉有效片；本轮改用现有需求球冠与经纬度矩形的最近距离筛选，不按数组次序截断。不是同时常驻全球所有分辨率。

同一批物理RID在WORLD与REGION之间换父canvas、投影参数和显示状态，保留原离场释放。后继LOD在后台读取／CPU准备，并按原上传预算安装。填充和同源海岸全部完成后才一起切换；CPU水域补集和覆盖范围也在该完成点发布。旧有效内容承担等待，完成后释放。

`GlobeRenderer._political_ink`、`RegionView.ink_styles` 只有CPU样式记录与共享历史查询几何。取消原完整政治GPU面、每国模板材质、重复REGION政治材质、相机对空样式的Shader提交和原政治面Shader预热绘制。实际物理分区按已有2048面批次上传；同源海岸沿用1024段合批、128段源块及闭合邻点。

LOCAL仍复用REGION底图和原有限三维目标；IGN、EA DTM、swissALTI3D、COP-DEM、ETOPO及已准入覆盖不变。没有新的阿尔卑斯材质改造、植被、古迹或水纹施工。

## 5. 边界、选择与事实不变

历史CShapes原面保留CPU查询几何，`GlobeSurfaceBatch.prepare_picking` 不上传整套GPU面。国家选择仍查询原PoliticalLayer显示身份；物理批次不以绘制先后夺取政治身份。真实地点、地标和原行政选择路径保留。

海洋空白点击先依据已完成物理覆盖及物理陆地面判定水域，再按原控制器取消选择。未知归属的物理陆地返回原地理参考资料卡，不给最近国家。未完成／未覆盖的片区不凭空宣称已知水域。

历史外缘不再作为物理海岸描边提交。历史国家边界仍独立保留。近景国家／行政线用已安装P的完整水域补集作显示裁切；水域外环和陆地内孔直接裁线：保留外环外的段及内孔内的段，不为裁线重新执行大面减孔和三角拆分。原国家线、原GIS顶点、行政拾取组件、成员和LandTopology完全不变。显示裁切不等于重画法理海疆。

现代物理岸线与1900范围不一致时：实际显示海陆用现代P，历史事实仍用原C/行政资料；海上的政治填色不提交，新增物理陆地无历史交集则中性。原历史范围不移动、不扩张，不自动分配新陆地。

## 6. 法国异常：本轮确认与未确认

确认的公共结构原因是：两来源轮廓通过P−C、C−P差集拼接，容易产生细长碎面；历史政治外缘又有独立描边候选；粗DEM背景可继续推断另一层海陆。有限球面弦与平面布尔边缘近似进一步增加显示接缝风险。没有证据把每个截图尖角归因于原历史GIS顶点。

本轮实际取消这些共同路径：完整C基础填充、差集补陆/裁水GPU面、政治外缘海岸批次、DEM海陆推断、旧差集球面弦补偿。新填充与海岸来自同一简化P；同一LOD完成点安装。适用于法国海峡、西部海湾、科西嘉及其他地区，没有位置专用规则。

保留：多孔、多岛组件、原球面细分、反经线展开、两个地平线扇面、源线闭合邻点、有效旧LOD到后继完成的规则。不可显示的退化浮点三角形仍按原规则不提交，没有随机删三角形掩盖异常。

这证明结构替换已实施，不能证明全部法国异常已消失。仍有现代/历史年代差异、1:1000万概化、不完整河口/湖岸、非线性投影的有限细分和不同来源行政显示精度。高精度地形垂直基准问题本轮未扩展处理。

## 7. 五类地图与时间推进

- 地理地形：直接使用独立P、物理水文和真实高程。
- 历史政治行政：P提供显示基底，原历史事实提供墨层、边界与身份。
- 产出：仍须经济线提供实际产出、单位、统计期和空间引用；当前fulfillment/shortage只是经济观察。
- 地态：独立surface_covers描述已有覆盖；不能从DEM、国家色或P推断森林、荒漠、草原和雪线。
- 军事：后续可读取同一物理空间；作战网格、单位、控制和行动由军事线负责。

没有五套物理地球或重复全球DEM。WORLD/REGION/LOCAL仍只是观察尺度。普通日期不改变物理请求键；静态物理参考不因战略历史包的一年窗口结束而退海。同期铁路／城镇和历史显示仍按各自日期判定，不将现代物理参考伪装成逐日历史事实。

TimeControl、GameClock、SimulationStep、FormalWorldApplication/Presenter及经济、人口、人物、组织和军事算法没有修改。4×合法结算全部保留。没有运行数据，不能归因或承诺风扇、缩放延迟、CPU/GPU/内存或FPS改善幅度。
