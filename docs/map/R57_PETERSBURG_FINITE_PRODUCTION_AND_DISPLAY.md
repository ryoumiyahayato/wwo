## 生产读取与真实来源

修改现有`tools/map/build_surface_r57.py`，复用原R57材质计算、Rasterio/GDAL和编码6写出。新增显式`FiniteInputs`：窗口记录提供方key/URL、产品、原生及提取格网、CRS、NoData、PixelIsPoint/Area、实际支持范围及方法。没有第二套GIS引擎、常驻下载器或运行管理器。

生产路径先调用`require_inputs`，再核对实际文件与声明的形状、CRS、NoData、仿射、产品及类别。ETOPO窗口保留EPSG:9518、60角秒、原始整数行列偏移和两个原像元邻边；不再要求假装存在完整全球文件。GLO保留Point格网及半像元偏移，仍按600²平均提取，约93m原生/185.325m提取分别记录。WorldCover保留Area、离散类别及0未知值；先最近邻取类别，再映射RGB并面积平均。

粗源先填充，局部细分类只覆盖其实际有效贡献；细窗外或细源未知部分续接真实粗源。225/450/2250采样由各自记录区分。本批保留两页原有23份450²、5份2250²来源，另取四核心的2250格网窗口，约148.26m。没有按类别编号进行平均或混用class10-only。

新增细源按源/目标仿射比例固定GDAL的XSCALE/YSCALE，消除默认分块比例随窗口变化造成的采样差。原页底稿沿用旧采样及地理单元处理顺序，保持兼容；原理见[GDAL重采样比例说明](https://gdal.org/en/stable/doxygen/structGDALWarpOptions.html)。

本轮恢复121个GLO对象所需输入，其中N59E030直接复用上轮原COG及提取，新下载120个。WorldCover只读取28个对象的必要COG范围，保留原版提取及16个细分类交叉窗；ETOPO只保留5个地理窗口。没有完整下载28份WorldCover或全球ETOPO。旧GLO原件的历史字节一致性仍未证明，没有计算哈希。

来源与窗口在`local-artifacts/terrain-r57/petersburg-2026-10-21/sources.json`。`first_target.json`、`batch_targets.json`是实际生产读取的描述，`recipe.json`接入既有增量入口。`precision.*_cells.bounds`表示该资产中的实际贡献范围；完整GeoTIFF格网、仿射及尺寸以来源记录为准，不能用裁剪后的贡献框反推采样精度。
