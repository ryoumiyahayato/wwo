# R55 — Map Coverage Integrity and Seamless Terrain Recovery

日期：2026-10-19。Godot 4.6.3 Compatibility。基线为本机R54。已修正三项BSAC显示记录的日期误挡、当前视野选片、LOD参数发布、细片边缘渐退及概览交接；补建欧洲俄罗斯区域地貌。没有运行游戏或取得R55性能测量。

## A. 政治对象：截图与确定原因

本轮收到的PNG为非洲南部政治图。浅色区域位于刚果以南、安哥拉以东；用户补充名称疑似罗得西亚、北罗得西亚。不是把所有浅色区域都判为国家丢失。

| 显示身份 | 源几何 | 原全球批次/三角面 | 1900年显示身份 | 错误与修改 |
|---|---|---:|---|---|
| `map_authority:gw_552` 罗得西亚 / BSAC | `gw_552` | 1 / 106 | 公司管理显示参考；非独立BSAC国家 | 原填色又检查CShapes的1900-01-29起始日期，1月1日权重归零。现用已有显示记录的有效期 |
| `map_authority:gw_5518` 东北罗得西亚 / BSAC | `gw_5518` | 1 / 71 | 公司管理显示参考 | 同上 |
| `map_authority:gw_5519` 西北罗得西亚 / BSAC | `gw_5519` | 1 / 100 | 公司管理、英国保护背景及地方权威并存 | 同上 |

这三项在`historical_authorities_1900.json`已有1900-01-01至1901-01-01的显示有效窗口、来源、公司管理性质和邻近日期几何说明。原`political_units_1900.json`的三个后期记录仍从1月29日起；没有修改该日期、建立新主权、写入军事控制或把公司管理升级为国家。

`HistoricalLoader.resolve_map()`在正式政治对象没有占用该几何时，附加这些已有非运行国家显示记录。`PoliticalLayer.refresh()`设置`display_only`。`HistoricalVisualResolver`已能解析`bsac_company_1893.svg`，资源存在。R37物理面中的引用也存在。真正的误挡发生在`GlobeRenderer._update_political_ink()`：它忽略显示记录有效期，又用`_source_validity[feature]`重设旗帜及政治填色权重。

现改为`PoliticalLayer.display_active()`：显式`display_only`记录使用自己的来源有效期；其余对象继续使用源几何时期。Renderer消费该结果。没有绕过全部日期过滤。拾取仍读取原几何和最终显示所有者；未改资料卡入口。

离线工具按现有日期和阿拉伯显示替换规则核对159个当前显示对象：全部有几何及全球填色批次；视觉解析无错误。日期误挡恰好为上述三项。欧洲、俄罗斯、奥匈、伊比利亚及其他非洲对象在此核对中没有发现同样的缺批次条件。该统计是源与编译包核对，不是159个对象的截图验收。

R54新增裁剪位于`_prepare_boundary_batches / _draw_boundaries`，仅处理宏观边界RID；没有直接删除政治填色。包围帽累积同组全部线点并加入边段角度余量，大于半球的帽不做屏外拒绝；不以单个组件替代整个多领地对象。填色批次仍使用原LocalSpatialLod/Layer的独立球帽与逐面地平线裁切。没有发现可解释本次罗得西亚浅色面的错误裁剪证据，因此保留该优化。

旗帜仍是原物理政治分区上的材质输入。UV不会扩大Mesh覆盖域。没有取消国旗、扩大旗帜支持域或借色填邻国。地理模式继续把政治及旗帜权重置零；切回政治模式使用原视觉来源。多领地组件UV、R37预制及正式主权不改。CShapes快照1900-03-12及局部邻近日期几何的不确定性保留；不是精确1月1日全球实测边界。

## B. 地貌格子与运行修复

本轮只收到上述政治截图，没有可精确配准的地貌断层截图。以下原因来自源码、实际纹理和指定窗口核对，没有倒填成截图某条像素边的实测定位。

| 确认的条件 | 文件/函数 | 处理 |
|---|---|---|
| R53共同概览外框虽到62°E，但Alpha只包含旧有地区支持域；莫斯科等地没有R49新地貌 | `arid_surface_r53.json`及`euro_afro_arabia_r53_base.bin` | 新共同概览在真实ETOPO覆盖内连续有效，保留旧R53已支持材质 |
| 2×2邻格围绕相机中心，不等于宽屏、旋转、高纬、平移后的屏幕 | `MapRelief._choose_surface()` | 读取实际RegionProjection的frame、origin、bearing、尺寸、比例及有限范围；9×9逆投影采样，保守边沿，另处理落入屏幕的极点 |
| 四张瓦片不能覆盖许多REGION宽视野 | 同上 | 按当前屏幕相交面积排序。四片覆盖比例不足时使用完整共同概览；接近预算边缘时连续降低细化权重。没有随机维持四块最高精度孤岛 |
| 旧Shader只对细片合并外矩形渐退，内部空位、非矩形集合和GLO/ETOPO交界无对应渐退 | `france_surface.gdshaderinc::surface_detail()` | 每片使用自己的core及四边权重；同采样间距的已安装邻片取消共同边渐退；不同精度的两侧均回到同一概览。曝光边0.35°平滑过渡 |
| 相同纹理ID下，mpp及细化预算权重可改变，但request未必要求重新绑定 | `MapRelief.request()` | mpp、细化权重和跨经度周转的参数变化也发布；不等待下一张图片或下一次滚轮 |
| 原概览需求更换后，旧概览可能在新图安装前退出 | `_refresh_surface_active / _retire_textures` | 相交的旧概览等待后继；目标安装后立即退休旧引用。当前两概览上限不变 |
| R50部分旧元数据把有地理渐退的细片标为支持度1 | R55制作脚本 | 复用前读取实际Alpha并按原编码解释。补足不完整支持域；已有完整旧核心直接引用 |

现有纹理仍通过`GeographyLoader.decode_relief → MapRelief单线程解码 → poll主线程ImageTexture → GlobeRenderer._bind_relief → 两个原Layer和RegionView`进入地图。旧编码0/1和新编码5继续分别解码；没有用阴影通道兼容性拒绝合法资料。R55编码5的RGB是固定地貌色与离线hillshade，A独立表示地理有效性，WorldCover分类不占用这个A。

新图保留源仿射配准、绝对高度解释、固定双方向公制坡面阴影及完整原生Mip。细片有实源邻边：GLO选窗32显示像素，普通片4个ETOPO像素。201份新资源的头部尺寸、完整Mip解压长度和清单文件长度均核对一致。未发现新图错误Mip长度或本轮Shader参数名错绑。没有重写原DEM、给整个地图加模糊、改变国家高度色阶或补随机噪声。

当前屏幕的底图完整性与最高精度分开：共同概览先覆盖当前画面，细片只增强有来源且预算适合的区域。首次进入前共同概览尚在读取时，原全球ETOPO/REGION参考继续显示；不保证首次远距离瞬移时高清已经安装。纹理完成仍由原`poll()`触发绑定和画面失效，站定后也会完成发布。

## C. 视野、邻域与持有上限

| 项目 | R55实际规则 |
|---|---|
| 概览 | 最多两份有效概览；单个解码任务。后继安装的瞬间可额外拥有一份待退休纹理 |
| 细片 | 仍最多四个常态持有槽，包含预读；不是四片另加无限邻域 |
| 屏幕优先 | 实际投影地理外框与有效源核心相交；先可见，再按屏幕相交面积/距离排序 |
| 宽视野 | 最佳四格占可用可见核心面积不足92%时仅概览；92%—99.9%平滑进入细化。保留原300—750米/像素渐退 |
| 邻域 | 可见需求用不完四槽时，最多两个空槽准备外侧约半个视野宽/高的有限带；优先复用已有邻格。没有额外永久GPU缓存 |
| 预读顺序 | world/region、合法native窗口、必要目录/概览、可见细片、空槽邻格。仍一次一个已有图像的读取及安装 |
| 退出 | 当前需求改变后丢弃过期结果，ImageTexture创建前检查需求；相交前驱仅等必要后继。离开REGION解绑细图，保留原全球资源 |
| 水文 | 原StrategicSpatialLoader的视野/LOD及显示所有权不改；没有新增水文预读缓存或全俄河网预安装 |

离线预生成仍做DEM重采样、阴影和Mip；运行时只读取已有原生资源；GPU预安装仍由原`poll()`创建纹理。没有运行时重做hillshade，没有第二个服务、第二套Shader或另一颗地球。

新共同概览3120×2280，完整RGBA8 Mip解码37,938,168字节；旧R53为32,830,188字节，增加5,107,980字节。单张1088²细片完整Mip为6,313,256字节。四个此类槽为25,253,024字节，替换瞬间至多一后继。这是图像数据预算，不是实测显存；原global/native纹理及材质对象成本另计。

原R54目录外层浅复制、行政窗口收缩/批量安装、图标身份复用、国旗纹理复用、LOCAL失败重试保护、控件父节点与RID修复均保留。没有重置相机、增加整屏ready门控或暂停半球仪。R39的24份全球coarse和455编译批次保持；REGION medium仍有自己的生命周期。

## D. 欧洲俄罗斯实际补建

R49报告明确为前置整改：概览0、细片0、水文0。R50西伯利亚及R52芬兰/高加索不能补记成R49欧洲俄罗斯已完成。

本轮生产地理范围18—70°E、40—82°N，外围有地理过渡。共同概览扩展至28°W—76°E、10—86°N，接续旧欧洲、北欧、北非、阿拉伯和亚洲西部。俄属波兰、波罗的海、白俄罗斯、当时俄属乌克兰、比萨拉比亚、克里米亚、欧洲本部、伏尔加及乌拉尔通过连续空间资料表达，不用现代俄罗斯国界作纹理裁切。

相邻国家的高程只作自然过渡，不改变1900政治归属。芬兰保持既有特殊历史身份；奥匈的加利西亚、布科维纳不改属俄国；克里米亚及比萨拉比亚不套现代疆界。芬兰、高加索及西伯利亚直接引用已有地理核心，未复制完整国家地貌。

实际新增201份bin：1共同概览、200细片；其中184份普通ETOPO、16份新选定GLO-90。直接复用254个已有核心。新bin共34,452,248字节，组合清单1,871,732字节。新水文分片0；新增LOCAL精细DEM0。16个GLO选窗的核心各有四个一度源单元；实邻边另保留。不是全俄统一90米或米级LOCAL。
