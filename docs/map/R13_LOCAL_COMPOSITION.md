# R13：LOCAL 合成与选择修复

范围：R12 现有地图显示和选择。没有新增地理资料、模型或模拟状态。

## 选择与悬停

- `GlobeController.select("", "")` 原本已能清空选择。`MainShell.map_selection_changed()` 却始终打开对象卡；无选择时 Presenter 不刷新 WorldPage，旧资料因此残留。
- 使用现有选择信号关闭临时对象卡，清空 WorldPage 的观察对象。人物身份、玩家国旗来源和相机不变。拖动阈值和 HUD 输入遮挡继续使用原路径。
- 悬停另发轻量显示信号，不再发 `appearance_changed`。原信号会刷新政治填充、经济地图观察入口和缓存视口。悬停现在只改变现有标记与标签，不改变水面、地形或行政主体材质。

## 一个 REGION 投影与同一视口

- 原 LOCAL 斜视压缩地面轴，但 REGION 底图保持俯视；两者并不对应。原地表还随屏幕中心高程改变垂直原点。R13 固定数据片参考高度，将所有 LOCAL 对象按既有 REGION 投影落点放置。
- 三维地表、普通建筑和地标共用地面变换。倾斜相机的地面缩短量在共同变换中补偿，零高度与原底图一致，垂直位移仍按实际米数显示。近景观察角为 55 度，较远 LOCAL 连续回到俯视。
- 模型东、北方向使用原球面等距投影的解析切向导数，避免用两个含大平移量的屏幕点相减。相机缩放及转向保留实际命中的地理锚点，不修改地理坐标。
- 既有 SubViewport 内明确分为底图 CanvasLayer -1、三维内容、注记 CanvasLayer 1。没有新增第二个世界或城市视口。
- 连续输入可能早于下一次绘制。射线拾取在相机姿态变化后同步当前变换，并失效旧屏幕点缓存，不重建 Mesh。
- 现有水系与行政注记读取同一份已显示高程网格，采用与地表相同的三角插值，跟随地形的屏幕高度。标签和拾取使用对应地理关系。

## 地表边界与水文交接

- 原矩形来自 `NativeLocalHeightReference`：整个 DEM 窗口使用不透明独立地表材质。同时旧分支在 LOCAL 隐藏战略图层中除河流外的内容，使技术覆盖边界更加突出。
- 保留原 DEM 采样。内区使用真实高程；覆盖边缘按地理网格约 12% 的窄带，将显示位移和局部着色渐退到原图。没有补造覆盖以外高程。原始采样与事实不变。
- 地表色读取现有地图配色，以原 DEM 法线形成克制明暗；不再叠加另一套深绿底板光照。边缘遮罩绑定地理范围，不绑定屏幕。
- 已有水面三角形在安装时切除重叠地表，保留来源规定的水位或原 DEM 贴合规则。没有增加河宽，也没有以加大高度偏移掩盖冲突。
- 进入 LOCAL 并完成实际视口呈现后，有限覆盖遮罩让 LOCAL 接管对应水面或中心线，避免 REGION 和 LOCAL 重复覆盖。退出或淡出时按相同权重交回。
- 河面采用低饱和灰青色，与线状水系统一。没有水面几何的河段仍是中心线，没有新增水流动画。

## 三角色块与普通建筑

- 已确认的异常路径：战略物理陆地按每面来源继承不同国家的政治和旗帜材质，并在 REGION 的正式政治表面上方绘制。R13 将该物理填充移到正式政治表面下方，不再对物理三角面使用国家皮肤；保留地形明暗、物理几何和政治表面自身的配色。WORLD 原有排序保留。
- 这条源码路径能够产生扇形色块，但没有运行 R13，不能据此确认截图中的全部三角异常只有这一原因。
- R12 六种共享模块、数量和地理锚点保留。仅调整显示体量与少量固定色阶，仍是抽象微缩组合；不生成随机位置或逐栋历史事实。模型底部与地标使用同一地表插值，继续避让既有地标。

## 生命周期与限制

- 新的高程纹理、水面交接遮罩、裁切用临时列表和射线数组归既有 LOCAL 内容所有。裁切列表在建 Mesh 后清空；退出时释放纹理、Mesh、拾取数组及材质引用。隐藏二维批次也清除采样器引用。
- 沿用 R10 的旧 LOD 退休、视野资源释放、异步请求收尾、有限 GLB 缓存及 R12 MultiMesh。鼠标悬停和普通时间推进不创建静态几何。
- 巴黎、伦敦的现代物理高程、水面参考及吉萨 DSM 的原有年代和精度限制不变。伦敦没有可靠统一水位，继续使用已有地表贴合参考，不能视为水力平面复原。
- 没有启动游戏、截图验收、性能采样或运行测试。资源导入和 Windows 导出不等于实际画面已确认。
- 没有修改历史主权、行政身份、LandTopology、经济算法、存档或 HUD 美术。MainShell 仅修改地图对象卡的取消选择同步。
