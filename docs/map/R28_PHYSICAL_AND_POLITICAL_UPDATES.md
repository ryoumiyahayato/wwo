# WWO R28 — Physical Map and Changing Borders

基线：本机R27。Godot 4.6.3 Compatibility。日期：2026-10-16。

本轮保留独立物理底图，接通已有正式土地的主权与实际控制。没有新增国家事件或地理内容。没有启动游戏、自动测试、回归、性能采样、哈希核验、审计、CI或Git操作。本报告区分源码施工与尚未确认的实机结果。

## 1. R27物理地图怎样加载和绘制

456个物理JSON／geom和354个可选ink文件保持原样，没有重制。Natural Earth原始资料没有读取进运行中的地图布尔运算。

`StrategicSpatialLoader` 按视野和粗／中档选择文件，解压既有几何。`LocalSpatialLod` 使用预制三角形并作原球面细分。`GlobeSurfaceBatch` 上传面数据。`LocalSpatialLayer` 完成整批LOD后发布陆地、海岸与水域版本，退休旧内容。WORLD和REGION继续转移同一套有效物理批次；LOCAL保留原地表和模型目标。

本轮直接读取法国相关 `physical_1_4_mid_5_1` 与 `physical_2_4_mid_0_1` 的实际描述、geom和ink：物理来源均为 `natural_earth_independent_physical_r27`；水域标记为REFERENCE_MASK_ONLY；政治文件角色均为DISPLAY_INTERSECTION_ONLY_NOT_SOVEREIGNTY。前者20个陆地组件、20段海岸组、2128个政治分区三角形，后者57个组件、61段海岸组、2853个政治分区三角形。组件数与岸线组数不要求相等，分片边界会切开线。只是资源结构读取，不是全体文件的自动化验收。

政治墨层是独立P范围内的可选完整分区，不是另一层全球不透明陆地。没有墨层时使用P本身，有墨层时使用同一物理范围的分区。物理岸线仍从相同简化P取得，不从国家外缘取得。孔、多组件、岛屿、反经线展开、地平线双扇面和既有退化面处理保留。

## 2. 本轮确认的公共问题

1. **视野候选可能漏片。** R27在球冠相交判断前，先用 `纬度半径/cos(中心纬度)` 近似经度跨度筛一次。它不是球冠经度极值，高纬且未越极点的视野可能被提前排除。现在物理分片直接按原球冠与经纬矩形最近距离选择；不再叠加该近似筛选。不降低数据精度，也不重新引入前64片截断。
2. **物理未知陆地仍可能拾取邻近国家。** 原历史精确面没有命中时，R27仍允许0.75像素内的邻近政治面作为候选。现在已确认的物理陆地若没有正式当前主权或历史精确命中，就返回未知地理参考，不再借最近国家。
3. **安装与拾取有一帧状态差。** R27按batch.visible判断陆地。批次完整安装并退休旧面后，可见标记要到下一次draw才设置；其间已安装的陆地可能被水域补集判成海。现在按已完成的有效LOD查询，不依赖该可见标记。后台未完成的面仍不参与。
4. **已有状态更新没有进入地图。** `TerritoryState.controller_changed` 已存在，但R27地图未订阅；`set_land_sovereign` 也没有显示通知。国家填色、拾取和资料卡只见初始政治范围。本轮补上实际通知和显示消费者。

没有从源码确认新的普遍环方向、孔洞丢失或索引倒置。R27的完整后继LOD交接、同源海岸、岛屿和孔处理保留，没有重复申报。政治切换不会触发NE解析或海岸三角化。

本轮没有实际法国画面。因此不能说此前法国海峡、西部海湾、科西嘉的尖角、细长色块和缺口已经全部消失。源年代差异、概化精度、球面／平面有限边缘近似仍在。本轮没有法国专用偏移、统一缓冲、删尖角或海色遮挡规则。

## 3. 当前国家与领土状态保存在哪里

| 内容 | 实际保存和读取位置 | 当前能力 |
|---|---|---|
| 国家身份 | RuntimePoliticalEntityRegistry；RuntimePoliticalEntityView为只读快照 | 开局历史实体、source ID、active状态和初始沿革；不是按日期自动建国 |
| 历史名称、旗帜、初始范围 | HistoricalPoliticalEvidenceView、HistoricalLoader/ResolvedMapContent、原CShapes及阿拉伯显示资料 | 提供带来源的历史显示；名称和旗帜可按已有有效期解析 |
| 正式土地几何 | SpatialWorld拥有的LandTopology | 当前有限覆盖、稳定单元ID、邻接、合法拆分与退休谱系；不是全球每块土地都有正式单位 |
| 当前土地主权 | VNextSpatialWorld._land_facts中的sovereign_polity_id | 已有set_land_sovereign；空值表示未知，不推断国家 |
| 当前实际控制 | TerritoryState._controllers | 已有set_controller和controller_changed；地点旧ID与territory_unit ID保留各自范围 |
| 历史行政 | 现有行政身份／GIS与独立土地成员字段 | 主权、控制变化不重写成员或原GIS |
| 保存 | FormalPersistence的territory，以及Spatial快照land.topology/land.politics | 原流程恢复当前控制、主权、拆分；本轮不改五槽或存档格式 |

源码中的隔离VNextTerritorialControlLedger不是当前正式地图的控制来源。本轮没有将它接成第二账本。

现有土地源文件有315个开局单元，并有原历史行政初始化拆分。它们属于现有法国有限空间工程及已注明的扩展，不是本轮新建的全球领土网格。生成单元边不是声称历史上已有这条国界。

## 4. 国家颜色如何跟随当前状态

`FormalWorldPresenter.refresh_map` 绑定现有SpatialWorld和TerritoryState。Renderer换世界时断开旧通知，再读取当前土地记录；存档加载也走这条入口。

对于开局初始化资格已经撤销的实际单元，读取正式主权和控制，不再无条件使用初始CShapes身份。该标记也可能由显式行政操作撤销；它只用于找到应读取的当前记录，不用于猜测新国家。最终国家颜色始终取主权字段，控制字段独立保留。

首次接入某单元或它的真实范围变化时：沿LandTopology原投影边采样地理范围，在相交的现有物理分片内切分政治显示三角形。既有LOD工作线程只处理受影响片的land_reference。上传完毕后替换这些显示批次；原完整物理多边形、coast和CPU水域引用不变。没有新全球差集或第二套底图。

该范围已安装后，再改变主权只改变对应墨层材质参数。当前主权仍与原墨层一致时，保留原国旗UV和墨层，控制变化不将其去旗或换成占领国。主权确实不同时使用新国家基色，不把整面新国旗拉伸到一小块土地；恢复原主权时可复用原UV。HUD国旗保持。已知主权为其他国家时不继续用旧国家颜色；未知主权用物理中性色。

颜色、旗帜和名称的已有资料更新继续由ResolvedMapContent解析。范围没变时不重新三角化物理地图。当前注册表没有正式改名／颜色编辑字段或新实体演进接口，本轮没有假造这些能力。

## 5. 边界与颜色如何对应

- 主权不同的两个已知正式土地单元，按它们现存的真实共享边显示主权分界。
- 只有实际控制不同，使用独立的暖色控制线；国家填色仍是主权色。控制线不称法理国界。
- 相同状态的共享边不生成政治网格线。相同共享边去重，不把所有生成单元画成国家边界。
- 正式覆盖外侧缺少相邻有效状态时，不臆造一段新国界；该处仍有颜色范围，但不将不完整资料包装成完整国界重建。
- 旧历史国家线在已安装当前单元范围内退出。WORLD历史线按有限源组复用，只重做相交组；REGION细节线在原后台准备中裁出当前范围。历史原线不改。
- 新状态线也使用已安装物理水域作显示裁切；行政线继续走原独立路径，不因为国界颜色改变而修改身份或成员。

主权线和控制线沿用原边界Shader、原有界overlay线程及canvas/RID生命周期。WORLD和REGION只换投影参数，不增加相机、SubViewport或独立全球地图。没有按每个游戏小时重制354个ink文件。

## 6. 选择、悬停与资料卡

海洋判定仍先使用当前已安装的物理覆盖。地标、地点和历史行政选择入口保留；它们的身份不因为新的主权颜色而被替换。

在已安装当前正式单元的范围内，国家查询读取该单元主权；范围外继续读可靠历史政治面。单元主权未知就保持未知。不会仅据物理Mesh或绘制先后分配国家。

点击现有行政区或地点时，保留原选中对象，同时记录点击处正式土地上下文。原资料卡补列“当前主权”和“实际控制”；历史行政和历史归属仍按原资料列示。当前单位主权改变后，已选中的国家和资料卡跟随更新，不改玩家身份或所在地。

只有地点控制记录、没有可靠面积几何的变化，资料卡显示实际控制，不扩大成国家领土。控制ID通过已有runtime/source显式映射解析，不猜最近国家。

LOCAL目前只有单一地表墨层，不能在一张DEM内精确分配多块当前政治颜色。如果当前主权范围与其原统一墨层冲突，本轮停用旧统一政治染色、保留物理地形和下层当前政治地图，不把整张LOCAL地表染成错误国家。没有重建DEM或重新加载所有古迹。LOCAL逐单位政治材质尚未完成。

## 7. 已有变化能力与缺少的条件

已有足够数据：`set_land_sovereign` 对现有正式单元的主权变更；`set_controller` 对正式单元的控制变更；已有 `split_land` 生成的合法子单元；原存档恢复的上述状态。它们提供实际多边形和明确ID，可以更新有限范围。

没有增加任何调用这些方法的战争、外交或国家事件。现有军事服务胜利控制路径主要更新战区内地点ID，并记录effective_hour；地点集合不等于有完整战区多边形，不能据此重画全国边界。当前正式时间链没有因此新增军事推进。

尚未具备：完整建国／解体／合并、国家改名和显示色编辑；任意新全球边界；所有地区的正式领土单位；主权与控制变更的完整逐日期历史。TerritoryState现有当前值本身没有每项effective_hour，军事control_history不能自动当作所有领土的历史记录。

只有事件文字、地点集合、行政名称或日期，没有可靠空间范围时，不画新国界。现代NE与历史CShapes范围不一致的陆地，不自动分给附近国家。

## 8. 性能与资源边界

颜色变化不读NE、不改coast、不重制DEM、不重建相机或三维目标。范围相同的再次变更不重做政治分区，只更新参数。范围首次出现或改变时，只重做相交物理片内的政治显示；原完整物理底图和岸线继续显示到后继完成。

按物理片分组后可以替换受影响批次，避免把一个国家的全球显示全部重做。代价是部分国家跨片时会增加小批次。没有新增美术纹理或Shader采样；小批次增加也会增加相应的既有面数据纹理和材质资源。实际运行成本尚未测量，不能承诺风扇或缩放负担已经降低。

沿用原线程、过期请求丢弃、有限上传预算、原LOD退休和按需视口更新。政治范围的准备错误会保留上一有效地图并报告，不以空白面冒充成功。没有每帧布尔交集、全日期地图缓存、五套DEM或常驻第二地球。

4×时间推进仍执行原GameClock和领域结算。只有真实状态通知或当前显示内容改变才更新政治显示。经济、人口、人物、组织、军事和外交算法均未修改。
