# WWO R47 — Historical Map Symbols and Icon Atlas

日期：2026-10-18。基线：R46及其后专项调查、清理。开工时项目序号46，没有R47交付；本轮采用47。未进入下一地区地貌建设。

已制作15种原创图形，并接入原GlobeRenderer：12种核心、两种宗教建筑变体、一个通用聚落回退。只读已有历史身份和地点；未生成城镇、人口、运输或行政事实。PNG素材、代码接入和Windows预览已交付；未启动游戏，不能把导出当作玩家视觉验收。

## 原路径及修改

原地点在`LocalSpatialLayer.update`投影、筛选，合并到`GlobeRenderer._place_points`；`_draw`按rank画方点/圆点，古迹走`_draw_landmark_symbol`，交通走`_draw_transport_symbol`。城市微缩及河岸另有建筑线框和7—10像素强调圈。文字又分别由local、strategic、GlobeRenderer绘制。不同来源的符号优先级和文字碰撞范围不统一。

本轮沿用原地点集、投影、视口及模型可见通知。新增`MapSymbolAtlas`只负责共享美术读取、类别解析、屏幕矩形占用与绘制；没有线程、SubViewport、独立地理数据库或自管RID。最终符号仍由GlobeRenderer这个CanvasItem提交。

```mermaid
flowchart LR
  A[现有地点与历史身份] --> B[当前视野投影点]
  B --> C[类别与尺度准入]
  C --> D[屏幕矩形避让]
  D --> E[同一PNG图集绘制]
  F[RegionView确认模型已经显示] --> G[退出常态图标；保留模型拾取]
  G --> D
```

旧古迹/交通手绘函数、聚落rank圆点及微缩建筑定位圈被替代。旧local/strategic各自的文字绘制、字体字段及重复占用状态退出；地名由同一批已准入符号的独立文字对象绘制。原地点投影数组、身份、资料查询和三维模型拾取未删除。

## 身份读取及有效期

首都对应离线核对现有正式capital名称、已有地点名称和坐标；唯一匹配且代表点相距小于10公里才记录两个来源。名称不是从普通城市推断首府的依据，身份先由capital声明给出。运行时重新核对当前政治显示快照中的原历史身份、capital名称及有效期；源声明变化后旧对应不再成立。未成功对应的首都不造ID。

首都和城市只选一个主要符号。原capital字段中的受控领地、保护地驻地不自动成为国家首都：按原relationship分别用星形或菱形；不是根据军事控制改变图标。首都优先级100、一级首府90、其他行政中心78、城市75、城镇55、村庄35；古迹和设施保留独立类别及适用尺度，并非从行政等级推定。

一级首府角色由`HistoricalLoader.resolve_map`读取既有法国身份中的明确place链接，随`ResolvedMapContent`交给Renderer。当前只有巴黎、凡尔赛明确对应，不用其他省份capital_name或多边形中心补造城市。区县中心来自已经被当前视野请求的行政身份及其原中心坐标，不在首屏枚举全法国区县。

诺让没有被本轮新注册成`place:nogent_sur_seine`。其图标使用已存在的`administrative_region:france_arrondissement_102`，名称、中心和资料卡仍属原行政身份。它能表示行政中心，不意味着本轮已建诺让城镇数据库。无稳定place关联的多来源中心仅作屏幕避让，不擅自合并史料对象。

所有对应限制在已有有效期内；静态分类表目前适用于1900年度。正式系统尚未提供独立动态迁都输入，本轮没有新建迁都或行政事实系统。显示快照刷新会重新判定；实际控制和军事行动不被当作首都变化。

## WORLD、REGION与LOCAL

- WORLD复用球面投影，背面点不准入。当前小型对应清单包含16个已有国家／交战国家首都点；另8个殖民地或保护地行政驻地只在REGION用菱形，不作为国家首都；普通重要城市只消费原已取得地点，不为图标加载全国LOCAL包。WORLD最多24枚符号，不加载村庄、车站或桥梁GLB。
- REGION保留原地点的日期、视野筛选，再按类别LOD显示。屏幕坐标矩形参与避让，图标不随地理半径增长。最多160枚符号，不代表每个视野必须填满160枚。
- LOCAL交接读取`RegionView.landmark_visible/settlement_visible`，要求已经呈现、实例可见且有有效屏幕范围。请求中、失败或未呈现不能隐藏符号；离开模型显示范围后恢复。判断不依赖猜测的“模型正在加载”标志。
- 模型出现后正常图标退出；选中只留下约8像素底部细金线，没有大实心圆盘。图形消失不移除原模型包围框拾取。模型拾取在REGION/LOCAL实际可见时优先，随后才检查已准入PNG的矩形。
- 图标点击框比画面矩形扩大4像素；未显示的普通图标不保留隐形圆点热点。原行政多边形选择、三维模型拾取、地理参考和资料卡入口保留。新首都参考可通过已有`geographic_reference_selected`传回显示资料，不写入WorldState。

## 避让、文字与状态

当前可见集合按选中、类别优先级、上次保留状态和稳定ID排序。使用32像素屏幕格存放占用矩形，只比较相交格；不执行全球地点两两比较。HUD和国家标签也参与占用。低优先级候选被遮挡时延后显示，不移动其真实地理锚点。选择优先可以突破普通碰撞限制。

12%LOD余量、同档保留偏好和稳定ID排序减少临界尺度交替。实际滚轮闪烁仍需用户观察，不能把算法规则当作实测保证。来源位置不同且没有稳定对应的同名地点不被强行吸附。

图标与文字分开。地名保持原中文/英文，放在图标右侧；最多40个常态文字，选中可优先。文字测量和字体有界复用，行政文字继续走原入口并避开地点矩形。地图标签关闭时，选中/已有悬停文字仍可提供反馈。

正常原色；悬停只增亮；选中用细底线。`symbol_selectable=false`可降亮且不进入符号热点；来源未知不会因此被判不存在。当前普通历史地点并未为展示此状态而人为禁用。

符号布局只在视图、内容、行政中心需求、模型呈现、选择或避让区域变化时重建。hover只重画前景符号，不触发地图纹理重建/上传；没有呼吸动画、TIME材质或新的持续处理器。

## 资源与启动边界

一个共享图集，一份ResourceLoader纹理引用；没有按地点加载独立PNG，没有每地点ShaderMaterial、CanvasLayer或SubViewport。裁切坐标来自清单，同类共享纹理；普通符号不自管CanvasItem RID。

图集及对应清单在实际地图需要符号时读取；油画首页没有提前实例化Renderer。离线制作可以枚举既有目录，运行不因此加载原GIS、全球城市几何或全部LOCAL模型。125个城市ID只是固定分类查找表，不是每帧全球扫描。

576×576 RGBA基级逻辑数据1,327,104字节，完整Mip逻辑数据1,769,448字节；不是显存或进程内存实测。独立PNG因原内部`all_resources`仍在包中，运行不读取它们。图集失败保留小型通用符号回退，未接入全球地图完整性门控。

离开地图时`MapSymbolAtlas.dispose`释放图集引用和分类状态；原Renderer场景仍负责其他资源。没有把新图标永久全局常驻，也没有宣称R41旧CanvasItem RID警告已经解决。

R39相机、24份coarse、有界medium、WORLD提交、R37政治包、R40行政和地理模式、R41模型与许可、R42—R46地貌、海洋太阳银河及黄铜半球仪未改。未执行性能测量，不能声称11秒、帧时间、内存或风扇改善。
