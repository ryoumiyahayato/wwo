## 阅读与执行约定

A–G 定义七个系统；H 定义六种 NPC；I 推演五条因果链；J 描述实际游玩；K 给出全世界成熟度；L 列出尚需选择与校准的机制。每节的验收句均描述未来开发要证明的行为，本次没有执行这些玩法验收。

玩家始终控制一个仍能行动的人物。看见某个国家、公司或军队不产生控制权；本人有任命、财产、成员资格、合同或有效委托，才可选择相应动作。被免职后仍可生活、求职、组织反对派；破产、选举失败和战败不自动结束一局。人物继承继续遵守既定的真实关系与退出条件。

所有时间均为游戏时间，除 J 特别标明现实游玩时间。动作显示预计耗时及原因；交通中断、补件、谈判和资源不足可以改变完成时间。已有日常计划持续运行，玩家无需每日点击上班、吃饭、缴每笔固定账单或批准每盒弹药。

### 共同的可玩规则

1. **行动必须有明确对象。** “争取支持”应具体到哪项提案、哪个组织或选区、哪类承诺；“扩建”应具体到哪处设施、增添什么设备和多少岗位。
2. **权利、实际手段、信息分别判断。** 有签约权却没钱、有部队却收不到情报、知道某人却联系不到，都产生不同选择。
3. **承诺不等于完成。** 采购保留未交货量；职位保留任期；预算保留未执行部分；协议保留双方未履行义务。
4. **持续行为在条件改变后调整。** 中途罢工只减少之后班次的劳动；新税率只用于其生效范围；已经完成的运输、生产和投票不被倒写。
5. **失败给现实的恢复路径。** 缺货可部分交付、改约、换供应商或赔偿；被否决可缩小方案、改条件或重新争取批准。没有可以反复点击的无成本成功抽签。
6. **消息有范围和日期。** 本人资金与职责内记录可精确查看；外地报价、前线报告和民意调查有时效与误差。隐藏事实只用于检验世界是否一致，不泄露给 NPC 或玩家。
7. **同一事实产生具体后续选择。** 工资欠付形成应收款和生活缺口；生活缺口让人考虑换工作、求助或参加议题组织。不得直接把它换成一个全体支持率或稳定度增减。

## A. Organization：一个集体如何形成并采取行动

### A1. 组织内部到底保存什么

| 内容 | 必须具体到什么 | 玩家为什么关心 |
|---|---|---|
| identity | 稳定身份、名称、种类、成立依据、活动地区、当前状态 | 换领导后仍是同一公司或行政机构；旧债旧合同不消失 |
| purpose | 明示宗旨、服务对象、禁止事项；当前经营/组织目标 | 合作社经理擅自卖掉会员公用设备会受到章程挑战 |
| internal units | 有真实职责、负责人或人员的部门、分支、委员会 | 采购、人事、生产、地方支部各有待办；没有职责的层级不创建 |
| membership | 谁是成员、资格、会费、加入/退出/开除依据、投票资格 | 员工不自动是股东或党员，非会员雇员仍能工作 |
| positions | 职责、席位数、选任办法、任期、报酬、兼任限制 | 董事长、部长、军需官是职位；一个职责不必另建组织 |
| appointments | 人物、职位、产生程序、生效/结束时间、代理状态 | 同一个职位换人后哪些权限留下、哪些个人委托失效 |
| internal hierarchy | 常设管理关系、可上报事项、监督与申诉路径 | 下属可以向谁请示，谁能撤换谁；上级身份不自动授予全部专业权限 |
| Power profile | A2 的分项能力及证据、可支配程度、限制 | 区分“有钱”“有预算批准权”“能组织到场的人”“有兵但缺弹药” |
| authority scope | 代表谁、能做什么、对哪些目标、额度与期限 | 财政部官员不能用同一授权替私人公司付款 |
| decision procedures | 提案资格、票权、法定人数、多数规则、确认/否决、截止和执行职位 | 知道该争取哪几票、还缺哪个批准，而非只看到一个成功概率 |
| current agenda / matters | 具体问题、候选方案、责任人、截止、所需批准、承诺和执行进展 | 缺煤、工会谈判、空缺职位、预算审议是真正的组织待办 |
| external relations | 控股治理、合同、联盟、监督、任命、谈判、配属等有类型关系 | 公司与工会是谈判对手；议会与政府是制度关系，不能都挂成下属 |
| resource references | 对应的资产、账户、场所、设施、部队、雇佣和合同 | 可以追到实际资金、工人和仓库；组织介绍页不自造资源 |
| lifecycle | 成立、活动、重组、受限、清算、解散及历史 | 退出经营仍需处置债务和员工，组织被禁也不意味着成员凭空消失 |

可任职者、成员和支持者不是同一集合。某人可以是公司雇员、工会会员、政党党员和地方议员；每次代表行为必须选一个真实身份，兼任冲突按具体制度处理。大型背景团体可用受约束的成员登记和代表名额，不要求每位成员具名。

### A2. Power profile：权力和实际能力分开列示

不汇总成总 Power 分数。每一项显示：来自哪里、持有什么权利、实际上能支配什么、受到什么限制、最近哪件事改变了它。量可以有不同单位，但不能相加。

| 类型 | 现实能力与来源 | 可衡量的内容 | 如何进入其他玩法；失去它的具体途径 |
|---|---|---|---|
| economic 经济 | 自有现金、授信合同、可售资产、产能、采购规模 | 可动用资金、到期债务、可用产能、可交付货量；已抵押和已承诺部分分列 | 支付竞选印刷费、提供工作、拒绝不盈利订单；欠款、封锁、抵押或破产缩小可用手段。财富不授予法定命令权 |
| administrative 行政 | 合法辖区、办事人员、档案、派驻点、工作流程 | 各类案件的实际办结能力、积压、到达覆盖；不能只给全国一个行政值 | 批许可证、征税、登记选民、发救济；离职、档案损毁、交通受阻导致具体业务延误 |
| political 政治 | 有效席位、议程设置权、提名权、否决权、尚有效的合作承诺 | 哪些票能由谁投、谁承诺支持哪件事、哪些事项可进入议程 | 提案、组阁、否决任命；倒戈、失去席位、协议到期会逐项减少可用支持，不能直接扣一个政治货币 |
| coercive 强制 | 有组织且愿意执行的武装/执法人员、装备、有效指挥或事实控制 | 能部署的单位、可达区域、补给、拘押/警戒能力及服从状态 | 执法、战斗、占领；命令可能违法或遭拒，执行会消耗人员时间和物资。持枪人数不能自动等于合法征税权 |
| organizational 组织 | 招募、会议、分工、内部联络、保有干部和执行承诺的能力 | 能召集的合格成员、可联系支部、空缺干部、正在办理的事项 | 完成会员投票、选候选人、管理项目；书记缺位或地方分裂会让具体名单和承诺无法落实 |
| informational 信息 | 报告、记者、侦察、档案、发行与通信渠道 | 覆盖对象、消息日期、证据可靠性、发行量与送达率 | 知道供应商报价、发现征税漏报、发布调查；报道改变收到信息的人对具体议题的判断，不自动控制他们 |
| social / mobilization 社会与动员 | 信任关系、社团网络、声誉、参与者愿意付出的资源 | 对具体请愿、会议、捐款、罢工的报名人数、到账金额、实际到场人数 | 拉来志愿者、募集救济、组织停工；失信、代价过高、信息未送达会使报名撤回或不到场 |

“具有能力”与“使用过能力”也要分开。工会能联系60名会员，可能只有50人投票、35人参与罢工；议员承诺投赞成仍要等正式表决。老板宣布捐100 U，未付款前竞选组织没有这100 U。概览可以提示“资金充足但组织覆盖薄弱”，不得把七栏压成战力式排名。

### A3. Power Transfer：九种转移及其完整边界

每次转移都要可回答 source、recipient、scope、basis、validity、revocation、exclusivity。转移的是具体职权、代表权、指挥关系或合作承诺；它通常不搬走账户、会员、资产和全部社会影响。

| 方式 | source → recipient | scope 与 basis | validity 与 revocation | exclusivity 与游戏结果 |
|---|---|---|---|---|
| appointment 任命 | 依法或依章程有任命权的职位/机构 → 合格人物 | 指定职位、部门、辖区；有效任命决定，需确认时包含确认 | 明确就任至期满/免职/失能；有权者按程序撤换，不能随便自我永久续任 | 单席位同一时段一位正式任职者；代理权限另列。新任人获得该职位权利，不接管前任私人财产 |
| election 选举 | 合格选民/会员依规则形成的选举结果 → 当选人 | 指定席位或职位；名册、票权、计票、异议处理及确认依据 | 结果确认后的就任日生效；任期、依法罢免/撤职或重选结束 | 一个席位只归一人；多席位按选制分配。当选党主席不自动当选议员 |
| delegation 委托 | 已持有且可委托该项职权的任职者 → 指定人物或职位 | 项目、目标、金额、可再委托与否；有效书面/组织记录 | 明确到期；可撤回；个人任命作为依据失效后停止新行为 | 可非独占，也可指定唯一签署人；不得扩大原范围。撤回不抹掉合法已签合同 |
| board authorization 董事会授权 | 有效董事会表决 → 经理职位/指定代表 | 特定项目、总承诺额、条件；会议规则与已通过文本 | 到项目期限、执行完或被修改/撤销；撤销须处理外部既成义务 | 多人可获授权但共用一个项目额度，不能每人各花全额；必要时双签 |
| ownership governance 所有权治理 | 正式股权/合伙资格的权利人，经治理程序 → 董事或经营者 | 选董事、重大事项、利润分配等章程权利；股份登记及公司规则 | 随股权登记和治理决定变化；撤换仍走有效程序 | 股权可分持，选票按登记；经营签署席位另定。买51%股份不直接获得仓库任意取货权 |
| command assignment 指挥配属 | 有配属权的军事职位 → 接收指挥职位 | 指定部队、任务、地域和命令类别；配属命令 | 到期、任务结束或上级明确替换；规定恢复去向和已下命令的接续 | 同一部队、时段、作战事项一条最终指挥链；行政隶属可保留，协同不构成第二条最终命令链 |
| statutory / constitutional grant 法定授予 | 有权制定该规则的制度程序 → 某机构或职位 | 列明事项、辖区、对象、条件；已公布且生效的法律/宪制规则 | 按生效日及过渡条款；废止、修法、有效裁决或任职结束后相应变化 | 可列举专属、共同或并行职权；共同事项写明谁批准、谁执行，不靠双方都说“有权”解决 |
| coalition agreement 联盟协议 | 各组织有授权的代表及各自批准者 → 协议各方 | 对特定候选人、议程、预算或投票的合作承诺；相同版本协议 | 期限、目标完成、退出与违约条款；不能撤销已经合法完成的公共行为 | 可排他合作或逐事项合作；协议不直接发公职、不代议员投票，实际任命另走国家程序 |
| temporary emergency authority 临时紧急权力 | 制度规定的启动者及必要批准者 → 指定官员/指挥职位 | 已确认的紧急事项、地区、期限、额度和措施清单 | 到期自动终止；续期重新批准；复核可提前结束，善后义务继续 | 冲突事项写明临时优先关系；不能由受权者自行无限延期或把救灾权扩为任免所有议员 |

共同规则：同一代表不能凭两份相似授权重复花同一额度；部分撤权只影响被撤的事项；机构权限变动须通知有关部门，通信尚未送达者可能继续按旧指示工作，但是否构成有效外部行为由该制度的生效/通知规则决定，不能无差别追溯重算。公共规则推荐公布生效，内部临时军令推荐送达生效，详见 L。

### A4. 提出 → 批准 → 代表/签署 → 执行如何成为玩法

| 情形 | 需要哪些步骤 | 具体例子 |
|---|---|---|
| 超出既有授权、改变他人权利或承诺重大资源 | 四步完整；每步可由不同人物承担 | 公司扩建、增税、对外重大采购、强制征用、长期劳资协议 |
| 已批准预算/项目内的常规操作 | 批准已经存在；经办人选目标、签署，工作人员执行 | 财务按有效工资表付款；采购员补购额度内耗材 |
| 经制度允许的日常指挥 | 指挥职位及常设命令构成批准；下令并送达，下属执行 | 师长安排已授权防区内换防；厂长调整下周普通班次 |
| 私人自愿活动 | 本人的选择和对方同意构成必要程序；无组织审批 | 工人买饭、申请工作、小店店主采购自有资金范围的商品 |
| 既有持续安排 | 无新选择时按原安排继续；跨阈值或改变内容才请示 | 每周订粮、工资支付、巡逻、普通住户消费 |

程序不能任意拖长。办公室内部签署可耗15–60分钟工作时间；必要会议需约定召集与表决期限；邮寄确认另加送达时间。审批者可以批准、拒绝、要求补材料、缩减或附条件；经办者可撤回未成立承诺、修改文本后重新审批。

表决须固定资格截止、空缺是否计入、法定人数、弃权、平票、回避、能否改投及复议办法。样例董事会5席、3人出席构成会议、赞成严格过出席半数：3人出席2赞成通过；4人出席2赞成不通过。文本改了金额、候选人或覆盖范围，旧批准不得继续使用。通过后无钱、无人、未送达或未完工，各有明确状态。

### A5. 六个完整组织实例

| 组织 | 内部构成与权力来源 | 一件事的完整经历 | 失败、交接和外部后果 |
|---|---|---|---|
| 小店 | 店主经营职位、可选店员；本人资金、租约、店铺库存、营业资格。无需董事会 | 店主看到次日可能卖出20份食品，花30分钟询价，按自有资金和已有资格买20份；付款后等半天送达，再按零售价出售；店员只获收款和售货职责 | 现金只够12份就缩单或借真实信用；卖不完会腐坏；店员不能抵押店铺。店主停业须退租和结清欠薪 |
| 股份公司 | 股东资格、董事会、经理、采购和工厂；股东产生董事，董事任经理 | 厂长提300 U扩建；经理常设限额100，提董事会；2/3到场赞成形成项目授权；经理签施工合同；实际工人、材料和安装用10日 | 现金不足可延期开工；已承诺200后再签150须重新批准。经理被换不清空项目、账户和合同 |
| 政府部门 | 财政部部长、预算处、支付处、税务分支；公职与法定辖区 | 部长提地区救济200 U；议会/有权预算机关通过；部长在额度内签拨付；地方人员核查名单，财务付真实款，物资人员发真实粮 | 5名经办员一天最多核查规定户数；积压家庭继续缺粮，可申请人员支援或按合法紧急名单先发。部长不能临时“生成国库” |
| 政党 | 党主席、地方支部、党团、党员；章程权、会员资源、议会席位分别记录 | 党主席谈组阁，党内批准与另一党同一文本；党团劝议员支持候选人；议会实际投票通过后形成任命依据；部长依法就任 | 60个联盟席位实际只有48票则失败；党主席可以重谈或转反对派；开除党籍不自动剥夺制度上仍有效的公职 |
| 军队 | 指挥机关、军官/军需/军医职位；部队与人员装备另有实际状态 | 上级批准第十师配属第二军3日；配属通知送达；第二军发防守任务；师长编组和移动；军需官组织补给；实际抵达后进入阵地 | 有指挥权但无铁路空位要分批或走公路；原第一军保留列明行政补给责任，但不能继续新发该范围作战命令 |
| 工会 | 分会负责人、合格会员、谈判代表、基金；会员与受雇人员分开 | 60名会员中50投票、35赞成授权罢工；负责人联系当班者，35人在职者确认；下个班次实际少35人工作；双方谈工资并按权限签同一和解文本 | 全厂100人不会全停；基金不足则减少补助或再募款；最低涨薪6%的授权不能直接接受5%，须回会员批准 |

### A6. 组织生命周期

成立先有明确创设依据：个人创办、成员共同签署、公共机构依法设立、上级建立编制或事实上的结社。初始职位由成立程序指定，不能要求尚不存在的董事会批准自身诞生。注册/承认、内部存在和实际资源是三件事。

分裂时，成员选择去留，部分职位空缺，新组织另有身份；转走资产、基金或合同须有相应处分权和对方同意条件。合并须分别批准并列出承继的债务、雇佣、会员和职位；新旧身份保留追踪，不让人凭改名逃债。收购股权可以改变董事选任，却不一定合并公司。

重组明确哪些部门合并、哪些职位结束、何时生效、谁接手待办；原有审批与业务义务逐项处理。解散先停止普通新业务，依法清算、结薪、转交公共职责、安置人员；历史身份保留。组织被禁止可失去合法渠道、资金或场所，成员是否继续地下活动留作 L 的深度内容，不靠删除所有成员结束冲突。

**A 的玩法验收：** 无权董事付款失败；拥有同一项目授权的两人不能各自再花完整额度；经理换任后合法旧合同继续；工会分裂不复制基金；部队配属不改变行政账和位置。六种组织均应至少有一次自主继续的日常事项及一次需要玩家取舍的例外事项。

## B. Government：公共职位每天实际办理什么

### B1. 机构、职位与日常职责

| 机构 | 主要职位与经办者 | 每日/每周实际工作 | 玩家可作的选择 |
|---|---|---|---|
| 中央行政领导机构 | 政府首脑、内阁成员、办公秘书 | 排审议议程、协调部门、处理未达成一致的项目、回应议会 | 先保救济还是军需；接受附条件支持；更换失职负责人；要求报告 |
| 财政部/国库 | 财政部长、预算官、税务负责人、出纳 | 核对征收、已批准支出、付款到期、现金和债务 | 支出排期、提追加预算、依法借款、决定在既有规则内的付款优先 |
| 内政/地方行政机构 | 内政部长、地方行政长官、登记与许可人员 | 户籍/资格登记、地方报告、公共许可、灾情协调 | 调查积压、简化可合法简化的材料、派员到缺覆盖地区 |
| 公共工程机构 | 工程负责人、工程师、验收员 | 勘察、招标、监督施工、验收维修 | 选路线、分期建设、关闭危险设施、在预算内改施工安排 |
| 战争部/军政机构 | 战争部长、动员和军需行政官 | 征募、装备采购、军饷、补充与高级人事 | 请求预算、调配征募任务、签批准采购、保留紧缺民用岗位 |
| 地方政府 | 市长/地方长官、地方议事机构、基层经办人员 | 本地税费、许可、卫生救济、道路、执行上级明确委托 | 地方预算取舍、设服务点、反馈中央命令无法完成的原因 |
| 司法和执法相关机构 | 有权裁决者、检查员、警务负责人、执行人员 | 审理申诉、检查、调查、执行有效决定 | 受理/补查、安排现场检查、执行有依据措施；职责依制度分开 |

机构之间通过具体辖区与事项协作。警察不自动兼有裁判权；公共医院/救济站可以由地方政府、慈善组织或承包机构提供。具体国家的机构名称、地方自治程度和职责组合属于内容配置，不强制所有国家出现同一张机构树。

部级人物的日常不是点击“行政能力增长”，而是在积压、资金、人员、政治承诺与期限之间选择。普通经办员的玩法是核材料、调查、说明异常、排案件和请求上级决定；其裁量、可接触的关系与个人责任都小于部长。

|---|---|---|---|---|
| 政府议程与部门协调 | 部长/首脑提出；内阁或制度指定者决定 | 首脑或分管部长签任务；部门负责人分工 | 秘书整理报告、会议占用半日至数日，外地报告另等送达 | 未知情况先调查；部门冲突保留未决事项，可缩小任务或分期 |
| 编制/调整预算 | 各部门报需求，财政整合；有权预算机关批准 | 财政部长签执行安排；国库与支出部门付款办事 | 有项目明细、到期义务和收入预期；讨论数日至数周 | 获批不增加现金；不足时延后可延支出、提借款/增收/削支，工资和合同可能欠付 |

| 任命/补位 | 有提名权者提合格候选；任命者及必要确认者批准 | 有权职位签任命；人事通知、任职者交接 | 职位空缺/有效撤换依据、资格与候选同意；1日至数周 | 候选拒绝则换人；无确认不就任；合法代理只得限时权限，岗位无人办理会积压 |

| 政府间协调 | 一方提跨区事项；每方对自己的职责与资金批准 | 各方授权代表签一致文本；各地分别组织落实 | 共同项目、分摊、期限、报告和争议办法；通信与谈判2–14日 | 一方延迟导致对应路段/拨款未完成；另一方可分期或重谈，无权直接替对方花钱 |

### B3. 行政过程的可玩细节

每类案件有具体工作量。验收例：120份简单许可，每份需1个合格经办员工作小时，3名经办员每日各有6小时用于办件，则首日最多办18份，全部至少7个工作日；现场检查和补件时间另算。不是给地区加“行政能力+10”就全部办完。

默认先处理有法律期限和紧急资格的案件，同类按受理顺序；玩家可以依法调整优先级，但必须说明依据。调两名税务人员去发救济，救济核查更快，同时税务可用工时减少；相同人员不能在两个地方同时办满额业务。雇新人需预算、招募、培训、办公地点与档案访问。

违法收费、偏袒和消极执行作为具体选择与记录存在时，必须伴随真实付款、被跳过案件、证人/证据及可能投诉。NPC 是否接受由其利益、风险和关系决定；不能用“腐败值”自动吞固定比例全部国家收入。复杂司法细节列入 M6，M3 必须先有明确拒绝、复核和公开问责入口。

财政同时区分批准额度、已经承担的承诺、到期付款和实际现金。税单产生应缴义务，缴税才增加国库；国库借款必须有愿意出资的贷款人和到期条件。地方收到中央拨款后才能使用这笔钱，拨款只承诺未到账时不能重复支付。

### B4. 同样的机制如何产生不同制度玩法

| 制度配置 | 具体权限关系 | 玩起来的区别 |
|---|---|---|
| parliamentary 议会制样例 | 首脑任用与信任程序关联；预算需议会；部长由规定的任命链产生 | 首脑必须维持具体票数；小党可用预算支持交换议程。失去信任后按规则进入看守期，不能删掉行政部门 |
| presidential 总统制样例 | 总统与议员分别选任；列明事项需要确认；否决与覆议按固定门槛 | 行政首长可以留任但预算被卡；玩家可缩减提案、谈跨党支持或争取覆议，不能靠解散对方组织跳过 |
| monarchical appointment 君主任命样例 | 君主职位按继承/确认产生，任命权可授给大臣；地方和咨询机构按实际权限配置 | 争取接触与任命者信任更关键；获得任命仍受税收、地方合作和执行人员限制。君主不能隔空征到无登记的粮 |
| federal / autonomous 联邦自治样例 | 中央与地方分别有职位和列举职权；共同事项需各自批准 | 中央可出钱但地方掌握实施许可；地方能拒绝权限外命令。跨区铁路要谈路线、地价、分摊与实际施工 |
| colonial / protection 殖民保护关系样例 | 上级与本地机构分别保留身份；条约/授权列出保留和干预事项 | 外部代表可控制列明事项却缺本地办事网络；必须借助地方机构或投入驻员。名义批准、当地服从和实际控制可以不一致 |

每个可玩制度至少必须确定：首脑和议席如何产生、预算批准路径、普通任免路径、地方权限、紧急权力到期及争议处理。不能只填一个政体名称。历史国家的具体配置另做来源核实，不能把此表当史实套用。

**B 的玩法验收：** 120件许可不能一天全办完；批准500 U预算不改变50 U现有现金；采购未到货不能发放；跨区官员不能代签另一辖区许可；中央拨款未到账时地方项目可获批但无法付款。

## C. Politics：争取、使用和失去具体权力

### C1. 政治舞台中的对象

| 对象 | 实际内容 | 与其他对象的区别 |
|---|---|---|
| parties 政党 | 党员、支部、领导、党团、候选提名规则、筹款和公开纲领 | 组织结构不包含全部选民；支持某党不自动入党 |
| factions 派系 | 围绕领导人、议题或利益形成的党内/机构内合作群体 | 可只保留成员和协议；有独立干部资金时再表现为组织单位 |
| candidates 候选人 | 真实人物、资格、提名、参选职位、竞选承诺和已知经历 | 被提名不等于当选；同一人兼选/兼职须满足规则 |
| interest groups 利益群体 | 有共同处境的人、企业或社团，例如租户、钢厂、伤员家属 | 共享利益不等于已组织，不能自动派出一个能代表所有人的领袖 |
| electorate / support groups 选民与支持群体 | 合法票权、地区、实际处境、收到的信息、对具体候选/议題的判断及参与意愿 | 有诉求的人可能没有投票权，但仍能请愿、组织或资助；人数不等于票数 |
| coalition 联盟 | 各方代表、同一文本、约定职位/议程支持、期限、履行与退出条件 | 联盟摘要不替代实际投票，不直接产生公职 |
| agenda / issues 议题 | 具体问题、受影响对象、候选解决方式、成本、权限、承诺和结果 | “低工资”须落到雇佣范围、工资条款、救济或劳动规则方案 |
| offices 职位 | 真实机构内的可争夺职位、资格、任期、选任与撤换规则 | 职位有具体提名、签署、预算或指挥范围；没有万能政治等级 |

### C2. 政治行为、成本和结果

| 行为 | 玩家具体配置什么 | 条件、付出和等待 | 可能形成的正式结果 / 失败之后 |
|---|---|---|---|
| 组织政党/派系 | 合作者、宗旨、章程、领导产生办法、活动地点 | 发起资格、会场/通信、成员同意；数日至数周 | 成员、职位、会费与具体议程；招不到成员就仍是小团体，不获全国组织网络 |
| 党内提名 | 候选人、目标选区/职位、所需签名或支部背书 | 候选合格且同意、满足党内规则；1–7日 | 正式党候选或被拒；落选可申诉、支持别人或依规则独立参选 |
| 竞选 | 目标选区、议题方案、公开承诺、访问/演讲/印刷安排 | 真实资金、本人和志愿者时间、场所与传播；活动半日至数日，竞选数周 | 收到信息的选民更新判断；形成报名、捐款、到场与未来投票意向，不直接写最终票数 |
| 游说 | 找有相关权力的人，提交证据、方案、修改条款和支持交换 | 可接触渠道、会面时间、材料；对方可能不见或拒绝 | 某议员承诺提案/支持某文本；承诺有条件和期限，未投票前不计正式通过 |
| 政治谈判 | 交换哪些合法议程/支持、何时履行、谁批准 | 各方授权、成本、外部批准；数小时至数日及通信 | 一致文本或谈判破裂；超权限承诺需要回组织批准 |
| 议会提案与表决 | 文本、支出/规则变化、生效日、执行机构 | 提案资格、审议安排、法定人数；委员会/全会数日至数周 | 通过规则/预算或否决；改文本需重新取得对应同意 |
| 选举 | 提名确认、选民登记、投票地点、截止、计票和异议 | 选务经费、人员、可达性与制度资格；固定竞选和投票日程 | 计票确认席位，再按就任日替换任命；无法投票地区按明示延期/缺席规则处理 |
| 组阁 | 首脑候选、部长提名分工、政策文本、支持期限 | 按制度获得信任/任命和必要确认；数日至数周 | 政府职位与权限改变；失败可重谈、少数政府或重选，须按具体规则 |
| 支持抗议/罢工 | 具体诉求、场所/雇佣范围、物资/法律帮助、参与承诺 | 自愿参加、时间、误工、基金、场地/许可及风险；数小时至数日 | 实際到场、停工、救济到账、谈判要求；未参加者不被强行算入 |
| 领导权挑战 | 挑战哪个职位、候选人、失职证据、签名/会议要求 | 章程或罢免规则、召集资格、组织成本；数日至数周 | 重选/罢免程序、保留原任或新任命；挑战失败可能失去党内合作，人物仍可退出重组 |

竞选活动必须经过人、物和传播。付印1000份传单需要印刷服务和配送；只有实际送达且能够接触内容的人获得相应信息；重复相同内容主要扩大未覆盖范围或提醒投票，不能无限堆叠说服效果。一个地方会议容纳200人就不能记2000人到场。

### C3. 选民、议员和群体怎样作政治选择

选民至少关心自己遭遇的具体问题、对候选人的认识、候选方案是否能改善问题、承诺可信度、共同身份/长期倾向和参加成本。收入、物价、伤亡本身不指定“应该支持哪个党”。

推荐的基础判断顺序：

1. 取得自己已知且有资格参与的候选人与议题。未知候选人通过公开信息/接触进入考虑范围。
2. 从近期生活中选最多三个突出问题：例如实际断粮、欠薪、住房被征、征兵期限、地方学校不足；没有严重问题者可以把长期职业、信仰或制度主张排前。
3. 比较候选方案的对象、生效时间、可执行性与可信记录。给所有人泛泛许诺，却没有预算/权限的方案，不等同于已有拨款的地方项目。
4. 结合既有政治倾向和利益冲突选择候选或弃权；差异很小可保持原选择。曾受帮助或失信的具体关系只影响知道此事的人。
5. 在投票日再判断是否有票权、能到场/按规则远程投票、是否愿意承担时间成本；意向未必转成票。

具名议员逐人作决定；普通选民按处境与已知信息相近的群体分布计算。群体内部保留不同倾向份额，不能“一万工人全部同票”。最终整数票数不得超过合法名册；已具名投出的票从同一群体票数中分出，不能重复。公开调查是有误差的估计，正式计票才决定席位。

议员除选区诉求外，还考虑党内合作、承诺、任职责任及个人立场。党鞭可劝说、给予规则允许的提名支持或党内处罚，不能代投。对方能否履约取决于实际掌握的职位和资源；同一项让步不能无限承诺给互斥的各方。

### C4. 基础选制与完整权力形成

第一套可验收选制推荐“单席选区、有效票相对多数当选”，便于清楚解释选区归属。名册截止、年龄/公民资格、参选资格、平票复选与异议期限必须配置。比例代表、两轮和限制选举权制度作为可替换内容规则，见 L；不能假设所有1900年国家都有普选。

组阁样例：议会100席，A40、B20、C40，首脑候选须至少51张赞成票。A与B批准联盟只形成60席的合作可能。实际A40+B8=48则失败；A40+B12=52则通过。之后依规则完成首脑任命，再提名财政部长并取得必要确认；部长在就任日才得到相关职权。

Politics 的可见成果必须落在以下之一：

| 成果 | 成立条件 | 实际改变 |
|---|---|---|
| appointment 任命 | 有效选举/任命/确认及就任边界 | 指定人物占有职位，前任结束相应任命 |
| authority 授权 | 有效职位、法定规则或具体委托 | 哪个人能够提出、批准、签署哪些事项 |
| rule 规则 | 有权程序通过、公布和生效 | 税率、选举资格、劳动标准、许可等具体适用条件 |
| coalition 联盟 | 各方按权限认可同一文本 | 合作和履行义务，未来投票/任命仍独立发生 |
| government control 政府控制 | 占有关键公职并维持制度所需支持，指令能送达且被执行 | 实际能安排的议程、人事和部门工作；不能把“执政党”标签等同全社会服从 |

### C5. 经济、人口和战争怎样变成政治问题

例如食品涨价：住户实际少买粮 → 记录连续未满足的食物需求 → 与邻居/工会交流、收到谁提出的配给或进口方案 → 愿意签某份请愿、捐款或听候选人说明 → 有权代表提案 → 议员投票 → 官员执行。任一步无人组织、信息不可信或成本过高，都可能没有后面的集体行动。

战死消息只先送达家属和有报告权者；公开后，伤员家属可能要求抚恤、军方要求补充、纳税人反对追加税。不同处境的人可以支持不同方案，不能将“战败”直接转换成所有人反政府。

未来接入非正常竞争时使用已有具体对象：争议任命、拒绝交接、命令不被承认、机关停办、实际部署与控制变化，以及对这些事实的知情和认可。政变、叛乱或政治暴力的成功不能由一个按钮/成功率直接转移国家全部权力。深度过程在 M6 增加；基础版先能表现“谁仍在任、谁在服从、谁控制场所、哪些部门停办”的分离，不新增另一套权力总分。

**C 的玩法验收：** 60席联盟48票不能组阁；党内提名不创建公共任命；预算被否决不直接扣产量；同一新闻未传到的地区不提前改判断；兑现住房承诺和仅发表住房口号必须对知情者产生不同选择依据。
