# 分层军事地貌：最小可玩切片

## 范围与入口

仍从原菜单“开始”选择已有合法人物，进入原正式世界。地图模式菜单中的“军事地貌 · 50 / 25 / 5 km”打开同场景内的观察层，不另建游戏、WorldState、人物或时钟。

当前唯一实装地区为 **Continuous 50×50 km + Ridgevale 原生 5×5 km**。50m 外围高度、4m 原生高度均来自原军事归档；5km 概览显示网格为20m，近景才生成焦点周边4m网格。25km是同源连续缩放，不是独立复制的地区。

**这是虚构训练场。没有历史地理配准，没有正式军事部署、单位或车辆控制权。** Ridgevale 是干燥村庄/道路地形，河流位于外围 Continuous；不宣称原生村内有河。村庄细资产主要集中原有中央约800m。不能将显示增强、查询窗口或更密网格称为新测绘精度。

## 安装与操作

资产不进入 Git 大二进制历史。运行：

```powershell
python tools/map/install_region_slice.py
```

需要已认证的 GitHub CLI。安装器从既有草稿资源 Release 下载 `wwo-region-slice-ridgevale-v1.zip`；附件 id **677929012**，11,756,695字节，24个原资产合计13,178,169字节。也可 `--from-zip 本地附件路径`。逐字节复用相同现有文件；拒绝覆盖不同文件；不计算指纹。首次请用Godot 4.6.3打开原工程完成PNG/GLB导入。详细来源在资源目录的README和RECOVERY_SOURCE记录中。

- 50km：完整10×10格区，左键选择5km格。只有标注已安装的Ridgevale可进入原生细地形；其它格明确只有外围概略源。
- 25km / 滚轮：同一地区缩放。左拖平移，右拖旋转，WASD移动观察相机。
- “村庄 / 道路”：近景观察原始房屋、石墙、树木、地表材质及道路语义。
- “步行观察（隔离）”：真实CharacterBody3D、重力和局部地形/建筑碰撞。WASD、Shift快走、右拖看向。这是无武装测绘观察体，**不是正式人物移动、完整战斗控制器或已恢复车辆运行时**。
- “上一级 / Esc”：结束步行或返回上次地区视角、选格。返回正式世界保留原世界实例、人物所在地、正式地图相机和选择。
- F12：保存当前根视口和本观察层的地区/相机说明，不错误引用隐藏的球形相机。没有自动存档。

## 实现边界与预算

FormalWorldApplication暂存TimeControl的暂停/速度，隐藏并禁用原输入层。GlobeRenderer保留缓存但禁用三个旧视口渲染；返回恢复原实例，而非重新启动。观察不调用领域命令，也不取得WorldState引用。

一个后台数据/网格工作线程。每帧最多安装一个块。50km最多100个5km粗块、250m显示步长；原生5km单个20m概览；观察宽度小于1800m才请求最多9个500m/4m细块。碰撞仅焦点±64m所需、最多4块，逐帧安装，不创建全50km或全5km碰撞。步行进入前等真实碰撞；边界未就绪时请求下一安全区并等待，不以高度采样冒充地面碰撞。

静止视口UPDATE_ONCE；没有动画水面、全世界预载或隐藏球形实时渲染。原模型分250m格MultiMesh；树约1800m裁剪，建筑约7000m。原始高度不改；法线/颜色增强只是表现。局部步行启用单个有限距离方向光阴影；远景不运行阴影。

可复用模块单独提交 [wwo-military PR #3](https://github.com/ryoumiyahayato/wwo-military/pull/3)。主仓保留显示用快照；仅preload路径和默认资产根适配主工程。军事仓本身没有可直接启动的完整main/车辆资源，本切片不恢复这些缺失依赖。

## 已完成的有限实机操作

Godot 4.6.3、Compatibility、RTX3050 Laptop、1280×720可见原生窗口。复用既有有限窗口驱动，经真实菜单点击、地区/原生层级、缩放、拖动、4秒物理步行、两级返回及正式世界返回；没有headless画面冒充窗口验证。

共享工作树第4次窗口操作通过：4秒移动约8.7m且is_on_floor为真；同一个WorldState，完整正式持久化快照、人物记录、原相机/选择不变，正式分钟仍为0。返回地区时细块/碰撞都降为0，返回正式世界释放观察层纹理。静止村庄、缩放、拖动和步行P95帧间隔约17.6–17.9ms；首次细层安装出现约61ms单帧。50km/5km静止段也出现约35–37ms P95，不能把各阶段都写成稳定60FPS。

窗口不抢前台，实测focus=false。帧间隔包含等待，不等于CPU/GPU执行时间；Godot process计数为约0.2–3.4ms的阶段末采样。外部采样为游戏进程CPU/工作集，以及包含桌面负载的整GPU利用率、显存、功率和温度，不能称为纯游戏GPU时间。记录位于本地 `local-artifacts/layered-region-20261026-v4/`，不提交截图包或测量平台。

早期第2/3次窗口驱动的滚轮只发pressed而未释放，造成GUI鼠标焦点滞留；这两轮没有步行/返回通过，已保留为失败，不混入通过结论。临时user_dir在引擎初始化后才改会导致shader cache写入失败；改用既有launcher在启动前设置隔离override后不再出现这些错误。仍有原GlobeRenderer锚点尺寸警告，不宣称整项目无警告。
