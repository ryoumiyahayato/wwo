## Decision and scope

PARTIAL_FOUNDATION: bounded automatic camera handoff and existing-world place/political display fixture. Paris/Northern France, Beijing and New York can exercise current point IDs; none has an admitted fine 1900 Local dataset. Paris has several nearby reference cities/ports; Beijing and New York each have sparse points. No modern city shards, admin1, roads, railways, terrain, factories, markets or military icons will be introduced. Unsupported anchors stay Region.

The existing planar renderer and immutable geometry are reused. A Local fixture is a finite subset of the same AEQD chart, with the same camera and cached viewport. This permits an exact handoff with no projection change or crossfade, and no geometry preparation, file read or upload. Entry is limited to a chart neighbourhood to bound metric distortion; it does not attempt to make the large Region disk a fine world map.

Native picking exposed an existing unresolved reference: New York/Washington/US port use `united_states` while current historical political identity is `united_states_1900`. This task does not invent a crosswalk or change that World fact. A selected stable place now survives an unresolved polity; its card displays the original reference and “unresolved”. This is a data gap, independent of camera support. Existing coarse US political map geometry can still be displayed, but its simplified coastline cannot supply accurate Local shorelines.

The same exact-ID audit finds additional unresolved parent references in Belgium cities (`country_bel`), London/Dover/Kolkata and London port (`british_empire`), Vienna (`austro_hungarian_empire`), Tokyo (`japanese_empire`), Buenos Aires (`argentine_republic`). The per-place read-only inventory is `local-artifacts/local-foundation-r1/place-reference-audit.json`. None of these aliases is silently resolved or treated as a current controller, population or market identity.

Actual scale thresholds are 200 m/px entry and 280 m/px exit, with a 25 m/px minimum. The Local circle is 300 km radius; entry anchor must be within 500 km of the Region geographic chart origin, with the full viewport fitting without a clamp on entry. All visible Local points therefore remain within 800 km of the fixed AEQD origin. In the spherical model transverse metric distortion is bounded by `c/sin(c)-1` at `c=800/6371.0088`, approximately 0.263%. Numerical inverse error and source positional accuracy are separate quantities: coordinate rounding in a JSON file is not a surveyed accuracy claim. The circle is a camera boundary, not an administrative/population/economic unit. Pan clamps at the boundary; a coarser zoom releases it without changing the chart or anchor.

Future Military/Economy positions and paths must be longitude/latitude references transformed through this presentation camera. Road/rail/terrain references need dated geometries; 50 km cell identities need a deliberately fixed geographic frame. Camera-dependent IDs must not become persistent world facts. No grid database or fixture-only cell identity is added here.
