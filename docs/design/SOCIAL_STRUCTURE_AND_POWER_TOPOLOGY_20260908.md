# WWO 社会结构与权力拓扑规格

状态：2026-09-08，按用户最后一次收敛后的要求编制的设计规格。研究与仓库基线为 `85c073649e1ed17594f2a41d4f2081feceeabe8b`。本文回答：**谁属于哪里、占据什么位置、凭什么对哪些对象行使什么权力、受到谁制约，以及权力如何转移。**

固定依赖链：WORLD CORE → Spatial World / Stable IDs / Time → Population / Organization → Economy / Politics / Military → Integration。Government 是公共组织与职权配置形成的制度体系；本文不改变该依赖链，不开发代码，不重构运行入口，不设计职业循环。

本文的职位期限、金额、门槛及具名案例是可直接细化的**设计样型**，不是所有国家/年代的共同法律。真实制度资料仅支持明确标注的结构区别；现代合作社、银行、大学和地方自治资料不直接成为1900年开局配置。某个历史国家的具体章程、宪制、任期与权限，仍需按国家和年份填写并核实。

“Power Graph”在本文中指下述社会对象及有类型关系的图示与规格，不提出一个新的世界基础系统。

## 1. 总体 Power taxonomy 与结构

### 1.1 先区分图中的对象

| 对象 | 定义及边界 |
|---|---|
| Person 人物 | 实际占有职位、作出签署或参与表决的人。人物身份、任职身份、个人财产及政治立场彼此独立 |
| Organization 组织 | 有持续集体身份、构成规则和代表方式的集体；是否有独立法律人格另行明确，不能用“是组织”推断 |
| Internal unit 内部单位 | 具有持续人员/职责的部门、分支或委员会。可复用组织结构；需声明它是内部单位还是有独立身份的关联组织 |
| Position 职位 | 归属明确组织/单位的职责位置，定义席位、任用和权限。职位存在不要求当前有人占据 |
| Office 制度职位 | 本规格中是具有持续制度身份、任用/交接规则的 Position，如议席、部长、董事、校长。不是与 Position 并行保存的第二份同一职位 |
| Appointment 任职 | 某人物在明确时间内占据某职位的事实；可为正式、代理或限职责兼任，不等同雇佣关系 |
| Membership category 成员类别 | 普通、表决、候补、代表、赞助、附属等成员身份；各自有资格及权利。雇佣、股权、选民资格通过正式登记关联，不全部改写成组织会员 |
| Decision body 决策机关 | 按特定成员/席位与程序形成集体决定的机关。可由内部单位承载，如董事会；已有议会组织不再复制一个同名议会实体 |
| Polity 政治实体 | 将宪制、公共职位、辖区与被承认的公共机构关联起来的既有政治身份；本身不是一个自动命令所有机构的超级首长 |
| Basis 权力依据 | 章程、法律、任命、财产权利、成员规则、协议、裁决、有效委托或被记录的事实服从安排。依据必须能追到具体记录和适用版本 |
| Domain object 对象引用 | 合同、账户、生产设施、部队、资产、案件、提案及 Spatial 地点等；被引用不表示获得操作权 |

**内部包含、治理控制、业务往来、法律承认、实际服从是不同关系。** 树形图只表达组织内部构成；箭头上有具体关系名时才表达该关系授予的内容。

股东并非董事；董事会拥有的集体批准权不能由每个董事各用一次；主席主持会议不自动获得集体决定权。所有者和选民也可直接拥有财产权利/投票资格，不为每个普通选民或股东虚造一个日常职位。

### 1.2 Power 分类：17类权力，不存在总权力数值

下列编号用于读表，不是17个万能开关。前15项覆盖用户指定范围，另外明确裁判/认定与提出/议程权，防止将它们错误归入一般管理、规则制定或投票。每次真正适用都必须有1.3的具体作用范围与依据。

| 编号／类型 | 权力实际允许什么 | 典型适用对象 | 不能由它自动推出 |
|---|---|---|---|
| P01 ownership / governance 所有权治理 | 依正式权益参与选治理机关、改变章程、决定保留重大事项 | 个体、合伙、股份、合作社、国企及集团；某些成员制银行和媒体 | 直接支取组织账户、占用客户资产、绕过受托限制；慈善受托人不是财产所有者 |
| P02 appointment / removal 任免 | 提名/任命/撤换列明职位的任职者；其中提名与最终任命可分属不同权力 | 各类正式组织，尤其政府、公司、党、军队 | 任命别人后自动使用对方全部权限；有任命权必然有随意免职权 |
| P03 command 指挥 | 向列明的下属职位、部门或部队发特定类型指令 | 军队、行政、企业、党务、办学与内部管理 | 因军衔/部门级别高而无限发令；指令天然合法或一定被执行 |
| P04 budget approval 预算批准 | 核准用途、总额、期间、调剂条件及保留事项 | 公司治理机关、议会、政府、大学、工会、慈善、党 | 产生现金、自动签合同、每名委员各用完整额度 |
| P05 spending / commitment 支出与承诺 | 在已获准范围承担采购、雇佣、借款等组织义务，或批准具体支付 | 经理、财政官、采购官、军需、银行授信角色等 | 突破预算、重复占用共同限额、实际付款必然成功 |
| P06 rule-making 规则制定 | 制定列明对象及事项的公共规则、章程或内部规则 | 立法机关、授权行政机关、股东/会员大会、学术与宗教机关 | 内部纪律变成公共刑法；党章自动改变国家宪制 |
| P07 veto 否决 | 阻止某类决定成立、生效或继续，类型须列明 | 总统/君主在特定制度下、议院、委员会、保留权机构 | 自动提出替代决定、撤销历史事实、一般监督权等于否决权 |
| P08 supervisory 监督 | 要求报告、检查、质询、提出纠正或启动问责；有撤销权时须另授 | 议会、审计、董事会、监管、上级机关、受托人 | 直接代签业务、修改被监督者记录、自动罢免负责人 |
| P09 representation / signature 代表与签署 | 为列明的组织/政治实体签署指定类别文书，形成可归属的意思表示 | 经理、部长、谈判代表、出版人、校长等 | 文书内容已获准、组织有资源、签章人拥有全部批准权 |
| P10 jurisdictional 管辖 | 将某机关的特定公权/制度权适用于列明地域、主体与事项 | 公共行政、司法、警察、税务；宗教/学术内部管辖需另标性质 | 一种管辖覆盖所有事项；成员纪律等于对所有居民的公共权力 |
| P11 enforcement 执行强制 | 依据有效命令/裁决，对指定对象采取列明强制措施 | 执法机关、军事占领相关职务；内部保卫仅限其依据范围 | 持有武器即可合法征税、审判或没收；实际控制等于法定授权 |
| P12 delegation 委托 | 将已持有且可委托的具体职权，限范围授给他人/职位 | 需要代理或分工的各种组织 | 自我扩权、转授保留事项、把不可再委托权继续转授 |
| P13 information-access 信息访问 | 查看、索取、审核或披露特定信息类别 | 董事、审计、经办官、编辑、指挥、监管、成员查询权 | 全部私密信息可见；访问权自动包含修改或公开权 |
| P14 political nomination / voting 提名与投票 | 提出合格候选、在指定选举或公共/组织表决中投有效票 | 选民、党员、代表、议员、股东、会员、治理席位 | 提名即任命、党内多数即公共权力、联盟声明即已投票 |
| P15 emergency 紧急权力 | 在明确条件与期间启用列明临时职权、替代路径或优先关系 | 公共紧急机关、依法军事接替、有限组织应急授权 | 空白支票、受权者自行永久续期、把全部平常规则删除 |
| P16 adjudication / determination 裁判与认定 | 对指定案件、资格或争议作具有明确效力的判断 | 法院、依法设置的裁决机关、获得具体资格认定权的专业机关 | 制定所有一般法律、代执行机关实施强制；专业认定不能成为公共司法权 |
| P17 proposal / agenda 提出与议程 | 提出指定事项文本、要求按规则受理、召集或安排指定机关议程，具体operation分别授予 | 厂长、经理、部长、议长、会员代表、组织领导 | 有权提案就能强迫立即表决、自己批准提案、改变合格参与者 |

权力的“强弱”表现为对象更多、辖区更广、批准门槛不同、保留事项更少、能授任的职位不同，而不是给这些类别乘一个总系数。经济实力、声望、武装实力和信息覆盖会影响能否取得或实际运用权力，但不存入本表成为法定权力数值。

### 1.3 每一项 Power 的必填结构

| 字段 | 规定 |
|---|---|
| holder | 具体 Position、Decision body、具有该项资格的成员角色，或明确受委托的 Person；必须能够确定实际行动者。职位权不复制成任职者永久个人权 |
| represented entity | 本次代表的组织、政治实体或本人；执行单位与承担外部义务的实体可以不同，必须明确 |
| operation | 具体动词和对象类别，如“提名财政部长”“批准项目P预算”“签公司采购合同”；不得只写“管理”“控制” |
| target scope | 具体职位集合、机构、部队、案件、项目、合同/资产类别；成员范围和对象范围可交叉约束 |
| spatial jurisdiction | Spatial已有地点/地区等引用及包含、排除规则；无地域条件写“无地域限制但仍受对象限制”，不能用空值猜“全球” |
| subject-matter jurisdiction | 税种、专业事项、公共职能、作战任务、党内事务、编辑栏目等；与地域范围同时成立 |
| amount / quantity limit | 有则写单位、期间、单项/累计口径、共同承诺范围；没有则显式“不适用”。额度是权限上限，不是资金库存 |
| valid_from / valid_until | 使用既有世界时间；开始含、结束不含；明确任期/任务条件能否提前结束 |
| basis | 具体依据、版本、授权者及必要程序结果；说明其属于哪个法制、章程或事实服从安排 |
| revocable | 谁按何种程序撤回、可否部分撤回、何时生效；“可撤”不是任何上级随时可撤 |
| delegable | 是否允许，接收者资格、可转授范围、最大层次/禁止再转授及保留事项 |
| exclusive or concurrent | 独占、各自独立并行或必须共同同意；必须写明同一目标/事项/时段的冲突和优先规则 |
| additional constraints | 提案版本、前置批准、确认、回避、双签、用途限制、合法状态与申诉途径 |
| accountability | 向谁说明、谁能审查、谁能启动何种责任后果；委托通常不消除委托者原有监督责任 |

同一制度内的基础依据来自已成立的法律/章程及成立事实，不要求无限追溯到另一个尚不存在的任命者。初始社会配置须列出这些成立依据；之后的变动引用它们或有效修改结果。

**完整实例：公司采购签署权。** holder=采购处负责人职位；represented entity=甲公司；operation=签维修材料采购承诺；target scope=甲公司工厂A的项目P；spatial=工厂A所在place及列明交货地点；subject=维修材料；limit=项目期间累计100 U，所有受委托采购人合计；valid_from=T0，valid_until=T0+30日；basis=董事会项目决定＋经理可委托条款＋采购任命；revocable=经理可撤该委托，董事会可依程序改项目；delegable=否；concurrent=可与经理共同拥有签署资格，但共享100 U上限；前置=项目有效、文本一致、无回避冲突；accountability=采购向经理、经理向董事会负责。签80 U后，另一人不能再以同一项目签30 U。组织侧只规定上限；已经承担多少义务查询相应合同记录。

### 1.4 法定权、内部权、争议主张与事实服从

每项依据标明适用秩序：公共法制、组织章程、合同/财产、成员自愿约定或事实服从。还要区分“按该依据有效”“被谁承认/争议”“实际是否执行”。这三个问题分别回答，不能以一个合法/非法布尔值包办。

犯罪首领可以对自愿或被迫服从的成员形成事实命令链；这不生成国家许可。军事接管者可以控制某机关场所，而原政府仍主张任命权。争议双方的主张可以同时记录，但不能在同一公认程序中都无条件当作唯一有效任职者。正式签署应说明采用的依据与承认条件；强制行为的实际发生由相应领域处理，不能因为无法定授权就把现实冲突从世界中删掉。

## 2. Power relation taxonomy：关系与“上级”的确切含义

### 2.1 权力关系表

关系本身同样须具备来源、目标、适用范围、依据与有效时间。关系成立只能产生表中列明的后果。

| 关系 | 起点 → 终点 | 确切含义与边界 |
|---|---|---|
| grant 授权 | 有授予资格的机关/职位/规则 → 权力持有者 | 建立1.3所定义的一项职权；授予者必须有该授权能力，不能只因parent相连而授予 |
| appointment 任职设立 | 有效任命决定 → 人物占据职位 | 改变人物—职位关系；职位固有权力经有效任职供该人物使用，不把职位权私有化 |
| approval 批准 | 批准机关 → 特定事项/文本版本 | 使该事项满足一项成立条件；不是替代签署，也不是给该文本之外的事情开权限 |
| confirmation 确认 | 确认机关 → 提名/任命/条约等结果 | 列明前一决定是否须经确认才成立；确认者不因此获得原提名权 |
| veto 否决 | 有否决权者 → 指定决定类别 | 区分绝对阻止、可覆议的暂停、附期限审查；明确覆议者和门槛，不能默认永久锁死 |
| supervision 监督 | 监督者 → 被监督机构/事项 | 要报告、调查或启动问责；若可撤销、叫停或免职，必须另有具体权 |
| reservation 保留事项 | 章程/法律/上级有效授权 → 被保留的事项集合 | 下放其他职责时，列明这些事项仍由指定机关决定；不是资源库存预留 |
| delegation 委托 | 现持有者 → 委托接收者 | 在可转授部分内建立范围更窄或相等的派生职权，保留原依据链及撤回办法 |
| exclusive authority 专属权 | 制度规则 → 持有者＋某范围 | 同一依据秩序内，该目标/事项/时段只有一个最终决定者；不排除别人有提出或监督权 |
| concurrent authority 并行/共同权 | 制度规则 → 多个持有者 | 必须区分“各自可以单独行动”与“必须共同批准”。同词不得混用 |
| emergency override 紧急替代 | 有效紧急决定 → 列明普通职权/程序 | 只在范围和期限内暂停或替代指定路径，保留未受影响的权利及期后恢复规则 |
| jurisdiction overlap 管辖重叠 | 两项辖权 → 同一地点/对象或部分交集 | 重叠是需要解释的事实，不自动构成上下级。区分事项不同、共同许可、优先规则、未决争议 |
| accountability 问责 | 任职者/机关 → 问责机关/成员 | 规定说明责任、调查和责任认定途径；可被问责不等于对方能代做所有决定 |
| succession 继任 | 已生效继任规则＋空缺事实 → 下一合格任职者 | 确定顺位、资格、是否正式继任或仅代理、是否需确认；不是继承全部私人/组织财产 |
| temporary command assignment 临时配属 | 有权上级 → 接收指挥职位及指定部队 | 时段内转移特定作战指挥范围；行政、纪律、人事、补给和财产关系逐项注明保留或变化 |

附加结构关系：`contains`只表达内部组成；`affiliated_with`表达关联；`ownership_reference`引用持股；`reports_to`表达特定报告责任；`recognizes`表达对某主张的承认。这些都不能不经上述规则直接变成无限权限。

### 2.2 “上级”至少有七种不同含义

| 被称为上级的原因 | 它能直接做什么 | 它仍可能不能做什么 |
|---|---|---|
| 结构上包含下级 | 仅说明组织构成；能否重组需另有P06/P02 | 代下级签合同或阅读全部材料 |
| 任免上级 | 任免列明职位，遵守免职和确认限制 | 代法官裁判、代编辑签稿、代董事会投票 |
| 行政指挥上级 | 下达其职责范围内的内部任务 | 改公共法律、调用不在其下的部队 |
| 作战指挥上级 | 对配属部队下任务、调动和优先安排 | 自动改变军饷、编制归属或高级军官任命 |
| 预算批准者 | 批准用途、额度、调剂和保留事项 | 自动使用受款组织账户、决定所有专业事项 |
| 监督/司法审查者 | 要求说明、依法审查，具有另授权时叫停或撤销 | 直接接任被监督机构领导 |
| 出资/联盟主导者 | 用真实股权或协议中的权利影响决定 | 把子公司、盟党或自治成员改成完全服从的部门 |

因此，查一个组织的parent只能得出结构路径；要判断某个人能否命令某对象，必须查具体指挥关系和职权范围。拥有任免权不自动拥有被任命职位的权力；可以通过合法换人改变未来决策者，但不能冒签那个人已经拒绝的事项。

### 2.3 重叠、联合批准与冲突

1. 同地不同事项：中央海关、地方警察、公共卫生机关可以并存，各查事项范围。
2. 同一项目多项许可：地方土地同意与中央铁路审批可以都必需；两者是“且”，不是先拿到任何一个即可。
3. 同事项各自独立：法律允许两个机构分别受理不同案件或分别征不同税时，明确对象划分与禁止重复处分规则。
4. 同事项有优先权：优先关系必须来自具体依据，只覆盖其列明交集。不是“中央总赢”“军人总赢”或“最后写入者赢”。
5. 仍有争议：保留双方主张、暂时有效安排和有权解决争议的机关。需要唯一公共决定的事项不得偷偷选一方；各方实际服从和强制行为另行记录。
6. 不允许循环再委托来扩权，也不允许以新任命逃掉原权力的地域、金额和期限限制。
7. 联合签署是形成一个承诺所需的多个签署；多人独立签署是多人可分别发起行为。二者都不能重复耗用同一个累计额度。

## 3. 各组织结构图与关键 Position 权限表

### 3.0 读图与任期规则

图例：O=组织；U=内部单位；B=集体决策机关；P=职位，其中具有稳定制度交接身份的职位亦为Office；M=成员/资格类别。缩进仅表示构成，带文字箭头才表示授权等关系。“关联”不等于parent。

下表任期是设计样型，按真实国家/章程配置时可替换数值，但不可省略空缺、代理和免职路径。任何表中代理都须有明确任命或预定规则，不因“副职”“资历最高”就自动获得完整正职权。代理不得延长自己的期限，原任被免不影响合法已经成立的外部承诺。

所有表中“代表”指代表行为归属；批准机关形成组织决定，由指定自然人按程序出具/认证文本，不能要求一个无人物身份的委员会凭空签字。

### 3.1 企业：六种不同构成

#### 3.1.1 个体经营

```text
  └─ 店铺管理U（有雇员才设置）─ 店长P、受托店员P
```

```text
├─ 受聘经理P（可选）
└─ 业务部门U

外部：合伙协议、合伙人个人责任条件、雇佣、债权人、客户
```

| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 执行合伙人／合伙 | 合伙人按协议选定/撤换；加入新合伙人与剥夺资格分别按协议程序 | 样型2年；空缺由会议限期指派代理；资格退出不当然清除既有责任 | 合伙主体；对外责任归属由具体制度确定 | P02经理任免、P03业务指挥、P05/P09约定业务；接纳新合伙人、重大负债由B保留 |

| 受聘经理／合伙 | 执行合伙人在授权内任免；重大人事可由B保留 | 委任期；原任结束后由执行合伙人安排限权代理 | 合伙主体 | P03/P05/P09约定项目；不因受聘成为合伙人 |

#### 3.1.3 股份公司

```text
股份资格M ──票权── 股东会B（甲公司O的治理机关）
                         │选任
甲公司O                  ▼
├─ 董事会U/B ─ 董事席位P、董事长P
├─ 总经理P
├─ 财务U ─ 财务负责人P
├─ 采购U ─ 采购负责人P
├─ 生产管理U ─ 厂长P ──引用── 生产设施
└─ 监督机关B或审计职位P（按所选章程，不能假定处处有监事会）

外部：股东、雇员、工会、子公司、债权人和监管机关各有不同关系
```

| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 董事席位／董事会 | 股东会依票权选任/撤换；特殊席位的提名与确认另列 | 样型3年；空缺补选；临时补缺仅在章程明许时由董事会提名且待确认 | 参与公司治理的席位；单独行动不等于董事会 | P14董事会投票、P13治理资料、P08监督；B集体持P02任经理、P04投资预算及保留事项 |
| 董事长／董事会 | 董事互选、董事会撤换主持职；其董事资格仍由原产生程序决定 | 随董事任期内1年；副主持仅依会议规则代主持 | 董事会认证与列明外部职责 | P17议程/召集、P14作为董事的一票、P09认证决定；无额外票或决定票，除非章程明确 |
| 总经理／公司 | 董事会集体任免 | 委任至撤换/任期末；B指定限权代理；不得自己任命永久继任 | 甲公司 | P03内部经营指挥、P02下级岗位、P05/P09范围内承诺、P12委托；P04保留投资不能自批 |
| 财务负责人／财务U | 经理提名，样型由B确认；B或依授权经理免职 | 委任期；代理由有权任命者指定，需具备支付资格 | 甲公司 | P05列明支付/融资承诺、P09相应签署、P13财务资料；不得以掌管账务冒充预算批准机关 |
| 采购负责人／采购U | 经理在P02范围内任免 | 至委托/任职结束；经理安排限范围代理 | 甲公司，不是采购员个人 | P05/P09采购类别、设施、项目及累计额度；不可自行采购集团其他公司资产 |

### 3.2 Government：中央、议会、行政、司法、地方、殖民/保护关系

以下职位表采用一个明确基础样型：议会确认政府首脑，首脑提名部长并按规定确认；议会任期4年；地方自治另有选任；法官的裁判独立且免职需专门责任程序。总统、君主任命和军事接管的替代权力边见第6节，不把这个样型当作所有国家的默认史实。

| 摄政／国家元首机关 | 由既定规则指定人选，或规定的议会/王室机关选任；开始与结束均由该规则认定 | 仅在未成年/失能条件内；到条件消失即交还；空缺依同一程序补位，不能自任继承人 | 代行君主Office的列明职责 | 仅承继摄政条款列出的职权；改变继承规则、处分特定财产或永久改制可列为保留事项，不因代行而取得全套君主权 |

#### 3.2.6 殖民与保护机构：必须分成两种构成


| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 总督／殖民行政 | 上级指定机关任免；需确认时列明 | 样型5年或受委任期；代理由委任规则指定 | 指定殖民公共主体或上级主体，不能含糊混用 | P02/P03/P09/P10及明授P06/P07/P11；哪些法案须上级确认、地方保留事项须列出 |
| 驻保护代表／保护方派出机关 | 保护方有权机关任免 | 委任期；保护方补位，临时代办仅承继明列权 | 保护方；只有条约明授时代表本地特定对外事务 | P08/P09/P10及条约列明P07；驻在当地不自动拥有内政和司法权 |
| 本地首脑／本地机构 | 本地继任/选任规则，保护方是否确认须写进条约 | 本地任期/继承规则；代理遵同一依据 | 本地政治主体 | 保留的P02/P03/P06/P09/P10；转交的外交/军事事项不得凭“本地首脑”称号单方行使 |

殖民、保护、租借、军事占领不能作为同一个“上级国家ID”处理。须分别说明谁依法/依条约主张什么、谁被当地承认、谁实际上控制何处。

| 司令／陆军或战区机关 | 有权军政任命者任免；资格及确认按军制 | 委任或任务期；空缺按经批准继任顺位代理，需补正式任命 | 指定军事指挥机关/公共主体 | P03列明部队与任务、P02列明军官、P12/P15限权应急、配属权；不得自动征用全部地方财产 |
| 军长/师长／所属指挥机关 | 指定上级人事权者任免，作战配属不自动改变该任命者 | 委任期；有明示顺位的副职代理，超范围需上级确认 | 本级机关对指定部队的指挥 | P03实际指挥范围、P13对应情报、P12允许的任务分派；只管理当前配属和本权限覆盖对象 |
| 参谋长／参谋U | 指挥官提名、军制规定任命者决定并撤换 | 委任期；参谋副职仅按规则代理 | 指挥机关参谋职责 | P13情报/计划、P03限参谋分工、P09代传已认证命令；没有自动独立作战指挥权，另授才可 |
| 军需负责人／军需U | 后勤或本级有权任命者任免 | 委任期；代理须另具支付/采购/领取资格 | 指定公共/军需主体 | P05/P09补给承诺、P03列明保障人员、P13物资信息；无当然攻击命令权 |
| 军医主管／医疗U | 医疗任用机构任职，军事行政任命和专业资格分别满足 | 委任期；合格医疗人员才可代理专业职责 | 医疗单位的专业职责 | P03医疗编组、P13限定医疗信息、专业分诊/适役意见的列明权限；不因知道伤员信息取得部队作战决定权 |

軍衔是资格/礼序/任用条件，不是自动的Power grant。行政隶属可以不变而作战配属改变；参谋、联络、协同与支援不等于指挥；上级下任务不等于接收者已有装备、弹药、可通路线和能执行的人员。

### 3.6 银行

```text
银行O
├─ 股东会或会员大会B（按股份银行/合作银行选择）
├─ 董事会B ─ 董事P、董事长P
├─ 行长P
├─ 授信委员会U/B ─ 审批委员P
├─ 出纳/结算U ─ 授权签署职位P
├─ 检查/审计U ─ 监督负责人P
└─ 分行U或子银行O ─ 分行/子行负责人P

M：股东/合作会员；存款人和借款人首先是合同相对方，不因存款成为治理会员
外部：监管机关、债权债务、担保、代理结算、母子公司治理等关系
```

| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 银行董事／董事会 | 股东/会员程序选任与撤换 | 样型3年；按原程序补位；临时补缺不得规避资格 | 银行治理席位 | P14/P08/P13；B集体P02行长任免、P04业务额度和保留授信规则；不能个人提款 |
| 行长／银行 | 董事会任免 | 委任期；B指定限权代理 | 银行 | P03/P02管理、P05/P09明授银行承诺、P12委托；客户存款相关义务仍由真实合同约束 |
| 授信委员／授信B | B依资格任免；关联交易必须回避 | 固定委任期；缺员不够法定人数时不能由行长一人冒充委员会 | 银行特定授信决定机关 | P14审批票权，B持P05具体信用批准；关联、额度、抵押条件与复核程序明确 |
| 分行经理／分行U | 行长在P02范围任免；子银行经理由子银行治理程序产生 | 委任期；对应任命者定代理 | 分行无独立人格时代表银行；子银行代表自身 | P05/P09指定客户、地区、品种、期限和额度；扩大地区客户与跨限额要另批 |
| 检查/审计负责人／监督U | 董事会或章程指定独立机关任免 | 样型3年；任命机关补缺，不由被查分行经理撤换 | 银行监督职责 | P08/P13、列明P07暂停异常事项；不能把审计信息访问当作转账权 |
| 结算签署员／结算U | 人事任用＋明示签署授权；撤职和撤授权可分别发生 | 两项有效期间交集；代理须具双签/复核资格 | 银行 | P09/P05已获批支付；授信批准、签署和实际清偿能力分别判断 |

银行仍保留企业治理，但不能以“公司经理权限”覆盖存款人、授信委员会和独立监督的所有区别。BIS资料支持区分董事会、管理层及监督控制职能；其现代职位名称和监管模型不强制用于1900年样型。[BIS银行公司治理原则](https://www.bis.org/bcbs/publ/d328.htm)

```text
出版/媒体组织O
```

|---|---|---|---|---|

### 3.9 教会与慈善：宗教管辖与财产受托分开

```text
宗教共同体O
├─ 教义/教务决策机关B
├─ 宗教领袖P
└─ 地方会众O/U ─ 地方宗教负责人P

层级样型：上级教务机关 ──宗教任命/纪律── 地方负责人
会众自治样型：地方会员大会 ──选任── 地方负责人；总会只有加盟章程授予的权力

├─ 执行负责人P
└─ 学校/医院/救济分支U或独立机构O
```

M须分别列信徒/正式会众/具有选举资格成员/神职/宗教代表，以及慈善受托人、志愿者、捐赠人和受益人。捐钱、接受服务、信教都不自动产生同一种治理票权。宗教Office与慈善受托Office可以由同一人兼任，但依据和职责不混合。

| 慈善执行负责人／慈善O | 受托治理机关任免 | 委任期；B定限权代理 | 慈善主体 | P03/P05/P09宗旨内的具体事务、P12有限委托；不可把慈善财产作为创设教会或自己的自由财产 |

英国慈善监管者将受托人描述为共同负责治理与管理方向的人，支持“受托治理不同于私人所有权”的结构区分；具体宗教体制与适用法律仍须另配。[Charity Commission：受托人的职责](https://www.gov.uk/government/publications/the-essential-trustee-what-you-need-to-know-what-you-need-to-do-cc3)

### 3.10 地方势力：先辨认它究竟是什么

“地方势力”不是一种能获得整省控制权的Organization。至少允许三种构成：

```text
甲：地方名望人物Person
    ──关系/引荐/合作承诺── 地主、议员、会长等Person
    各人各自持有本人的Position；整张人际网不自动形成一个可签约主体

乙：地方协会/宗族共同管理组织O
    ├─ 成员/代表大会B ← 确有共同治理资格M
    ├─ 会长/族产管理者P
    └─ 地方分支U
    ──引用── 共同财产/救济等限定对象

丙：地方自治机构O或地方武装O
    分别使用公共机构或军事结构，不能借“地方势力”混合两类权力
```

| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 地方协会会长／协会 | 成员大会选任/罢免 | 样型2年；理事会任限期代理并补选 | 协会 | P03成员事务、P09被授权声明/协议、P14推荐、P12有限委托；不能代表未加入的全部当地居民 |
| 共同财产管理者／共同管理O | 权利成员依共同财产/创设规则选任/撤换；长幼或血缘不默认产生任命权 | 样型3年；原权利机关指定代理 | 共同管理主体/明确权利人集合 | P05/P09限定财产事务、P13账目访问；处分本金、改变受益范围须保留机关批准 |
| 地方协调代表／明确合作B | 各参加组织依自身程序委托同一代表 | 协议期；各方可按条款撤回自己的范围 | 每次列明委托方，不能笼统“代表全地方” | P09共同事项谈判；没有附带公共P10/P11 |
| 地方武装负责人／独立武装O | 依明确公共任命、成员选任或事实服从来源产生 | 任务/委任期；按该组织明确接替规则 | 该武装及有依据的委托主体 | P03内部指挥；公共P11/P10只有另有有效授予才存在 |

名望人物可以通过关系影响别人是否支持某项任命或提案，但“有声望”不能直接成为P02/P04。若其同时是市长、银行董事和协会会长，图中是一个Person连接三个独立Position，而不是一个地方领主总权限。

### 3.11 犯罪组织

```text
犯罪组织O（存在的集体；公共法承认状态另列）
├─ 首领P
├─ 核心议事B（确有共同决定机制时设置）
├─ 分组U ─ 分组负责人P
└─ 临时代表P
M：核心成员、一般成员、附属成员；受胁迫者/交易对手/受害者不能自动记为自愿会员
外部：合作协议、依附/冲突、控制主张；合法企业若有关联仍有自身身份和职位
```

| Position／所属 | 产生与任免者 | 任期、空缺、代理 | 代表谁 | Power及对象、限制 |
|---|---|---|---|---|
| 首领／组织 | 成员认可、核心议事或其他明确的事实服从安排；记录谁能撤回承认，不虚构合法公共任命 | 依内部规则/事实持续；空缺可能继任或争议，不默认继承人获得全体服从 | 该组织内部及其真实对外表示，不代表国家 | P03内部事实指挥、P02内部角色、P09对外表示、P12委托；不因此具有合法公共P10/P11 |
| 核心议事席位／内部B | 明示内部资格/认可程序 | 随资格或约定期；空缺由该认可程序补位 | 组织内部共同决定 | P14内部表决、P08内部问责；其结果不改变外部法律许可 |
| 分组负责人／分组U | 首领或内部B按实际规则任免，记录服从是否变化 | 任务/委任期；继任者需满足同一认可规则 | 组织的明确范围 | P03指定成员/任务、有限P09；不同组织合作不自动成为上下级 |
| 对外代表／组织 | 有内部授权者委托、撤回 | 特定事项到期；替换代表不替换组织身份 | 该组织，仅在确有授权的范围 | P09指定协议；若兼任合法企业职位，必须使用企业的另一套授权，不能混用 |

这里只定义内部组织与公共合法性不同、名义命令与实际服从不同的结构。它不提供犯罪实施办法。违法行为是否发生、形成何种财产/人身后果及谁可追责，由相应领域处理；不能从“犯罪组织获批某事”推导“国家承认该事”。

### 3.12 跨所有 Position 的共同约束

- 同一Person兼任：保留各份任命；每次行为选定身份；利益冲突和禁止兼任按具体职位对规定，不能把全部权力求并集。
- 职位空缺：职位和常设职权继续存在但无人可使用；代理必须有自己的有效依据。机关成员不足法定人数就不能作集体决定。
- 职位改名：不改变历史身份；职位拆并须指明旧任终止、哪部分职权保留、谁合法补位。
- 会员权与职位权：普通会员可以凭资格投票，而无需一个虚构干部职位；退会不必然消灭无会员要求的外部任职。
- 集体机关：席位规则须明确资格、人数、法定人数、权重、回避、弃权、平票、确认与否决；主席签发只认证有效决定。
- 外部代表：内部单位有经办职位不意味着有独立法律人格；对外承担义务者必须在授权中写明。
- 提出与议程：各表中“提出、召集、议程”的文字分别对应P17的具体operation；“提名、投票”对应P14。前者不能由后者或parent自动推导，也不因表中简写而合并为同一授权。

## 4. 五条四阶段权力路径

四阶段分别确认：谁有资格提出；哪个机关决定事项成立；谁能代表主体承担外部承诺或签发有效命令；哪个实际执行者有自己的执行职责。阶段可以由同一人物承担，但必须分别找到依据。认证/传达不能替代集体批准；组织批准也不能替代外部相对方的同意。

### 4.1 公司扩建

```text
厂长P：提出工厂A扩建P                  [提案资格，目标=绑定设施]
     ↓ 经理组织正式提案
董事会B：批准项目、用途、总承诺上限     [P04；必要股东保留事项先获股东会批准]
     ↓ 决定授权给“经理职位”，不是每位董事
当前经理Person以经理P身份签合同         [P05 + P09；代表甲公司；绑定批准文本]
     ↓ 供应商以自己的有效代表同意
施工企业执行／财务按有效义务处理付款     [各自职责；Economy核验真实资源和合同]
```

厂长只提出，B集体批准，经理代表甲公司，承建方代表自己。换任经理后职位授权可以继续；若决定特指某个人，则须按变更程序改执行者。常规维修已有常设项目授权且未超限时，不再召开董事会；仍需有效代表及业务条件。

### 4.2 政府预算及具体采购

```text
部门首长P提出部门需求 → 财政部长P提出预算案             [提案范围]
     ↓
有权议院B及制度要求的其他批准/确认者                   [P04/P06；各自门槛]
     ↓ 依法公布/认证者签发预算决定                     [P09认证，不是采购合同]
授权部长/采购官P签具体采购承诺                         [P05/P09；代表指定公共主体]
     ↓
供应方签约；采购、验收、财务人员各按职责执行             [资源和履约另核验]
```

议会的预算批准与政府采购签约是两个不同对象，不能用一次“签署”混掉。预算内部已经给予的常规支出授权允许直接进入具体承诺环节；新增税种、越预算、保留项目不得跳过制度程序。

### 4.3 军事调动与临时配属

```text
原指挥官/参谋提出配属建议                  [提案职责]
     ↓
有command assignment权的上级职位批准      [目标部队＋作战事项＋期限＋行政保留]
     ↓
该上级的有效任职者认证配属命令              [明确发令依据与送达/生效规则]
     ↓
接收指挥官获得限时作战指挥范围
     ↓
接收指挥官下达具体调动命令                  [P03；不是再次决定配属]
     ↓
师长/部队执行；Military和Spatial核验可行性
```

日常任务若在既有指挥授权和任务约束内，指挥官直接发有效命令即可，不必逐令请求最高统帅审批。调出授权部队、转授保留指挥权、跨越任务范围或军事介入民事管辖，需要另有批准。参谋代传应显示原发令者，不能把代传变成参谋自己的P03。

### 4.4 工会罢工与和解

```text
分会负责人P提出明确雇佣范围的罢工事项
     ↓
有资格会员/代表机关B批准                  [P14 + 章程保留决定；可附总会资助批准]
     ↓
有委托代表P签发组织通知/对外要求          [P09；代表工会，底线/期限明确]
     ↓
成员分别确认参加 → 相关劳动安排发生变化   [不以组织授权代替个人参与事实]

和解：雇主代表 ↔ 工会代表达成同一文本
       ↓ 各自所需批准满足
       ↓ 各自有效签署
       ↓ 合同/劳动条款依覆盖范围生效
```

工会可以给负责人组织行动的权利，不能由此取得雇主的人事指挥权或对全体员工的强制停工权。已经有明确谈判授权的代表可直接签范围内和解；低于授权底线、扩大覆盖或作出新重大义务时，回原批准机关。

### 4.5 党派联盟

```text
A党有权代表P提出协议版本 ──谈判── B党有权代表P
                ↓                         ↓
           A党批准机关B                B党批准机关B
                └────认可同一版本─────────┘
                            ↓
                  双方代表各以本党身份签署 [P09]
                            ↓
                 联盟承诺成立，约束协议各方
                            ↓
         各议员依本人的公共议席实际投票；国家机关依法任命
```

联盟协议的“执行”首先是履行合作承诺，不是直接修改公职。党主席持签约权，也不能保证每个议员实际投票。已批准的短期议题合作可由常设谈判授权直接签；组阁职位分配、排他联盟或改党纲若属保留事项必须回党内机关。

## 5. Power Transfer：来源、边界、终止与残余权

### 5.1 十一种转移的完整表

| 转移 | source → recipient；power type | scope与basis | effective boundary及expiration | revocation | 原持有者保留什么 |
|---|---|---|---|---|---|
| election 选举 | 合格选民/会员形成的有效结果 → 当选Person占据指定Position；P14形成结果，职位带来的P02等由原制度提供 | 指定席位；名册、选举规则、计票及确认依据 | 结果确认且到就任日；至任期终点/合法失格等 | 罢免、失格、有效重选等明定程序；普通败选对手无撤回权 | 前任就任边界后失去该职位权限；可能保留其他职位、成员权或明确看守权 |
| appointment 任命 | 持P02者及必要确认机关 → 候选Person的任职 | 指定职位；任用规则＋有效决定；不是直接赠予私人永久权 | 必要确认完成、候选接受且到任命生效时；至期满/有效免职 | 谁能免、是否需理由/确认单列；任命者无默认任意撤职权 | 任命者保留自身P02和明有监督权；不是丧失一份与新任同量的权力 |
| succession 继任 | 继任规则＋空缺/失能事实 → 顺位中合格者 | 指定Office与代理/正式范围；宗教、君主、军事、组织章程分别规定 | 空缺经有权程序确认并满足必要确认；代理至原任恢复/正式任命，正式继任至其自身任期终点 | 依据失格、原任恢复或规定撤换；代理不得自行延续 | 原任暂时失能时可保留身份但暂停范围；永久离任不保留该职权，私人财产另论 |
| delegation 委托 | 持可转授职权者 → 明确Person/Position | 原权力允许的对象、事项、地域、额度子集；委托记录 | 明定时点/送达；至期限、基础职权失效或任务结束 | 有权委托者/制度指定者依条款撤回，不能任意撤销已成立外部承诺 | 通常保留原权和问责；若委托规定暂时独占则原人该范围暂停，其他权不变 |
| board authorization 董事会授权 | 有效B集体决定 → 经理职位/指定代表 | 具体项目、共同总承诺、签署条件；会议与有效文本 | 决定完成必要程序且生效；到期限/事项完成 | 原B依程序修改/撤销，对外已成义务须另外处置 | B保留P04/P08；董事个人不取得项目资金或签署资格 |
| ownership governance 所有权治理 | 正式权益变动＋股东/成员治理规则 → 新权利人及之后合法选出的治理席位 | 具体公司/资产权益对应的P01/P14；股份登记、协议、章程 | 票权按登记/资格截止生效；董事/经理变化在各自任命边界生效 | 依权益转让、资格终止或有效裁决；不能由经理随意撤股东权 | 原所有者保留未转出的权益；原董事/经理可能暂留任，直到有效换任 |
| command assignment 指挥配属 | 持配属权上级 → 接收指挥Position | 指定部队、任务、地点、命令类别；有效配属依据 | 明定生效/通知条件；期限、任务完成或替代配属终止 | 有配属权者明确撤回/替换；处理正在执行的命令 | 原上级失去被转的作战范围，保留列明行政/补给/任免；接收者不取全部编制权 |
| coalition agreement 联盟协议 | 各方有授权代表和批准机关 → 协议各方 | 特定候选/议程/投票合作；相同版本协议 | 双方批准/签署和约定日期；至期满、目标完成、退出 | 按退出/违约规则；不能撤销公共机关已合法作出的结果 | 各党保留自身组织、席位与法定投票者；只有合作义务变化，没有公权被自动交出 |
| law / constitution 法律/宪制 | 有P06及必要批准/确认者 → 指定机关/Position/资格群体 | 列明权力与管辖；有效修法/制宪程序和公布文本 | 按生效日及过渡条款；至修订/废止/有效裁决 | 对应合法修改、审查和撤销程序，不能由受权官员自撤制衡 | 原机关保留未修改事项；被转出范围自边界后终止或按过渡规则并行 |
| emergency transfer 紧急转移 | 规定的启动/批准者 → 临时职位或现职位的临时授权 | 列明危机、地域、事项、例外、监督和额度；P15合法依据，或另记事实接管主张 | 危机条件确认且到生效边界；硬截止/条件消失，以先到者为准 | 提前终止/司法或立法复核依制度；续期须重新批准 | 普通机关只在明确覆盖的部分暂停；监督、救济、未列事项是否保留逐项写明；到期恢复 |
| organizational split / merger 组织分合 | 各组织有权治理机关＋必要外部同意 → 新/存续组织及合法新职位 | 成员、职位、辖权、合同承继逐项列清；各自章程决定、法律及第三方同意条件 | 约定组织变更日；不同合同/公共授权按各自过渡边界 | 生效前按原程序撤回；生效后需新变更/裁决，不能简单“撤回历史合并” | 未转移部分仍归原主体；旧债义务依承继规则存续；公共许可和军令权不得因资产合并自动复制 |

权力不遵循一个总量守恒公式：任命增加一个岗位的实际任职者，立法可创设或废止职权；但**同一独占事项、同一席位或同一额度**不能通过转移重复产生。必须区分“原有权的行使者换人”“原权委托给别人”“一个新规则建立了新的权限”。

### 5.3 生效、通知、撤销与善意相对方

权力生效、消息送达和对象实际服从是不同边界。公共规则按其公布/生效条款；内部临时命令按该军制的认证、送达及生效条件。不得因为某人还不知道自己被免职，就无条件视其继续有真实职位权。

对外承诺可能另受表见代表、善意相对方或通知保护规则约束。因此输出要区分：内部是否越权、外部是否仍约束被代表主体、谁承担责任。具体制度尚未规定时保留“外部效力待认定”，不能把内部权限拒绝等同“合同必然不存在”，也不能默认任何冒签都有效。公司、银行、公共采购的此类例外只按明确制度增加。

撤权默认阻止之后新行为；既往合法合同、已投有效票和已完成结果按其规则保留。草案、尚未形成的批准或未签署承诺交新任处理。依某个职位作出的持续规则不因发布者个人离任自动废止；依其个人限期委托产生的权力则按委托条件终止。

## 6. 不同制度下的 Power Graph

### 6.1 一个 polity 当前的 Power Configuration

配置不是执政党名称或支持值，而是某一时刻以下内容的组合：

| 部分 | 必须能够回答 |
|---|---|
| 有效制度依据 | 哪些宪制、法律、条约、授权及紧急条款在适用；哪些有争议 |
| 机构与职位 | 哪些公共机关存在，关键Office是什么，谁在任、代理或空缺 |
| 权限分配 | 谁提名/任命谁；谁批准/确认/否决什么；哪些事项由谁保留 |
| 辖区 | 哪个机关对哪些地域、主体、税种、案件和其他事项有权 |
| 制约与问责 | 哪些机关互相监督；何种责任程序可以结束任职或撤销决定 |
| 合作承诺 | 谁承诺支持哪个提案/候选，条件和期限是什么；不等同已投票 |
| 承认与实际服从 | 哪个机构接受哪一套任命/规则；哪些机关无法落实自己的有效决定 |
| 空间事实关联 | 主权、行政、军事控制等现有Spatial事实，与权限主张是否一致 |

Politics改变这些具体点和边。社会声望、组织动员或公众态度可以解释某次表决/任命/拒绝服从为何发生，但其结果必须落实为某个任职、关系、规则、承诺或承认状态的变化。

### 6.2 制度变化一：议会权力扩大

```text
变化前：
君主任命首脑P
君主机关 ──P04最终批准── 国家预算
议会B ──建议/请愿── 君主机关

变化后（本样型选择的具体改革）：
君主任命首脑P                          [保留]
议会B ──P04批准── 国家预算             [新增]
君主机关 ──P09公布已有效预算           [原自由批准权被缩减]
首脑P ──提名── 财政部长候选
议会B ──confirmation── 财政部长任命    [新增]
```

图的改动：新增议会预算批准边和财政部长确认边；删除君主单独批准预算的充分性；保留君主任首脑、法官任用及其他未修事项。是否另设政府对议会负责必须再有明确改革条款，不能从“议会变强”自动推导全部议会制。

生效时已有合法合同继续；尚待批准的新预算按过渡条款进入新路径。议会也不因此获得国库账户的直接支付权。

### 6.3 制度变化二：总统制样型

```text
总统选任资格群体 ──独立选任程序── 总统P
国会选民/代表资格 ──各自程序── 议席P
总统P ──提名── 列明行政/司法职位候选
确认议院B ──confirmation── 列明任命
国会B ──P06/P04── 法律/预算
总统P ──P07可覆议否决── 列明法案
国会规定多数 ──override该否决── 法案成立
司法机关 ──列明案件/审查权── 适用对象
```

从首脑依赖议会普通信任的制度转入此样型时：首脑职位改用独立选任依据；普通不信任票是否不再终止任期明确写入；弹劾/责任程序与任免边分开；议会保留预算和立法，不能因总统为行政首长而成为其parent下属。

美国宪法原文提供了行政提名、参议院参与确认、国会立法与行政否决等彼此分离的实例；上图是比较制度样型，未声称完整复刻美国各年代规则。[美国国家档案馆：宪法文本](https://www.archives.gov/founding-docs/constitution-transcript)

### 6.4 制度变化三：君主任命制

```text
继承规则/选举君主规则 ──succession/selection── 君主P
君主P ──P02── 首脑与列明大臣P
大臣P ──P03/P05/P09/P10── 明定行政范围
顾问会B ──建议── 君主P
地方传统机构/法院 ──各自既有权利── 保留对象
```

“君主制”至少还须选择：哪些行为需大臣副署、顾问会仅建议还是必须同意、议会是否控制部分预算、地方是否有保留权。基础样型选择君主任免大臣、顾问会仅建议；若规定副署，则君主签署加负责大臣副署是共同成立条件，不能由君主头衔跳过。

继承更换的是君主Office的占有者。皇家私人资产、国家财产、地方财产权和部队实际服从分别处理；新君主不会自动继承所有私人公司。

### 6.5 制度变化四：地方自治扩大

```text
变化前：
中央机关 ──P02任免── 地方首长P
中央机关 ──P04批准── 地方预算
地方机关 ──受委托执行── 列明教育/市政事项

变化后：
地方选民/议事B ──选任── 地方首长P
地方议事B ──P04/P06── 地方预算/教育/市政规则
地方行政 ──P10── 地区A的上述事项
中央机关 ──reservation── 国防/列明对外事务/中央税种
中央与地方 ──共同批准── 跨区铁路等明确共同事项
中央监督者 ──P08/P13── 列明合法性/拨款监督
```

改动不只是一条parent移除：地方首长选任源、预算批准机关、事项辖权和中央撤销范围都发生变化。中央派出的海关机构仍可在同一城市存在；自治不意味着中央全部权力消失。

现代英国议会官方说明把下放事项与保留事项分开，这里只借用这种逐事项表达方法，不将其现代具体制度倒置到1900年。[英国议会：下放与保留权力](https://www.parliament.uk/about/how/role/relations-with-other-institutions/devolved/)

### 6.6 制度变化五：军事接管

```text
原有效制度图：
议会/任命机关 ──原合法依据── 文官首脑/部长/法院
军政机关 ──原任用依据── 将领P

接管后的实际关系图：
部分军事机关 ──承认/服从── 临时军事委员会B
部分行政机关 ──事实接受指示── 委员会指定代表
其他行政机关 ──仍承认── 原政府
Spatial：指定地点军事控制改变；其他地域事实分别查询

公共权力主张：
委员会 ──声称紧急任命/规则权── 指定范围
原制度机关 ──争议/继续主张── 原职位与辖权
```

必须区别依法启用紧急权力与突破原制度的事实接管。前者有P15依据、期限、被暂停事项与复核；后者记录新的控制和承认关系，不能伪造原宪法已授权，也不能自动删除旧任命与债务。

如果之后发生有效制度改订、选举确认、承认变化或恢复文官秩序，再分别改相应法律/任职/指挥边。接管军队驻地不会自动给委员会全国司法、中央银行、地方税和党内任命权。将领可有实际强制能力，却缺某些机关的承认和工作人员服从。

### 6.7 同一制度改革怎样落在图上

每次变更列出：新增哪些职位/权限/关系；终止哪些；保留哪些；改变哪些条件；涉及哪些地域和对象；何时生效；未决事项如何过渡；谁负责认定争议。不得只记录“政体=总统制”“自治+20”“军方控制国家”作为全部后果。

## 7. Spatial 与权力：地域范围及跨组织关系案例

### 7.1 Jurisdiction引用何种Spatial对象

现有Spatial目录包含地区、城市、港口以及道路/铁路/航路等对象；已有边界可使用`place:<map_id>`查询地点，线路沿用Spatial的既有引用。以下是权力适用范围的语义，不引入新的地图、几何或Stable ID种类。

| 权力范围 | 引用方式 | 必须说明 |
|---|---|---|
| 全国/政治实体范围 | 既有polity身份＋其对应的Spatial地点范围关系 | 代表哪个政治主体、何种事项；不能把polity名称当作任意全球对象选择器 |
| 地区、市、港口管辖 | 已存在的region/city/port地点引用；遵实际目录层级与包含关系 | 包含下级对象还是只管指定设施；飞地与排除地点明确列出 |
| 税区、警区、司法辖区 | 由既有地点组成的范围＋具体事项规则 | 三者可以用不同地点集合；不得只复制一个省份所属字段 |
| 特定设施/土地/部队 | Economy/Military对象引用，再读取其对应Spatial位置 | 物权/专业权限可能跟对象，地域公共权可能不跟对象；两者求适用交集 |
| 跨区路线/边境设施 | 既有线路及端点/途经地点引用 | 线路经营权、沿线用地、边境检查、军事通行不是同一许可 |
| 在域外/无地理限定的内部权 | 明确“仅成员/组织事项，无地理限定” | 例如党内表决或公司董事任免，不构成当地公共管辖 |
| 当前精度无法表达的范围 | 保留尚未完成的范围定义 | 不得把一个尚未支持的小街区默认为整省；内容需落到可判定的已有粒度后再宣称成立 |

辖区随边界如何变化必须明定：绑定某时点确定的地点集合，或随依法定义的行政区域更新。战线移动不能自动改税区；设施搬迁可能使原地方许可不再适用，但公司所有权或经理任职并不因此消失。

### 7.2 同一个地方可以同时存在的authority

| 层面 | 它回答什么 | 是否能从其他层面直接推导 |
|---|---|---|
| sovereignty 主权/主权主张 | 哪个政治主体具有既有主权归属或提出主权主张 | 不从驻军出现自动推导；当前空间事实与争议主张分开 |
| administration 行政 | 哪些公共机构实际/依法办理哪些行政事项 | 不等于所有事项归同一行政首长，也不保证实际办得到 |
| military control 军事控制 | 哪个军事主体在指定地点具有实际控制 | 不等于永久主权、税权、司法权或私人财产权 |
| police jurisdiction 警务管辖 | 谁对何种治安/执法事项、哪些对象有权限 | 可有地方警察、中央保安或专门机构并存，各有案件/事项范围 |
| tax jurisdiction 税务管辖 | 谁有权制定/核定/征收哪一种税 | 中央关税与地方税可同地并存；征税、立税和实际收款不是同一权力 |
| judicial jurisdiction 司法管辖 | 哪个法院对什么案件有权审理、上诉由谁处理 | 行政长官或军事控制者不自动成为法官 |
| private / internal authority 私人及内部权 | 谁对公司设施、宗教成员、大学事项有内部权 | 不因地方政府/驻军管辖而自然消失，也不能越界成为公共权力 |

1899年海牙陆战规则第43条已经分别谈到占领者掌握的实际权力和当地既有法律，支持将实际占领与原有制度分开表达；并不意味着本稿已实现或概括完整占领法。[ICRC条约数据库：1899年规则第43条](https://ihl-databases.icrc.org/en/ihl-treaties/hague-conv-ii-1899/regulations-art-43)

### 7.3 地点A的完整重叠实例

```text
地点A：城市＋港口
甲Polity ──既有主权归属── 地点A
甲地方行政O ──市政行政管辖── 城市
甲中央海关O ──关税管辖── 港口进出口事项
甲地方法院O ──民事案件管辖── 列明案件
乙军事主体 ──实际军事控制── 地点A
甲地方警务O ──原警务授权── 列明治安事项
乙占领相关机关 ──特定占领职权主张── 指定措施
丙公司O ──实际产权引用── 城市工厂
```

由此不能推出乙取得工厂所有权、可以任免公司董事、已经收到海关税款或已经接管所有法院。若警务被实际替换，另记录谁开始接受谁的命令；如果税务人员继续工作，也必须明确收税依据、代表主体和真实付款对象。相互冲突的法定主张保留依据及争议处理，不能用一个`controller`字段覆盖七种含义。

### 7.4 跨组织关系案例

| 案例 | 正确权力路径 | 被禁止的错误推导 |
|---|---|---|
| 财政部长兼国企出资代表 | 公共任命给其财政职权；另一明确委任给其股东代表权；国企董事会产生经理 | 在股东会投票的身份直接签国库采购；凭部长身份支取国企现金 |
| 党主席同时是议员和部长 | 一个人有三份独立任职；党协议、议会投票、公共签署各使用自己的身份和程序 | 党主席可代其他议员投票，或党内罢免自动结束全部公共职位 |
| 母公司收购子公司 | 股份变化→治理票权变化→董事选任→经理任命；跨公司采购需子公司明确授权 | 母公司经理因parent/控股直接指挥子公司全部设施 |
| 银行向关联公司授信 | 银行有效审批机关按回避/额度批准；银行代表和公司代表分别有资格签署 | 同一人兼两边职位便自动满足双方独立批准、免除关联回避或拥有两边账户 |
| 工会与雇主签协议 | 工会会员授权限定代表；雇主治理链授权雇主代表；双方同一文本形成覆盖条款 | 工会内部投票改写全公司工资，或企业老板任免独立工会主席 |
| 跨区铁路与军事通行 | 中央铁路事项权、地方用地/相关许可、经营者代表权及明确军事通行依据分别满足；最终路线容量仍查Spatial | 获军令可省掉全部民事许可，或有地方土地同意就拥有全国铁路调度权 |
| 大学与独立学院 | 联合章程规定代表名额、学位认可和共同事项；学院负责人依学院自身选任产生 | 大学校长能免除所有独立学院负责人、直接处分学院资产 |
| 教会创设慈善医院 | 宗教任命产生教务职位；慈善文书产生受托治理；医院负责人获得医疗/经营范围授权 | 宗教上级的纪律权自动包含医院资产处分、病历公开和全部专业决定 |
| 保护方驻代表与本地首脑 | 条约只转移列明外交/军务或监督事项；本地其余职位和辖权继续存在 | 驻代表在首都办公就获得全部内政、司法和地方财产权 |
| 地方名望人物支持军官 | 社会承诺可改变人事提名者/表决者的选择；最终任命仍走有效军政程序 | 声望数值直接产生军衔、指挥关系或公共免职权 |
| 组织分裂与公共许可 | 成员分流和新治理机关分别成立；资产/合同按承继规则转移；旧许可逐项查可转让性 | 两个新组织各复制一套旧工会基金、营业许可或同一独占军令权 |
| 犯罪首领控制合法公司人员 | 记录事实胁迫/服从；合法公司的任职、授权、外部效力和责任分别核验 | 首领内部批准等同公司董事会批准或国家合法授权 |

这些关系必须能同时成立。一个人或一个机构可以在某条边上处于上位，在另一条边上受对方制约，例如行政首脑提名法官，而法院依法审查该首脑的行政行为。

## 8. 对 Organization、Politics、Government、Economy、Military 的语义约束

本节规定后续接口必须表达什么，不设计新的底层模块或代码任务。

### 8.1 各方必须给出和接受的事实

| 范围 | 本规格要求表达的内容 | 不应由它推断或保存的内容 |
|---|---|---|
| Organization | 组织构成、职位、成员资格、任职、内部规则、决定、代表授权及相应关系 | 公司现金、仓库库存、产量、人口总量、兵力和战斗结果 |
| Politics | 候选与任用程序、政治协议、具体表决/制度变更结果、公共权力配置及承认/争议关系 | 用支持总分直接代写职位、预算执行或军事控制 |
| Government | 公共机关、具体职位、辖权、审批与签署路径、执行职责及问责 | 因预算批准而产生现金，因有许可权而宣称施工/发放已经完成 |
| Economy | 接收有效主体及授权范围下的合同/支出/资产请求；判断财产、资金、库存、生产、债务及履约 | 因付款人有钱就授予公共职权；根据公司kind猜谁能代表它 |
| Military | 接收明确发令者、依据、对象、范围、有效期间的命令；判断实际服从、兵力、装备、物资、命令送达与执行条件 | 因高级军衔自动扩权；把作战胜利直接变成所有民事权力 |
| Spatial | 提供既有地点、路线与地域事实引用，支持确定空间适用范围与物理可行性 | 由一个军控/主权字段自动展开所有税务、司法、警务和私人财产权限 |

Organization只保存额度**规则**和业务引用；已花费、已承诺金额来自相应经济事实。资源概览可以查询，不能复制一份可独立修改的组织现金/库存。军事组织只引用Formation；不再保存与Military竞争的兵力或战斗结果。

### 8.2 一次代表行为必须带齐的信息

对外提出、批准、签署或命令，至少能追溯到：实际Person、所使用的任职/会员/个人依据、holder、被代表实体、具体operation、目标引用、地域与事项范围、拟生效时间、适用Power与basis、所需批准及其版本、任何委托或配属路径、问责主体。

授权回答须区别：

- 没有该资格或对象不在权限范围。
- 有提出权，但事项缺批准/确认。
- 事项已批准，但当前人物不是有效代表。
- 代表及程序有效，尚须相应领域判断资源/实际条件。
- 存在内部越权或公共权力争议，外部效力依指定规则待认定。

“有资格”的结果不能包含伪造的已付款、已到货、已移动或已获胜。相应领域拒绝执行时，也不能倒推这项任命/预算决定一定不存在。

| additional constraints | 文本与批准一致、必要回避/双签、不得拆单绕限额 | 指挥认证与送达、任务约束；实际执行由Military/Spatial判断 | 回避、合议或上诉规则；裁判签署另有P09 | 对方有有效雇主代表；低于6%需会员重新批准；双方同一版本 |
| accountability | 对财政主管、预算监督及依法审查负责 | 对配属批准者及军制责任程序负责 | 对法定审级与司法责任机关负责，非案件结论听命行政领导 | 对会员批准机关负责；雇主不能撤其工会职位 |

### 8.4 三个必须保持的区别

**CEO有权签合同，且董事会已批准300 U项目；公司可能只有50 U现金。** 前两项属于组织与权力事实，后者由Economy判断。合同可以要求贷款、分期或等待资金，不能把权限核验成功视为付款成功。

**部长有权采购100箱器材；市场可能只有20箱可交付。** 部长权限仍然存在，供应条件使请求只能部分履行、延期或无法成立；组织权限层不补出80箱，也不把20箱库存变成100箱。

**将领对第十师有有效command authority；部队可能未收到命令、缺装备、路线中断或不再实际服从。** 任职、授权、送达、实际服从和执行结果分别记录。执行失败不会自动使该将领的公共任命被撤销；是否撤换是另一条人事/问责路径。

## 9. 规格完整性与未预设的制度选择

### 9.1 内容配置不可留空的选择

| 需要选定的差异 | 允许的结构选择 | 本稿的处理 |
|---|---|---|
| 内部单位与独立组织 | 纯部门；独立子公司；自治附属组织 | 图中分别标明，不能靠kind或同名推断；对外主体必须明确 |
| 一元/两元公司治理 | 董事会监督；另设监事/监督机关 | 基础公司样型使用董事会＋独立监督职责；需要两元制时明确新增监督机关的任免/监督边 |
| 单独/共同代表 | 一人可签；多人可各签；必须双签 | 每项Power选择，累计额度共享规则不可省略 |
| 君主/宗教/军事继任 | 固定顺位、选举、上级任命、混合确认 | 不推荐跨所有组织统一选一种；逐Office填写，不用“最高资历者”兜底 |
| 中央与地方冲突 | 明确保留、共同同意、有限优先、司法/特定机关解决 | 默认不凭层级裁胜；未规定的同事项冲突保留待认定 |
| 编辑、学术、司法等专业独立 | 有限保留事项或受特定指挥 | 独立与不独立都必须有具体授权/保留关系，不用机构名称自动产生 |
| 对外越权效力 | 严格不生效；满足特定条件仍约束主体；待有权机关认定 | 必须按制度和相对方条件选定，内部违规与外部义务不能混为一项结果 |
| 组织分合的公共授权 | 依法随主体承继；须重新确认；不可转让 | 逐权力/许可列明，不能随资产或会员分流复制 |
| 紧急权到期 | 硬到期、条件提前结束、依法续期 | 必须有硬终点或可判定结束条件，受权者无无限自行延期权 |

### 9.2 结构审查应能回答的反例

1. 把采购处的parent改成董事会，不会因此给每位董事付款权。
2. 任命法官的人，不因此获得代法官裁判的权力。
3. 董事长兼经理，仍不能把自己一票当成董事会全票。
4. 监督机关要求报告，不因此获得被监督者的对外签署资格。
5. 集团公司控股，不能省略子公司代表权及自身治理程序。
6. 议会扩大预算权，只修改预算及明确关联边，不能顺便创造军事指挥权。
7. 自治地方仍可能与中央税务、警务、法院在同地并存。
8. 部队临时配属届满，接收指挥者失去新令资格；已有行动由命令规则接续，历史不抹掉。
9. 联盟协议解散，不自动废除各方原本的公职、法律和组织合同。
10. 教会对神职的任免权，不等于对独立慈善受托财产的自由处分权。
11. 银行批准授信、签贷款合同和实际提供资金，是不同事实。
12. 犯罪或接管组织的内部认可，可以产生事实服从关系，不能伪造原公共法的认可。
13. 同一Person的职位、会员、财产及亲属关系不能被合并成一个总Power。
14. 地点军事控制改变，主权、行政、司法、税权、警权和私人产权逐项保持或依各自依据变化。
15. 新组织成立/分裂/合并不能复制旧组织的独占席位、预算额度或同一部队的最终指挥权。

这些是对设计和后续内容的判定标准。本次未编写或运行新代码，未声称上述制度或跨领域行为已实现。
