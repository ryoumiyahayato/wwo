## 建议实施路线

### 阶段 1：正式会话与持久化

串行完成 P0-001 → P0-002 → P0-003 → P0-004。完成定义是一位玩家、一个命令边界、一个完整事务快照，并通过新建—行动—保存—退出—重启—继续及故障注入。

### 阶段 2：最小生活经济

先完成 P1-006，再完成 P1-001 和 P1-007。完成定义是需求/工作/收入/消费把一个玩家与聚合经济连成可观察、可保存的因果链。

### 阶段 3：空间与社会

在稳定 ID/owner 上完成 P1-002、P1-004、P1-003。完成定义是一条旅行闭环和一条通信/知识闭环端到端 `VERIFIED`。

### 阶段 4：非玩家世界反馈

完成 P1-005，并同时解决 P1-008/P1-009 的历史语义和发布许可门禁。完成定义是至少一个政治/组织/AI 变化可被玩家获知、应对、反馈和恢复，且性能有界。

P2 的测试/文档事实治理可在正式边界稳定后并行；许可审查和历史下级行政来源研究可独立进行，但不得在契约未定时改变正式运行语义。
