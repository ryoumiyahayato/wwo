# WWO经济系统盘点与模拟精度评估

## 人口消费与区域货运

正式法国开局有巴黎5,000人、里昂3,000人和鲁昂2,000人的人口组。开局分别持有10,000、6,000和550,000公斤粮。口粮按每日每人0.5公斤干主食当量结算。实际消费扣原货批。自用先消耗自有货批，采购还要受库存、知识、现金和运输约束。人口组与开局粮是开发设定。衣物、住房和出行需求尚未按同一开局的人口组完整校准。客运使用现有旅客通行责任。

沿用沙盒已验证的批量交付和运力。货运以地点为节点，路径按已配置连接查询，供区域、国内和国际市场共同使用。报价将商品实付额与各段承运费分列。原订单锁价、库存承诺、运力、收货与Ledger付款负责执行。原空间线路的有效运力为零时，货运不再进入该段。已进入线路的批次按锁定进度到达。线路状态变动会使寻路缓存失效。

启用共同报价的情景复用现有按日交付汇总。后台观察按发地、收地、商品和币种返回实际交付量与实际支付的毛运费，两数相除得到数量加权单位运费。排队或在途订单不算交付，退款单独保留。观察窗口上限30日。汇总不写入存档。源回执仍随实际合同保存，长期回执增长另计。

普通开局隔离存档恢复后推进至第9日。最近7日鲁昂至巴黎实际交付17,510公斤粮、实付运费17,510；鲁昂至里昂交付10,500公斤、实付运费21,000。两条线路分别为每公斤1、2开发计价单位。承运账户累计43,511，其中5,001发生在观察窗口之前。三组累计消耗45,000公斤干主食当量，观察期未发生口粮缺口。

旧的宏观国际贸易层已有禁运和配额规则。正式订单仍缺方向性通商准入、可执行跨境路线、关税及相应结算条件。国别用于判定准入与市场范围，地区之间的实际网络不按国家复制。

Debug 新开法国世界可用 `--formal-warehouse-pilot` 启用巴黎铁路场站和伦敦港仓的租仓报价。报价在市场「仓储与运输」中按已知范围显示。租仓与到站货物共用已有仓容，库存、保管工时、费用和损失沿原货批、服务合同与 Ledger 记录。损耗按合同有效期内的实际保管量与时间累计，费率和仓容是开发参数。住宅容量、仓房建设与维护、道路及气候对仓容的影响仍缺模型。

### 法定平价、发行责任与计量

1803年法郎法律基础为4.5g纯银或约290.3225mg纯金。纯金标准精确记为`9/31g/Fr`，即约0.290322580645g/Fr；20Fr金币标准毛重`200/31g`、成色900‰，不能把毛重当纯金。代码存整数分子分母：100c/Fr，`90000/31μg/c`，不累计浮点金量。[IMF法国货币制度章节](https://www.elibrary.imf.org/display/book/9781451949605/ch005.xml)核对法律口径；该站正文访问受限，数值从其索引摘录核对。法国银行[工作论文422](https://publications.banque-france.fr/sites/default/files/medias/documents/working-paper_422_2013.pdf)研究硬币流通与磨耗，并非1900年纸币准备金法规。

法国1873年限制、1870年代后期停止自由铸银，1900年按金平价运行，但银5Fr大币继续作为支付手段，银铜辅币承担小额支付。不能称仍有无限自由铸银的完整双本位。法兰西银行发行纸币并负兑付责任；纸币是银行负债，存款是账户债权，硬币是金属支付手段。把存款兑现成纸币只改变持有形式，不能把同一准备金重复算成三份净财富。[IMF金银本位研究](https://www.imf.org/en/publications/fandd/issues/2023/03/gold-silver-monetary-stability-johannes-wiegand)、[1890—1913法国货币量研究](https://www.persee.fr/doc/hes_0752-5702_2006_num_25_2_2592)。

当时纸币发行有法律上限，资产覆盖可以含金、银、证券和商业票据，并非所有纸币须100%黄金覆盖；银行可用金或银履行金属支付责任并采取保金措施。黄金流入可以进入铸币流通或银行准备，流出会收紧准备，但不会机械地一克对应扩张/收缩全部银行信用。[同期银行制度汇编](https://www.gutenberg.org/files/35120/35120-h/35120-h.htm)法国部分；[法国1878—1939货币机制研究](https://shs.cairn.info/revue-de-l-ofce-2012-2-page-147?lang=fr)。本轮没有把这些制度概述写成新央行规则：当前缺实际发行主体、储备来源、可兑付负债和兑换动作，黄金储量仍未知，没有新增实物黄金。

启用方式为`EconomyNetworkDevelopment.resource_franc_request()`交给原WorldBootstrap。配置只选择原Ledger内的结算币种；报价精度为0.001生丁/商品单位，实际货款、运费及工资为整数生丁。例：18.7c/kg的批量报价在第1日生效，19kg取整付款355c。已受理合同仍按原锁定价格结算。共同参考价格算法不读黄金字段，因此金平价固定不阻止粮价下跌或缺货面粉涨价。

新开局自动主体现金162000c，即1620Fr；它取原初始分布数值的20倍生丁，是**新情景财富假设**，不是兑换率。旧8100开发币情景保持原样。手动玩家2500开发币仍保留在同一Ledger的原账户，法郎账户为0；没有FX报价，不能支付生丁订单。零余额的旧账户保留用于兼容。存档配置缺少`settlement_currency`时仍按原开发币读取。

### 消费覆盖与未建模项

500/600g是干主食**服务代理**，不是完整食物篮子或实际营养指标。grain是原粮，却和面粉一样直接提供1000g服务/kg，尚未要求家庭加工及烹饪后才能取得该服务。工业磨坊5kg原粮→4kg合格面粉，另有1kg开发规则加工不合格量；面包5kg面粉+煤+劳动→10份，每份500g干主食服务。面包湿重、水、家庭烹饪燃料和营养吸收均未闭合。聚合消费的最后一个整数单位还可能只有部分服务被计入满足，不能以原料重量直接代替服务满足量。

肉、豆、乳、蔬果、油脂、酒、照明、衣物、居住等不能由当前两个生活类别充分表示。现有少量工业商品不等于这些需要均已建模。[Allen生活篮子Table 3](https://web.mit.edu/14.731/papers/greatdivergence.pdf)含182kg成品面包、豆肉乳等及5百万BTU燃料；表中价格是1745—1754斯特拉斯堡银克，不是1900法国法郎。只把182kg面包按1900巴黎0.334Fr/kg计约60.788Fr；其余项目资料不足，完整1900篮子成本保持未知，不能把182kg成品面包换成182kg干粮。

## 2026-10-30基层经济循环与两年运行

结论：实物农业再生产、矿产销售、工资付款和家庭消费已经互相连接；这个有限地区仍未形成可自持的货币循环。两年能继续结算，也能同时出现收获积压、工人缺粮和企业停产。新增收获没有自动变成收入。本节是前轮比例与经营规则；当前补充见上节，下方原100/1000数量试验保留为控制，不把两者混称为同一配置。

### 数量依据与缺项

原1000组有6000名自动阶层成员、100ha、年收121500kg、下季种子20000kg。扣种后101500kg，仅相当于每人每天46.35g；按500g干主食/日只够约556名成人一年，不能支持6000人的完整口粮。旧20/100g食需是开发强度，不是历史标准。

[Allen 2001表3](https://web.mit.edu/14.731/papers/greatdivergence.pdf)的欧洲比较篮子含182kg面包/人年，另有豆、肉、乳品、蛋等，燃料5百万BTU/年约14.45MJ/日。它不是1900鲁昂/里昂实测；面包也不能直接当成等重干粮。[IPCC表1.2](https://www.ipcc-nggip.iges.or.jp/public/2006gl/pdf/2_Volume2/V2_1_Ch1_Introduction.pdf)其他烟煤低位热值默认25.8MJ/kg，范围19.9—30.5；这里只用于燃料数量级。[FAO/WHO/UNU](https://www.fao.org/4/Y5686e/y5686e07.htm)说明能量需要随体重、年龄及活动变化，不能把粮食克数当完整营养标准。

### 参考价的含义及现行公式

`R`是**当地稀缺压力与实际交付成本的混合参考指标**。它不是均衡价、当前可采购价或成交统计均价。当地库存是时点量，询价最多覆盖14日，交付是7日流量；三者共同用于有界决策，不构成瓦尔拉斯清算方程。

- `S`：同一正式place内，允许销售的主体实际可用实物，扣除承诺、种子及自用保留。远方库存、在途、停业库存不计入。
- `D`：询价期限内、仍由原账户余额和原分项预算支持的剩余未成交量。成功受理后先预留钱货，再记录残余询价。每买方/商品保留一份；同账户和预算不重复支撑多个请求。家庭共用尚未覆盖的同类需要；已有食品、在途和替代食品均参与核对。替代请求按已观察的单位需要成本顺序分配一次，位置估算每买方每窗只做一次。
- `V`、`W`：本窗实际交付量及其真实货款加权均价。卖方place取货款，买方place取货款＋运输费；同地只记一次。接受但未交付的订单不是V；历史合同交付仍使用其锁价，不能把W误认为当前边际报价。
- 需求数量按已观察的整数单位成本和预算保守限制；整批结算可能允许略多购买。该试点尚未求解完整家庭需求弹性或全市场最优篮子。

每7日同一算法更新。内部R、卖方报价按1/1000货币整数保存；压力按1/1000保存，整数除法向零截断。参数：平滑0.5、压力系数0.05、阈值0.1、成交锚0.25，参考值单窗约±5%。卖方调价次日生效。

```text
若 S+D+V=0:
    R不变；p = 0.5*p_previous；a = 0
否则:
    x = (D-S)/max(1,D+S+V)
    p = 0.5*p_previous + 0.5*x
    若 a 与 p 不同号：a=0
    a += p
    若 abs(p)>=0.1：u=p；a=0
    否则若 abs(a)>=0.1：u=a；a=0
    否则：u=0
    target = R*(1+0.05*u)
    若V>0：target += 0.25*(W-R)
    R_next = clamp(target,0.95*R,1.05*R)
```

`a`仅累计同方向的小压力；反向或空窗清零。漏过多个观察窗时按经过窗数衰减旧压力，在当前精度归零后立即停止循环。零供给不除零；无成交但有资金需求仍可推价；供给恢复和低价交付可拉低R。空窗保存旧参考值，不假称出现了新的成交信息。

卖方目标：已知成本时为 `0.75R+0.25cost`，否则为R；每窗向目标走四分之一，限约±5%，报价最低1货币/实物单位。成本取已交付合同前缀的实际平均含运支出与已知配方/工资，不取最后一笔小额尾差。成本没有强制售价底线，不保证利润。合法手动报价仍可偏离参考值。

**已修改**：残余询价记录时点；家庭已满足/替代需要的排除与共享；停业供给排除；同方向小压力累计；空窗压力衰减；精确整批报价与到货金额；矿产机会成本不再使用四舍五入后的单位报价。没有重写全世界价格均衡。

### 两种方案及最终算法

|方案|共同公式|优点|代价|
|---|---|---|---|
|A：直接有界超额需求|`x=(D-S)/max(1,D+S+V)`；`R'=R×(1+0.05x)`|状态少、计算一次完成|小幅交替失衡也反复反向调价；单独使用时没有成交价锚|
|B：平滑失衡＋已成交价格锚；本轮采用|下列公式；卖方另作有限报价调整|过滤小波动，保留实际成交和独立卖方报价|需保存每市场的上期压力、参考值及窗口成交合计；参数不是普适均衡证明|

`S`是该市场当前实际可售量。`D`是未成交且仍在期限内的有资金需求。每个买方/商品仅保留一个当前未完成询价。计算时重查原Ledger可用余额，并按账户共享剩余预算分配，防止同一钱包同时支持多份愿望。无钱生活需要仍留在原需求/短缺记录，不作为该报价下的可成交需求。已锁订单不重新计作待成交询价，在途不作为已到货供给。

每7日边界运行一次，无逐帧全网搜索或全世界均衡迭代。询价最迟14日且不超过自己的need-by日期。已有分项采购预算也限制可负担量；询价只存原规则ID及单位额度，更新时重读原预算的已用金额和有效期，共享预算不重复使用。成交记录在实际交付时增量累加，不扫描全部交易史。单币种试点只接受原开发计价单位，不声称已统一跨币种市场。

```text
x = (D-S) / max(1,D+S+V)
p = 0.5*p_previous + 0.5*x
p_used = 0 if abs(p)<0.1 else p
target = R * (1 + 0.05*p_used)
if V>0: target += 0.25*(VWAP-R)
R_next = clamp(target, 0.95*R, 1.05*R)   # 另受正数与配置价格上界限制
```

无库存、无有钱需求、无成交时保持参考价。零供给使用安全分母及有界幅度；不会除零或一步爆价。参考值和卖方内部报价使用1/1000货币单位的整数，除法向零截断。对外实际合同仍使用原整数货币，卖方报价四舍五入且至少为1。小数部分保留在状态中，不在每轮被丢弃。

卖方内部报价每窗向目标移动四分之一，单窗不超过约±5%。目标以当地参考值为主；有已知成本时取 `0.75×参考值＋0.25×已知成本`。已知成本使用实际到货含运价与已知配方/工资条款，是报价估计，不替代原成本归集。成本没有硬下限，库存过剩时可以亏售。手动合法报价仍可独立发布。新价次日生效，旧合同按受理日条款校验并锁定。

采购继续复用原 `_input_offers`：先排除不能执行的运输，再比较期限、到达时间、含运成本及既有合作信息。最终原 `_buy/_admit` 再核知情、资格、现货、金额、预算和线路。低价不能绕过闭路。资金预留不等于收入；实际交付才转移物主、货款与运费。跨市场参考反馈来自实际到货：卖方市场记录货价，买方市场记录含运价；不会直接复制无法运输的远方报价。

## 1. 经济系统全貌

WWO目前有两种同时存在、责任范围不同的经济计算。

- **Formal宏观经济**按经济统计区域、商品和人口估计每日生产、消费、短缺、价格及跨区域调配。它有聚合库存和在途记录；贸易价值进入统计贸易差额，不逐笔进入企业Ledger，也没有对应的企业StockLots来源链。[S02][S03]
- **Native经营经济**保存具名人物或人群、企业、站点、账户、货批、工作、工资、订单和合同。现金由Ledger保存，实物由StockLots保存；采购、生产、运输、交付和消费各有条件。进入Native的人口范围从原宏观消费范围扣除，不能再消费一次。[S04][S05][S06]
- **普通法国新开局**已有巴黎两个模拟雇主、两个岗位、两个零售点、玩家及一名自动居民。工坊和面包坊使用有限粮食、实际劳动和独立账户；雇员没有企业经营权。其他国家不因此自动得到同样的Native企业网。[S01]
- **PR125开发开局**是另选的八地点、20公司产业网络，含鲁昂两人加工家庭、有限矿藏、产业投入、供应发现和跨城订单。城市是地点与查询分组，不拥有全城库存、钱包或统一城市AI。它仍是有限样本。[S07][S08]
- **本地未提交增量**把巴黎—鲁昂两向改为吞吐时间窗口，并增加设施占用索引和分层经济地图。巴黎—里昂、海峡仍沿用持续占用的Shared模式。旧模式也没有逐帧移动的3D列车；差别在运力义务怎样占用后续窗口。[S09][S30]
- **正式源码中的其他经营功能**包括贷款、汇兑、股份、发行、分配、设备建造与转售、服务、租赁、零售、招聘和收尾。多数需要显式开发配置，普通巴黎开局没有把它们全部启用。[S10]至[S27]
- **独立研究仓库**另有全球商品参考、家庭选择策略、有限流量反馈和研究界面。部分生产/读取规则已移入PR；研究仓库整体没有因此接入main。[L01]至[L05]

## 3. 各模块实际模拟精度

分类：**主体**＝独立主体模拟；**事件**＝离散事件；**容量**＝数值容量；**聚合**＝群体聚合；**对象/空间**＝需可识别地点、设施或资产的独立约束；**视觉**＝只读表现。同一模块可以混合使用。对象独立不等于要生成3D模型。

| 系统 | 当前计算粒度 | 什么时候执行 | 必须保持的真实事实 | 是否可以进一步抽象 | 抽象后的风险 |
|---|---|---|---|---|---|
| 时间与主结算 E01 | 事件边界；Native日结仍分阶段遍历 | 推进世界时间，遇实际边界 | 同一Clock、历史有效区间、确定的先后顺序 | 可研究统一到期索引及活动集合 | 改顺序会改工时/付款/采购机会，不能只比较末日总数 |
| 宏观生产消费 E03 | 聚合＋容量；经济区域×商品 | 日界 | 原人口范围、单位和统计口径 | 已是黑箱；优先维护Native范围去重 | 再压缩可能掩盖短缺和商品差异；不能据此认定企业货源 |
| 宏观调配 E05 | 聚合流量＋到货事件；线路容量参数逐笔用，未合计全商品共享量 | 日结调配/到期 | 起终点数量、延迟、统计口径与价值 | 已轻量；可改到期索引；共享容量是规则选择，需另讨论 | 不应升格为有企业产权的真实订单；不能宣称已有Native式共享运力 |

| 更多经营候选 | 资本/家庭反事实投影可能约候选×K×活动/类别；不同策略叠加 | 显式周期、候选、冷却和实际资源前置条件 | 主WWO中投资估值与劳动/服务策略各占多少CPU |
| 地图与经营UI | 复制和几何重建可独立于经济日结消耗CPU；动画按帧绘制 | 字段白名单、选中1站点、分页、原路径几何复用 | C尚无GPU实机帧率/遮挡/字体结果；不能拿逻辑断言替代 |

**成本优先判断：** 钱货合同本身要保留；较值得先测的是重复估算、扫描与历史复制。当前仓储没有逐件3D存储成本，生产没有逐工人物理模拟成本。把这些系统改名叫“黑箱”不会自动省成本。Shared新模式主要解除持续载具占用的扩展约束，是否更快取决于活动规模、排队和实际索引命中。

## 5. 正式能力、开发情景与研究边界

### 5.1 当前普通世界怎样运行

以普通法国巴黎开局为例：工坊和面包坊是两个模拟组织，各有自己的账户、粮食和面包。工坊初始现金1200、粮60、面包12；面包坊现金600、粮24、面包0。两家各一个岗位，每次实际工作2小时，时薪分别3和4，工资延迟分别1和2日。每轮最多1小时用于现场销售，余下工作才供生产；没有工作就不能把纸面产能当成实际产出。[S01]

玩家和一名自动居民从已知岗位中行动。完成工作后，工资成为雇主责任；到期要从雇主账户付。居民用收到的真实资金买面包，买完再消费。普通开局的价格和材料交易是明确生成条件，不是1900年历史实价。工坊可按单价1向面包坊累计出售至多8粮，并保留4粮及既有生产/预留责任；面包坊采购不赋予雇员经营权限。现场交付也要占原销售工时。[S01]

这套普通开局没有持续农业补给。现有粮源、授权和工作决定它能继续多少；暂停、欠薪、现金不足和原料耗尽会留下结果。玩家不工作时不能自动获得玩家工资；自动居民和企业仍按原策略行动，但不保证两家都有人工作，更不保证长期满产。银行、股份发行、复杂服务、跨城设备交易和租赁并不是这两家企业默认日常活动。

普通其他国家仍有宏观经济及适用的正式人物入口，不会因为巴黎具备Native样本而自动复制两家雇主。宏观的估算生产/贸易继续运行，不能拿它的聚合余量无条件补给巴黎企业。

### 5.2 八地点区域开发世界怎样运行

菜单显式勾选法国城市/产业开发情景后，使用另一份声明配置。巴黎、里昂、马赛、鲁昂、勒阿弗尔及两港、伦敦组成八地点网络；20家公司有自己的经营地点、库存、资金和投入活动。鲁昂两人家庭另外持有有限粮食，使用未被就业/服务占用的劳动加工面粉。城市hub只帮助组织这些地点和寻找供应商。[S07][S08]

工厂的采购器查自己的计划、缺口、钱和已知供应商。供应发现会延迟，报价会受限，货物先被卖方预留；承运取得窗口及站场条件后才发运。线路延误会使买方没有原料。途中普通SALE的物主仍是卖方；交付后才按原合同付货款和运费。目的地无合法空位或卸货劳动时，货物等待，不能先算买方可用库存。

巴黎—鲁昂的新窗口是本地C；巴黎—里昂与英法海峡保留Shared持续池。两条铁路共用原巴黎站场与劳动，没有各复制一套。新窗口前8日12对旧8的采用差异，来自“待卸货是否继续锁后续运输吞吐”的规则差别。两者每窗仍为4、钱货仍逐单负责。关仓分支磨坊实收粮0、产面粉0，未干预分支实收10、产面粉4；这说明数值化保留了原料迟到的经营后果。[R01]

有限矿场要建造设备，再用维护保持可用，工具厂停产会反过来限制矿产。已有36日记录中，正常煤48/矿72、维护2次；工具停产分支煤28/矿42、维护0。家庭有限24粮加工16面粉，早期已验证样本实际销售6、收款18。后续供应发现时序调整会改变部分订单日程，不能强求不同配置整世界快照一致。[R01]

这些不是20家公司代表整个法国，也不是两人家庭代表农村经济。NPC在原策略内可以继续生产、求职、采购、消费和服务/资本决策；哪些策略启用由该配置决定。没有无限运力、自动免费补料、宏观兜底现金或保证成交。

### 5.4 独立研究中已发生与尚未发生的反馈

[Lab最新综合报告第九至十二节][L02]应分三件事读：

1. 收到公告可以使报价向初始价格锚回升；这不必由指数数值上涨导致。
2. 另一个**外生法国小麦供给冲击**确实在第54日使发布价3/4分化；第57日原采购器接受1粮新价订单，第59日按原路线交付，支付货款4及运费1。此项已超出早期“零改价”的报告范围，但仍是E研究情景。
3. 在同一外生冲击下，只切换**有限原生流量采用**，内部指数出现微小差异，公开两位小数公告、企业报价、订单和实物量在该窗口没有分歧。不能把第2项的冲击效果算成第3项的内生反馈效果。

有限跨境粮食已真实交付，但缺少与估计进口的覆盖标识时，报告明确不把该笔再加进宏观进口贡献。钢材单位/样本代表性、完整反馈、磁盘专项及报告记录的配置持久化问题仍各有边界。这些研究成果不构成主WWO全球市场已完成。

## 6. 下一步最值得讨论的9个问题

1. **哪些主体必须独立？** 建议先决定具名人物、直接经营家庭、企业和债权人独立到什么范围；背景cohort可否共预算，不能等同每人福利相同。
2. **普通开局目标是什么？** 是有限就业/消费样本，还是要持续运行的地方供给网？现有普通巴黎有限粮源与区域开发网是两个入口，不能靠暗补资源把边界抹掉。
3. **运输需要哪种稀缺？** 普通经济更重“每窗能过多少”，还是“同一载具多久返回”？鲁昂和里昂现有差异可用于讨论；不是所有线路必须一个答案。
4. **采购公平性怎样定义？** 按事件标脏和同窗聚合会改变先后手。哪些必须保持稳定，哪些排队规则可作为正式设计？
5. **仓储共享到哪一层？** 先明确同设施、保管者和单位；是否接受开发payload，或需逐商品正式重量/体积。统一查询不应变城市统一库存。
6. **生产需要多少过程？** 当前日级整数批次已能造成缺料、欠薪和停机。哪些行业真的需要多日WIP、专门工种或设备细节，是否存在相应玩家决策？
7. **投资判断要多精细？** 多候选反事实估算是否改变足够多的实际选择？能否以可解释的有限阈值和事件重算保留相同责任，而不每天重复预测？
8. **历史保留怎样分层？** 活动责任、重复动作识别、来源和玩家可查历史分别保留多久/何种形式？先定恢复与追溯要求，再讨论归档，不能先删记录。
9. **何时把底层机制提升为普通玩法？** 物流当前多为自动执行/观察，资本金融多为专项动作。先选玩家角色、权限和少量完整导航，再决定开放哪些模块；不要以“代码有实现”替代可理解玩法。

面对几百座城市和大量人口，应保留**独立产权、账户、合同、实际投入产出、债权、唯一设备及空间责任**。较适合抽象的是**运输执行、仓储容量、背景人群需要、服务人份、维护/租金到期和稳定区间结算**。较适合优化而非改经济含义的是**报价候选、路径、排产/投资估算、活动扫描和派生UI读取**。全国农业更新、银行与完整市场制度尚缺的部分，应先决定规则；黑箱形式本身不能代替规则。
