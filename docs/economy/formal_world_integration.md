# 1900 正式世界整合基线

## 世界、经济聚合体与可玩目录不是同一个计数

正式半球以 `data/world_map/historical/political_units_1900.json` 为政治地图事实来源。当前日期切片包含 151 个政治单元。50 个主要政权是高细节经济与可玩性候选目录，不代表世界上只有 50 个国家或政治实体。

50 个高细节经济记录覆盖 55 个地图政治单元：绝大多数经济体对应一个地图单元；`australia_colonies_1900` 对应 1900 年尚未组成联邦的六个澳大利亚自治殖民地。卢森堡经济旧名也通过显式交叉表映射到 `grand_duchy_of_luxembourg`。因此其余 96 个地图政治单元才是纯背景单元。

当前经济聚合体的可玩性分层：

- 第 1–2 位：领先列强；
- 第 3–7 位：列强；
- 第 8–18 位：主要政权；
- 第 19–30 位：可玩次级政权；
- 第 31–50 位：次要政权候选。

前 30 个经济聚合体构成当前核心可玩层。第 31–50 位保留完整高细节经济数据，以便后续根据可玩性审计缩减或提升。96 个纯背景政治单元仍保留地图边界、控制关系、外交存在和可选择信息，但不运行高成本的国家级详细经济。

显式一对多和别名映射位于：

- `data/world_map/historical/major_economy_polity_crosswalk_1900.json`

## 正式地图权威

正式产品入口为：

- `res://scenes/formal/formal_world_menu.tscn`
- `res://scenes/formal/formal_world_main.tscn`

三维历史半球是唯一正式地图。原 V2.3 平面产品场景、标题场景、平面地图玩家画布和旧玩家界面已经删除。正式运行场景不得包含 `PrototypeMap`。

## 两国八地区夹具的地位

Loran/Vesta 两国八地区数据不再由 `FormalWorldEconomyService` 加载，也不参与：

- 世界政治单元计数；
- 正式地图；
- 正式存档；
- 正式长期数值平衡；
- 正式 Windows 产品启动。

现存 Alpha 夹具仅用于隔离验证复式账本、合同、企业、劳动、迁移和 AI 执行等低层服务。在这些服务迁移到正式世界数据模型后，相应夹具应继续缩减或删除。

## 长期平衡门禁

正式长期平衡由 `tests/formal/formal_world_long_term_balance_test.gd` 验证。测试直接运行 151 政治单元世界中的 50 个高细节经济聚合体十年，不实例化两国八地区世界。门禁检查年度满足率、库存与价格有效性、运输队列、存档大小、恢复等价性和运行时间。
