# 1900世界经济数据方法

本数据层覆盖50个游戏优先政治实体，并以8个残余汇总项闭合全球人口约16.4862亿。国家记录可以进入国家级校准；残余汇总仅用于全球总量，不生成虚假的行政区、企业或运输节点。

## 数据等级

1. **直接历史锚点**：Maddison人口与人均产出、COW NMC人口/城市人口/钢铁/能源、CEPII双边贸易与关税，以及可核对的国家人口普查和铁路史料。
2. **邻近年份或边界转换**：缺少1900单年值时使用邻近年份插值，并按1900政治边界组合或拆分现代国家序列。
3. **有界估算**：农业、矿产、铁路、水运和港口能力缺失时，使用人口、收入、城市化、资源禀赋和已知枢纽推导。每项必须保留中心值、上下界、方法和置信度。

禁止把现代港口容量或1995年后的铁路里程直接改名为1900数据。现代资料只用于位置、定义和数量级核对。综合置信度低于45%的记录不得进入正式国家结算。

## 家庭预算

城市工人模板以1901年工人家庭调查为锚：2,567户具有详细支出记录，25,440户具有较宽统计，生活必需品约占总支出的79.8%，食品约占42.54%。其他阶层使用相邻模板中位数、恩格尔规律和地区收入水平推导，并允许家庭层面±12%的差异。

## 运输网络

运输数据是国家—枢纽级稀疏骨架，不是每条铁轨、河道和港区的精确复原。数据包括50国铁路/可航水道总量及范围、主要港口、30条远洋蒸汽航线和13条主要河运走廊。它适合运力、路径、时间和风险结算；不适合按线路像素复原历史地图。

## 紧凑表

运行时使用带字段顺序的紧凑表保存50国和运输网络。公共来源和方法保存在清单中，国家行仍保留人口、收入、城市化、产量、矿产、铁路、水道、港口、预算模板、上下界和置信度。`AlphaHistoricalWorldEconomyData` 负责展开并进行完整性检查。
