# 1900经济系统：界面、AI、稳定性与缺口审计

审计对象：`agent/1900-market-economy-core`  
审计环境：Godot 4.6.3，Ubuntu CI，1280×720 Xvfb 图形环境。

## 结论

当前实现已经形成可运行、可保存、可由人物AI持续驱动的Alpha经济闭环，但尚不具备完整世界经济系统的内容覆盖、长期数值平衡或正式游戏界面质量。

- 技术稳定性：通过。
- 数据与引用完整性：通过。
- 菜单入口和可见交易页面：通过，但布局存在明显缺陷。
- AI驱动：通过，三年内持续产生并成功执行经济决策。
- 长期经济平衡：不通过。三年末消费满足率仅11.36%，失业率17.42%。
- 性能：可运行，但长时间快速推进仍偏慢，三年Alpha模拟约92.87秒。
- 正式世界接入：未完成，目前仍是8个隔离Alpha样本地区。

## 必要但尚未补充的经济内容

### P0：进入正式游戏前必须补充

1. 将正式1900年国家和历史行政区人口接入商品市场，替换8个Alpha地区。
2. 将企业财务、工资、利润、税收、银行信用与实体商品销量和库存统一结算，移除“背景市场日利润”作为最终结果来源。
3. 修正生产能力与需求校准。三年末消费满足率11.36%，说明总体供给、地区调拨或国际流动池无法维持人口需求。
4. 建立价格影响需求、替代品选择和贫困人口降级消费，避免所有需求刚性累积为短缺。
5. 建立正式玩家经济界面，而不是仅从正式菜单进入独立审计预览。

### P1：完整世界市场必须补充

1. 港口、铁路、内河、商船吨位、航线、海峡与封锁组成的运输网络。
2. 双边贸易、关税、禁运、殖民地与宗主国贸易规则，而非单一国际流动池。
3. 国家货币、汇率、金本位储备、跨境支付与国际信用。
4. 政府采购、军费、战争动员、公共工程和战略储备。
5. 企业资本投资、折旧、扩产、技术、破产后产能转移。
6. 农业季节、收成、矿藏储量和资源枯竭。

### P2：人口与社会经济深化

1. 按阶级、城乡、家庭规模、年龄和职业划分消费篮子。
2. 收入分配、贫困、储蓄、债务、住房与生活成本。
3. 品牌、质量、声誉和销售渠道；品牌不应拆成新的基础商品。
4. 黑市、走私、配给和价格管制。

## 界面审计

正式菜单提供“经济系统审计预览”按钮，按钮可点击，目标场景可载入。页面自动运行30日，并显示：

- 总人口、消费满足率、失业率；
- 当日国际进口和出口；
- AI决策记录数；
- 地区选择、商品选择；
- 商品价格、库存、需求、生产、消费、短缺、进口、出口；
- 近期区域调拨与国际贸易；
- 人物AI经济决策。

1280×720实际截图发现：

1. 商品名称列宽不足，数据行中的商品名称不可见。
2. 九列商品表产生水平滚动，关键字段不能同时完整阅读。
3. 右上“返回正式菜单”按钮被窗口右边缘裁切。
4. 地区ID和AI动作仍主要显示内部英文标识。
5. 页面明确说明当前是Alpha审计预览，尚未接入正式里尔与全球历史行政区。

因此结论是“能打开、能看到真实交易数据”，但不是可交付的正式经济界面。

## AI运行审计

完整Alpha模拟连续推进3年（26280小时）。测试结果：

- 保留AI决策：512条，上限有效；
- 其中经济类决策：471条；
- 成功执行的经济类决策：471条；
- 涵盖工作、求职、迁移、信贷、还债、创办企业、经营企业、建立合伙与出售企业；
- 商品市场日结失败事件：0；
- 市场历史保持96条上限；
- 三年后跨服务引用完整，库存无负数，价格有效。

AI能够驱动旧劳动、企业、信贷和合同系统，同时商品市场按日运行。但AI目前不会针对新商品市场的具体短缺主动调整生产配方、扩建对应工厂、选择贸易路线或制定关税政策，因此还不属于完整的宏观经济AI。

## 稳定性与性能数据

三年测试最终指标：

- 总人口：8,930,000；
- 消费满足率：11.36%；
- 失业率：17.42%；
- 就业人口：3,324,031；
- 失业人口：701,259；
- 日需求：9,409.55单位；
- 日消费：1,068.46单位；
- 日未满足需求：8,341.09单位；
- 保留市场历史：96条；
- 存档序列化体积：8,636,609字节；
- 三年模拟耗时：92,865,194微秒；
- 平均每游戏小时：3,533.68微秒；
- 最慢单小时：77,202微秒。

判断：

- 程序稳定性良好，没有崩溃、负库存、价格失效、引用损坏或日结失败。
- 历史数组均有上限，没有明显无限增长。
- 单小时峰值77毫秒可接受，但三年快进约93秒，作为玩家快速模拟仍偏慢。
- 8.64 MB存档对Alpha可接受；扩展到全球数百地区后，如果保持逐商品完整字典，存档和日结成本会近似按地区数线性增长，必须采用稀疏库存、分层结算和低频远端市场更新。
- 数值稳定性不合格：供给长期崩塌，满足率过低。技术“不报错”不能等同于经济“运行良好”。
