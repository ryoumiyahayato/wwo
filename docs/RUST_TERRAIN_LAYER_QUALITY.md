# 全球地貌逐层质量验收

## 冻结取景

使用 `worldcrs84quad-15s-v2` 和 PR #139 的 Rust/wgpu 离屏入口。每个 Z 层单独抽取七洲，各用 `--terrain-level` 指定该层。北向上，1280×720。取景倍率按该层投影采样密度和纬度选择。Z0 用半球尺度。极区按精确层页预算缩窄取景。投影与实际绘制层以回执为准。

洲界锚点为 Natural Earth Admin 0 Map Units 1:110m v5.1.1，陆地为 Natural Earth Land 1:10m v5.1.1。先以行政图元和陆地交集定位大陆和岛屿，再按自然地理归洲。欧洲与亚洲以乌拉尔、高加索、土耳其海峡的折线近似切分，白令海峡按两岸归洲。大洋洲含太平洋群岛、澳洲与新几内亚。南极洲含南纬 60° 以南的陆地。海外领地按所在地归洲。未与洲界相交的岛先按近海岛群范围归洲，余者按经度环绕的最近地图单元归洲。旧池曾把西伯利亚归欧洲、把皮特凯恩群岛归南极洲。Z0–Z6 在随机拍摄前用更正后的池冻结，Z7 旧池画面保留为专项补充，按更正后的池重新冻结七洲。[洲界数据](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-details/) · [陆地数据](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)

候选为与该洲陆地有正面积交集的瓦片，按 Z/X/Y 升序排列。Z5 按洲排除[上轮随机瓦片](RUST_TERRAIN_LAYER_REVIEW.md#冻结抽样)，Z7 亚洲排除本轮基础设施前已拍摄的 `7/190/34`。各层种子为 `2026111500 + Z`，CPython 3.12.15 的 MT19937 按表内洲序调用 `randrange(候选数)`，下标从 0 起。瓦片中心落在该洲陆地外时，用瓦片中心的 WGS84 方位等距投影查找瓦片内最近陆地。同距按经度、纬度排序。裁切边界与瓦片边缘留 0.00000001° 数值余量。几何库为 Shapely 2.2.0、GEOS 3.14.1、PyShp 3.1.7、PyProj 3.8.0、PROJ 9.8.1。

## 原版画面与施工结论

PR #139 合入提交为 `e5a4b5edfc2d73871765d9a2d841b77b2da9496b`。它交付单层候选、指定层、最高 LOD、实际瓦片观测和离屏渲染入口。原版八层 QPK 的 43,690 张记录和历史全解码结果分别见[结构检查](RUST_TERRAIN_LAYER_REVIEW.md)。以下实拍使用同一正式 Rust/wgpu 管线和原版 `worldcrs84quad-15s-v2`。

S1 定位全球母栅格将高度和纬度换算为固定雪层。羌塘 `89°E, 33°N` 的 Z7 帧由 `7/191/40` 绘制，海拔约 5,034 m，源冰川掩模为 0，旧画面却覆盖广阔雪白地表。野外调查记录该地为高寒草甸、草原与荒漠草原。遥感分类记录羌塘冰雪覆盖约 1.36%。[野外调查](https://www.nature.com/articles/srep34105) · [遥感分类](https://www.frontiersin.org/journals/environmental-science/articles/10.3389/fenvs.2023.1217225/full) · [Z7 原版羌塘](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z7-tibet-grassland-before.png)

生成器的 QPK 路径改用 WorldCover 2021 v200 类别 70 和 Natural Earth 冰川范围。高程和光照仍由原 SRTM15+ 母数据计算。用实际源数据检查羌塘、喜马拉雅、格陵兰和南极各一处。羌塘恢复岩土色，另外三个冰川点保留颜色。四处的高程、海陆和水覆盖一致。此改动作用于 Z0–Z7 共享母栅格，候选须逐层写出全球 QPK 并复验。历史非 QPK 地貌走原有生成路径。

S3 独立复核 Z7 旧版 30 组 PNG 与同帧状态。所有截图背景离屏、无焦点、无正式会话。选中页就绪，九点贡献均为 Z7。羌塘问题以外，博斯腾湖和湖西侧水系可见；东侧孤立河段仍需对照到具体源河段。Óbidos 亚马孙主干连通，示意河宽较均一，细弯有阶梯化。密西西比鸟足三角洲、多佛海峡两岸、南极半岛山脊和冰岸均可辨。北极 QPK 缺季节性海冰资料。两极和阿尔卑斯、反经线专项静帧未见明显缺页或矩形边界。[博斯腾湖](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z7-bosten-before.png) · [Óbidos](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z7-lower-amazon-before.png) · [喜马拉雅](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z7-himalaya-before.png) · [南极半岛](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z7-antarctic-peninsula-before.png)

[Z3 原版羌塘](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/z3-tibet-grassland-before.png)记录同一问题在洲际尺度上的表现。

原版自动 LOD 专项各以 19 档缩入与缩出，共 57 个取景节点，拍过渡与稳定时点。S3 复核阿尔卑斯和太平洋反经线。阿尔卑斯 360 m/px 刚进入 Z7 时中心混合 Z7/Z6 约 10%/90%，稳定后九点全是 Z7。缩出至 6,200 m/px 时滞回目标 Z4 需 262 页，预算为 256，实际全画面限至 Z3。反经线 720 m/px 刚进入 Z7 时中心混合约 61%/39%，稳定后经线两侧均有 Z7 瓦片。关键过渡静帧未见明显黑块或接缝。连续快速缩放的闪烁与正式游戏帧时未测。[Z6→Z7 过渡帧](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/alps-z6-z7-transition-before.png) · [Z7 稳定帧](https://github.com/ryoumiyahayato/wwo/releases/download/rust-native-windows-20261115/alps-z7-stable-before.png)
