# 组织、工作与商号

在正式入口 `wwo-map-lab --play` 打开“组织与工作”。“当地组织”按人物实际所在地显示可接触的机构，“我的组织”显示本人的会员或任职关系。开局六城共有七家企业、六个居民互助会。19 名创办人、联络员和求职会员从当地既有人口实名化。机构、人名和岗位条件均为模拟设定。

- **巴黎。** 粮食工坊和面包坊沿用各自账户、站点存货及劳动合同。面包坊的在岗员工根据原料缺口发起采购。企业按既有授权向当地工坊结算，交割受双方的值班能力、余粮和买方现款约束。
- **其他五城。** 伦敦经营燃料，柏林经营纸品，圣彼得堡经营粮食，北京经营衣料，东京经营水产。客户下单时预留货款和代办费。实际交货才扣减市场库存、交付本人持有的商品，并向市场和企业分别付款。限价、库存、到场或班次条件不足会使订单等待或退款。
- **抵达新城市。** 具名乘客实际抵达有可用居民池和统计市场的城市后，按当地有需求的商品登记商号及互助会，从当地居民中登记三人。商号以零现金开户。之后即使乘客离开，商号仍按同一世界时间经营，再访沿用原人员、合同和账户。
- **家庭需求。** 日用品需求按目录用量累计。住户先用自己的存货，再按预算购买或委托商号。下一餐所需现金优先保留。无力购买的差额进入人物存档。
- **求职与经营。** 当地互助会联络员可介绍有空缺的岗位，获介绍者仍需应聘、登记班次。合伙人可用个人现款入资，按权限调整接单、购入企业货批并支付运费。选“企业账户”的“实物货运”可查询路线、发运和办理到货销售。目的地按现有市场报价和实收资金收购。
