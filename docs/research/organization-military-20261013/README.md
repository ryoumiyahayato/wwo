## 用户已确认的设计原则

- WWO为人物视角；组织涵盖行政、军事、企业、社团。成员、岗位、任职、授权、所知、产权与实际控制分开。
- 机制本身不自动产生玩法；模拟现实会增加复杂度。先完善必要机制，在机器负担内抽象，不能全世界每人每件装备同细度运行。
- 113项军事活动广泛保留为内容目录；当前岗位权限只限制当前参与，不裁掉世界活动。人物身份、交接和控制对象可能变化，不只升职；具体换人规则尚未确定。
- 配平指覆盖、计算精度、操作深度、UI承载与实现成本，不是本轮填全部军事值或用模拟拟合商品基础数值。基础参数后续按现实资料近似填写游戏抽象单位。
- 商品自身先只有单位重量、基础每日损耗率；价格属于市场报价/交易。运输方式另有损耗率，商品/方式损耗组合及方式按日/按程量纲尚未确定。“运输时效”关注最后可交付可用量，ETA另列。
- 武器、战争方式、半沙盒半箱庭地块战斗尺度及基础商品/产业链内容由用户后续规划；本目录不抢定。
- 组织、军事、经济最终共处一个世界，不能各自拥有第二套人物、库存、资金或全局Clock；研究/文档发布不等于已经整合。

## 本版架构建议（尚需设计核对）

显示展开、无损表示转换和物理模型改变分开；活动模型按世界事实在允许边界固定，视角/焦点/负载不重算或重抽。已有具名身份、伤损、任务、批次/预留和既定结果连续保留；匿名个体化有来源与准入上限。无法从平均量恢复真实细节时，拒绝/延后计算转换，不现场补历史。

人口人头与有效作战能力分开；实际死亡采纳一次，康复不增人口。专业状态各有唯一端口，宿主只装配/推进/安装；军事提出战损/消耗/实际交接，经济共同采用资源变化，组织关联责任。维修拆件必须有来源/产出/能力代价，不能从装备因子造零件。

日级策略与可中断过程分开。重大事件先结旧段再改未来条件；经济原整日行为和全部即时变化不能无条件同时保留。推荐唯一时间能保留秒级边界，当前宿主适配待核；共同容量窗口收齐请求后一次最终分配。离屏照常付成本，负载不足放慢时间/限制准入，不删开放责任。

当前任职的新动作、在途签署凭据与已接受组织义务分别判断；换人保留原任务与签发历史、知识按真实渠道交接，切焦点不刷间隔。委托用实际专业执行者；亲自介入须资格/位置/工时，并接同一任务份额，不能NPC与玩家双计。

## 已补充的经济研究与边界

新增报告核对Capitalism Lab、X4、Offworld Trading Company、Patrician III、EVE Online、Coffee Inc 2、The Guild 3和Victoria 3，并单列CapLab银行/金融DLC与通胀/Inverse Inflation。报告逐项区分实际机制、待核实细节与WWO建议；没有把用户例举价格/过程、Guild的具体面包配方、开发中功能或竞品AI的完整资金约束当成既有事实。

核心发现：物理生产约束不等于所有资金闭合；Victoria 3历史设计没有逐件商品库存，Guild有补货系统，均不能直接替代WWO有限库存链。经济提议以独立十五算法为主要对接起点，AI有真实资金/库存/用途和有限信息；不为竞争凭空补货、降价或造有款需求。银行首阶段保持已有资金出借语义；存款为负债、资本与流动性分开；贷款创造存款若后续选择需独立清算/发行模型。商品/运输损耗组合和真实数值仍待决定。

经济目录62项是内容分解，不是数量目标或已实现清单。先做有限地区的消费—劳动—生产—交易—运输、经理限额/换人和一条军需链；其他专门机制分两阶段。五组关键取舍与最新本地源码核对见经济完整报告第12节。逻辑案例和验收建议没有冒称运行、性能或玩法测试；新增文档不授权恢复旧实验或进入实现。
