# WWO 经济活动与机制分层研究：摘要与活动索引

2026-10-13｜v1｜配套 [完整报告](economy-activity-layering.md)

建议以现有独立经济十五类算法为主要对接起点，将人物任职、有限信息与真实经营活动连起来：居民收入/消费 → 实际生产与劳动 → 有资金和库存保障的交易 → 运输/损耗/交付 → 新的经营与生活后果。军事沿用原专业执行，通过真实耗用、损失和采购参与；组织只授予范围、控制和责任，不产生钱或物资。

这是研究架构，**没有游戏代码修改、旧实验恢复或运行验证**。云端实际接口、作者交付说明和本方案分列；最新本地未提交源码还需要窄核对。

## 3. 最少对象与接口边界

复用现有人物/人口、组织/岗位/任职/授权、经济主体、物资批次/预留、每币资金/预留、原订单/合同、劳动/生产/运输任务、共同信息渠道、唯一 Clock 和共同存档。新增优先为薄的需要/企业政策、待决进度和必要授权绑定；不要同步复制一套订单总账。

```text
人物/AI + 当前任职许可 + 已取得资料 + 原政策/进度
  → 提出/批准原订单或专业任务
  → 权限、额度、真实资金/库存/人时/容量共同重验
  → 专业执行与唯一交割/消耗/损失采纳
  → 真实回执按渠道返回 + 只读报表
```

共用制度骨架包括任职、代理、授权、资产/账户范围、责任与信息。行政专属辖区/税费/公共预算，军事专属命令/编制/装备/补给，企业专属经营/雇佣/股东/产销，社团专属章程/会费/活动。上下级关系不是产权或无限权限。

经理额度限制同一窗口的承诺/支出，仍受原账户可支付额限制；拆单、代理和换人不能刷新额度。任免先结旧时间，再影响未来新动作；旧订单、原签发者、已履行部分和组织责任保留。知识通过真实交接，不复制旧任全知视图。

## 4. 分层与金融的关键边界

- **S 模拟、A 权限、U 界面分开。** 浏览和控制焦点不更改模型、步长、随机、待决间隔或资源；表示无损转换需要足够状态，异质均值通常不够。
- **策略可日级，过程可中断。** 若要日内即时反应，先结旧段再改条件；这会改变部分原整日实验结果，须另列模型版本。共同容量窗口收齐请求后一次分配。
- **需要 ≠ 有款订单；成交 ≠ 到货可用；没回执 ≠ 失败。** 实际位置、产权、保管、付款、履约与所知分别处理。
- **商品固有字段先保留单位重量/基础每日损耗。** 价格属市场；方式损耗量纲与组合尚待决定。运输时效重点是最终可用量；拆单、分段和读档不减少应有损耗。
- **先保留 funded credit。** 存款是银行负债，贷款是资产；出借使用已有可支付资金，不能和存款人双花。资本与即时现金分别检查。贷款创造存款若后续选用，需要另做清算/发行模型。
- **收入、利润、现金流分别呈现。** 存款/借款本金不作营业收入，二级股份款到原卖家，集团内部交接不重复形成合并外部收入。
- **名义额与购买力分开。** 相对涨价不是全部通胀；汇率变化不重写原币余额；CapLab 的 Inverse Inflation 不能默认成为扣款算法。指数化只按明确合同。

## 5. 三个流程与分期

**雇员上任经理：** 生效任职/限额 → 取得限定资料 → 原采购端口重验资金库存 → 实际交付 → 回执 → 离职仍保留组织订单和资产。

**军官接替：** 原行动耗用先采纳 → 同一命令/运输任务继续 → 新任通过报告得知 → 有权提出真实缺口 → 到港、陆运、前线接收分别完成。

**行政岗位换人：** 公共账户/仓库/合同不变 → 未来权限改交新任 → 资料/保管实际交接 → 原到期责任继续支付或保留未偿 → 清算不删除开放责任。

| 阶段 | 目的与最小新增 |
| --- | --- |
| MVP | 有限地区内真实消费—劳动—生产—交易—运输循环，经理限额/换人，一条军需链，安全恢复；先核对十五算法和共同后端 |
| 后续一 | 少量服务/门店/租约、经营委托、真实研发/扩产；funded credit 银行中介、有限多币/股权，检查预算竞争与现金压力 |
| 后续二 | 异质地区、公共经济、重组/清算、长期成本与准入；信用创造/货币政策须另行论证，不自动加入 |

完整报告第 11 节有 12 条不变量和 20 个未来验收案例。优先验：无来源钱/货、同资源双用、换人丢责任、回执迟到重复采购、分段损耗/读档重复支付、银行双花、名义/实质混算及异质平均失真。当前都是设计验收，尚未跑游戏测试。
