# WWO 组织机制架构摘要

2026-10-13｜v2修订稿｜研究文档，未实现。详细来源见[完整研究](organization-research.md)，分层机制与113项见[军事活动覆盖与分层计算草案](military-activity-layering.md)。

**先完善同一世界的机制，再检查人物参与体验。** 机制不自动产生玩法，现实复杂度也不应全量逐人逐件模拟。人物通过工作/使命、有限信息、协商/执行/请求资源/拒绝及真实后果参与组织；身份、任职与控制焦点可以改变，不局限于升职。当前岗位权限限制参与，不裁掉世界活动目录。企业、行政、军事与社团共用制度结构，但不共用一套万能目标或成功公式。

## 少量组织对象

复用Organization、独立成员关系、Position、Appointment和范围授权；只补持续责任/交接及专业执行引用。成员≠雇员≠股东≠任职者；能看≠能拿；能批准≠有钱/材料；汇报/母子关系不自动授全部权。

```text
人物身份/任职 → 有依据的范围授权 → 提案/批准/命令
组织开放责任 → 经济真实承诺/生产/运输 → 军事物理执行
                    实际结果事件 → 按来源/时刻投递 → 人物所知/责任反馈
```

军事已有Task8、operation_intent、Information与Task6；组织不再造物理任务、消息调度或库存。组织责任的完成依据专业事件，不按“点了采购/下令成功”判完成。报价/预览用人物已知，新的提交重验当前人及专业条件；已经接受的合同/持续任务与尚在途命令有各自有效期/撤销规则，不因换任一律消失。

## 三算法的唯一事实

| 事实 | 推荐唯一归属 | 其他层的作用 |
| --- | --- | --- |
| 身份/生命/人口来源 | Person/Population | 军事身体给伤情与失效事件，经济劳动/需要引用；有效作战能力不是人头 |
| 地点/设施/连接与容量 | 统一人物位置provider及Spatial | 军事驱动物理动作，载具附着解释人物位置；任命不瞬移 |
| 每币现金、批次/权属/保管、预留、工时/合同/权益 | 经济账务/物流端口 | 军事提交实际消耗/交接/毁失候选，组织给授权和责任；宿主Ledger/CashAccounts/Task6不得三份双写 |
| 能力/编制、命令/行动/战损 | 军事专业状态 | 组织关联目标和负责人，经济共同采用资源变化，不重算战斗 |
| 岗位/任职/授权/持续责任 | 组织 | 薪资/产权/身体/实际任务分别留在专业域 |
| 报告/观察/知晓 | Information语义 | 实际记账不等报告到达；未回执不等失败，转发不刷新观察时刻 |
| 时间/组合次序/候选安装 | GameClock、Step、Persistence | 域游标只是处理进度，不能另走全局Clock |

任职更替保留组织/岗位/责任、订单和原签发历史；新任只获依法送达的交接资料与未来控制范围。控制焦点切换不复制知识、清空未决命令或刷决策间隔。亲自介入需资格、在场、工具、工时和同一任务交接，不能指挥官代所有专业人员或NPC和玩家双计产出。

## 分层计算的修正

模拟细度、当前决策权限、UI深度独立。显示展开可只读；无损表示拆分需原状态足够；改变物理模型不称无损。少量平均量、任意时点完整细节和非线性结果完全等价无法无条件同时满足。建议活动模型按世界事实固定，禁止按视角/焦点/负载换公式重算；真实新动作可改变未来条件。

已有具名ID/伤损/位置/任务/预留和已确定随机结果不能缩聚删除。匿名个体化从原人口来源扣覆盖，保留新ID且受准入限制；不因页面查看生成全国人物。休眠要么无必须变化，要么有可靠区间结算/下一阈值事件；离屏维护、损耗与义务照常发生。

日级策略与可中断过程分开。重大事件时先结旧段，再改变未来条件；不能整天先算完再回填中午，也不能声称保留旧经济日内行为同时获得全部即时变化。推荐统一可保留秒级边界的时间，日/月为投影；当前分钟宿主适配仍未核。共享窗口收齐请求、一次最终分配，避免调用顺序双花。负载不足放慢/限准入，不能删除开放责任或离屏免耗。

## 内容与参数边界

113项保留在12族目录，表中的军事/经济作者报告只是对应切面，不是全功能支持。新建工程、医院/卫生/战俘人道安置、研发/设计/转产、管道连续流、停火/占领及新技术任务需专门规则，不能换名称就说通用任务内核能执行。

商品自身先只有**单位重量、基础每日损耗率**；价格在市场；运输方式另有损耗率。组合公式和方式损耗按日/按程待定，不相加相乘、也不默认为零。运输“时效”按用户定义关注最终可用量，ETA另影响期限；损耗归经济物流唯一结算，战损/保存损耗不能重复扣同一货。

基础值后续依据现实资料近似填写游戏单位，不以模拟拟合。用户规划武器、战争方式、半沙盒半箱庭地块尺度与基础商品内容；本轮不抢定。覆盖、精度、操作、界面和实现成本的取舍由后续架构/工程协作继续处理。

## 机制验证切片与下一步

机构任命补给负责人→有限账户权限→经济真实订单/生产/装运→军事实际交接/守备→延迟回执→组织处理开放责任与未来任用。缺资源、未到港/前线、失联、换任、维修拆件和可用量不足均保留真实状态与可请求路径。此切片用于检查机制，不是最终内容上限或已验证玩法。

先核对本地较新军事实验、独立经济十五算法、宿主状态/Step/Persistence；产出已有接口/限制/缺口及取舍，不默认改代码。再接共同身份/位置/资源/时间与候选恢复，补相邻专业机制，按技术与内容扩展。联合验收须查守恒、同刻争用、随机/表示连续、中断/未决恢复；当前没有性能/实时UI或三算法整合通过结论。

六游戏来源与证据限制保留在完整报告：CK3任用关系、Bannerlord分派尺度、EVE权限/贡献、DF工作组织、Victoria3企业权利/资产、Suzerain人物反馈。新架构是WWO建议，不是它们共同已有实现。
