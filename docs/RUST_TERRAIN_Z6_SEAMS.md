# Z6 全球地貌接缝验收

候选为 `worldcrs84quad-15s-v2` 的完整 `6.qpk`，509,254,800 字节。全层检查和渲染均使用从私有发布恢复的候选库。单层离屏指定 `--terrain-level 6`，自动 LOD 和正式窗口使用同一候选库。QPK 复用。正式资源和存档未替换。

## Z5/Z6 与 Z6/Z7

- **Z5/Z6 通过取景回归。** PR #144 基线在阿尔卑斯停在 1,060 米／像素时，第 16 帧 `6/68/16` 已占 93.3%，北侧 `6/68/14` 和东侧 `6/71/16` 仍由 Z5 绘制。连续帧的 RGB 变化沿页边界先后出现。Z6 复用 Z7 的整幅过渡机制。候选在阿尔卑斯、尼罗河三角洲及安第斯使用相同输入，各 102 帧。九点 Z6 权重的最大空间差从 1 降为 0。慢缩放、反复越阈值和瓦登海缩放加平移旋转另有连续帧。
- **Z6/Z7 普通过渡。** 阿尔卑斯与反经线均达到完整 Z7，382 帧的九点混合权重各帧一致。反经线北纬 67.5° 回到 1,055–1,150 米／像素时，Z6 缺 2–5 张，整幅纯 Z5 持续 4 帧。末帧 Z6 权重恢复至 67.4%。尼罗河快速往返也出现过缺页后整幅回退，未见矩形。保留这些容量与时序限制。
- **530→970 米／像素快拉远。** Z7 层缺页时仍整幅退到完整 Z6，存在一帧纹理阶跃。Z6 整幅过渡初版在阿尔卑斯缺 14 张 Z6 页，会多退一层。最终用 256 页内的剩余位置预取两倍跨度的父页，普通视口与原有预取环优先。阿尔卑斯、瓦登海各两次快速拉远均在首帧绘制完整 Z6，Z7 各缺 58、56 张。回到 530 后，Z7 在完整 Z6 上整幅淡入。参见 [Z7 快拉远同倍率对照](RUST_TERRAIN_Z7_SEAMS.md#530--970-米像素专项收尾)。

## 正式 Rust 游戏

候选 Release 版以 1280×720、RTX 3050 Laptop GPU 和 Vulkan 后台运行。地理、政治、经济和军事专题实际进入，从 2,300 缩至 1,060 米／像素并反复缩放、平移。临时配置和暂停的测试会话独立。窗口全程无焦点。军事专题检查限于球面地图。
