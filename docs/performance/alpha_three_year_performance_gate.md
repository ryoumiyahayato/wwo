# Alpha 三年性能门禁调查

## 范围与结论

本调查针对统一验证中的
`tests/alpha/alpha_ai_economy_stability_test.gd`。它保留 15 项检查、三年
`26,280` 个模拟小时、固定随机种子 `1001900` 和完整 Alpha fixture。
调查没有缩短模拟、减少检查、改变随机数调用顺序、存档 schema、Alpha
经济规则或正式历史世界规则。

结论分类为 **D**：

- 存在稳定、可复现的生产热点，主要位于固定通勤扫描、背景人物小时处理、
  日结回滚快照、运输短缺调度、生活需求规划和商品日结；
- 单次墙钟时间也存在显著运行环境波动。相同 Windows、相同
  `4.6.3.stable.official.7d41c59c4`、相同提交的五次运行范围达到
  `154.156896` 秒，最慢值比最快值高 `83.34%`。

因此，单次 180 秒断言不能稳定区分代码回退和 Runner 抖动。180 秒仍是
正式目标，但由同一 Runner 上五次 Head 运行的中位数判断；同时保留
300 秒单次绝对安全上限，并要求 Head/Base 中位数比不超过 `1.05`。

只读阶段探针的每个 override 都只调用一次原实现，并在返回后记录耗时和
调用次数。Base 与优化后的 Head 均处理 `26,280` 个小时和 `1,095` 次
日结，没有重复初始化、重复日结或跳过小时。

调查同时检查了：

- 每小时全人口、全企业和全地区扫描；
- 候选排序与重复分配；
- Dictionary 深复制；
- 快照与序列化；
- 重复经济日结；
- 运输队列全量遍历；
- 测试日志构建与重复初始化。

主要可控浪费是按小时重复深复制只读权威配置、已按开始时间排序的日程仍
全量扫描、以及同一日结内重复计算不变的运输目标库存。测试本身没有重复
初始化，也没有重复结算同一个经济日。

## 受控优化

生产优化只减少重复工作：

- 日程查询利用既有的开始时间排序不变量，在已越过可能匹配范围后停止；
- 高频只读配置查询直接读取权威文档，只对最终返回记录进行深复制；
- 一次短缺运输日结内复用不会在该调用中变化的目标库存计算结果。

没有新增 Manager、Autoload、全局变量、持久缓存、兼容别名、fallback
或双写字段。库存仍在每次访问时从权威商品市场读取，局部 memo 只存活于
一次日结调用。

## 结果等价性

优化前后 30 日运行使用相同 fixture 和随机数顺序，归一化状态 SHA-256
均为：

`a326a77ba8e6f4dc284f98eae3a94bff748499ba53e8d0bc6b37403dceb34f54`

三年 Head 保存与恢复的归一化状态 SHA-256 均为：

`fa23989b32e7595d641d529122b456579c94d1768334e046c1f3df8ee546f261`

归一化只排除纯计时字段 `alpha_maximum_hour_usec`，并对语义为集合的
`processed_keys` 排序。原始首差异诊断证明未归一化的保存/恢复首个差异
只是该集合的序列化顺序；世界摘要、库存、价格、运输、人口、就业和经济
结果保持一致。

项目 GDScript、场景和项目配置中没有 Godot 网络 API 引用。生产差异没有
新增日志语句；Base 与 Head 使用同一份测量脚本。下载 Godot 发生在 CI
测量前，测量期间编排脚本不发起网络请求，也不运行调试器、截图任务或
并发测试。

## 门禁语义

`.github/workflows/alpha-three-year-performance.yml` 在同一个固定
`windows-2022` Runner 中：

1. 检出 PR Base 和 Head；
2. 使用完全相同的 Godot `4.6.3`、测试脚本、fixture、种子和小时数；
3. 分别冷导入；
4. 按 Base、Head 交错顺序各运行五次；
5. 上传每次原始日志和结构化 JSON 报告。

通过条件全部满足才成功：

- Head 五次运行中位数小于 180 秒；
- Head nearest-rank P90 小于 300 秒绝对安全上限；
- Head/Base 中位数比不超过 `1.05`；
- 每次执行全部 15 项检查和 `26,280` 小时；
- 所有 Base/Head 运行产生同一个归一化状态哈希和世界摘要；
- 每次保存/恢复成功且恢复哈希相同；
- 单小时结算仍不允许达到一秒；
- 没有网络 API、调试器、截图或并发测试干扰。

这种门禁没有让明显退化通过：稳定回退会触发 180 秒中位数或 5% 相对
退化限制，极端尾部回退会触发 300 秒 P90 或单次绝对上限。
