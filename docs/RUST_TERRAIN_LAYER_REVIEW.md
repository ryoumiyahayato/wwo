## 冻结抽样

洲界用 Natural Earth Admin 0 Map Units 1:110m v5.1.1 的 `CONTINENT`。Seven seas 记录按该数据的 `REGION_UN` 归洲。陆地用 Natural Earth Land 1:10m v5.1.1。陆地多边形与一个洲相交时整块归入该洲。与多个洲相交时按洲界切分，剩余碎片按其内部代表点归入最近洲。无交集的岛屿归最近地图单元所属洲。最近单元按经纬度平面距离查找，经度在 ±180° 环绕，同距按洲名排序。跨洲分类沿用 Natural Earth 地图单元口径。[洲界来源](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-details/) · [陆地来源](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)

同一抽样层 Z5。候选包含与该洲陆地有正面积交集的瓦片，按 Z/X/Y 升序排列。本轮可取得的旧截图为固定取景，没有冻结的上轮随机名单可供排除。CPython 3.12.15 `random.Random(20261115)` 的 MT19937 按下表顺序调用 `randrange(候选数)`，每洲抽取一次。几何计算用 Shapely 2.2.0、GEOS 3.14.1、PyShp 3.1.7。中心不在陆地时，用 PyProj 3.8.0 和 PROJ 9.8.1 的 WGS84 方位等距投影，以瓦片中心为原点，沿裁切后的海岸线找最近点，同距按经度、纬度排序。北美取景点因投影线性化与源海岸线相差约 3 厘米。

两档取景共用下表中心。北向上，1280×720，区域方位等距投影。区域档 4500 米／像素，目标 Z4。近景档 1000 米／像素，目标 Z6。实际层级以渲染记录为准。

## 离屏结果

RTX 3050 Laptop GPU，Vulkan。观察回执显示独立地图模式、无窗口焦点、无正式会话。各批顺序执行。四批的指定层截图分别达到 Z0–Z3、Z4–Z5、Z6、Z7。样本中心依次为 `0/1/0`、`1/2/0`、`2/5/1`、`3/11/2`、`4/23/4`、`5/47/8`、`6/95/17`、`7/190/34`。视口中落在地球上的采样点均由当次指定层贡献。单层替换入口用现有 `7.qpk` 试读。`--terrain-max-level 0` 在阿尔卑斯 400 米／像素时仍绘制 `0/1/0`。

每洲区域档目标及实际均为 Z4，近景档均为 Z6。稳定时九处地表采样点均由目标层贡献，无父级混合。截图与同名 JSON 位于本地 `offline-map-sources/migration-20261115/terrain-review-20261115/auto-final`，文件名为表中前缀加 `-region` 或 `-close`。

180° 经线两档中心为 `4/31/2`、`6/127/8`，东边缘为 `4/4/3`、`6/4/8`。未见明显接缝。北、南极区域档中心为 `4/20/0`、`4/28/15`。近景目标 Z6 的候选达 572 页，超过 256 页缓存。两极稳定使用 Z5，中心为 `5/40/0`、`5/56/31`。极点经度受投影奇异性影响。北极画面无海冰表示，南极雪地对坐标文字的对比度偏低。阿尔卑斯指定 Z6，中心 `6/68/15`，跨 X67／68 的画面未见明显缝线。

阿尔卑斯九档稳定取景实际为 Z5、Z5、Z6、Z7、Z7、Z7、Z6、Z5、Z5。从 4500 直接切到 400 米／像素的加载帧，中心 `5/34/7` 权重 38.8%，`4/17/3` 权重 61.2%，最终 `7/136/31` 权重 100%。两帧未见黑块，截图不能排除帧间闪烁。首次后台运行发现终态权重未写满。修复依据改为页表已写的淡入权重。原样本复验后均达到稳定状态。

有界离屏观察记录空闲 23 个帧间隔，中位 49.0 ms，最大 50.1 ms。九档交互记录 65 个帧间隔，中位 34.8 ms，最大 51.2 ms。离屏调度设有 33 ms 提交间隔，此数据仅记录本轮调度，正式游戏帧率和高压负载未测试。

九点数据来自 CPU 投影和提交至 GPU 的页表，包含中心、四边中点和四角。紧贴分片边界可能受浮点差异影响。截图保留原有 HUD。没有复做全层解码或改写 QPK。旧清单的顶层压缩表述和 Alpha 水面覆盖说明有误，二进制按实际 `WWOQ4PK2` 和 Zstandard 读取。
