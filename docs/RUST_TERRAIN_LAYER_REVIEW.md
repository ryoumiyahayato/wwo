## 冻结抽样

洲界用 Natural Earth Admin 0 Map Units 1:110m v5.1.1 的 `CONTINENT`。Seven seas 记录按该数据的 `REGION_UN` 归洲。陆地用 Natural Earth Land 1:10m v5.1.1。陆地多边形与一个洲相交时整块归入该洲。与多个洲相交时按洲界切分，剩余碎片按其内部代表点归入最近洲。无交集的岛屿归最近地图单元所属洲。最近单元按经纬度平面距离查找，经度在 ±180° 环绕，同距按洲名排序。跨洲分类沿用 Natural Earth 地图单元口径。[洲界来源](https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-details/) · [陆地来源](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)

同一抽样层 Z5。候选包含与该洲陆地有正面积交集的瓦片，按 Z/X/Y 升序排列。本轮可取得的旧截图为固定取景，没有冻结的上轮随机名单可供排除。CPython 3.12.15 `random.Random(20261115)` 的 MT19937 按下表顺序调用 `randrange(候选数)`，每洲抽取一次。几何计算用 Shapely 2.2.0、GEOS 3.14.1、PyShp 3.1.7。中心不在陆地时，用 PyProj 3.8.0 和 PROJ 9.8.1 的 WGS84 方位等距投影，以瓦片中心为原点，沿裁切后的海岸线找最近点，同距按经度、纬度排序。北美取景点因投影线性化与源海岸线相差约 3 厘米。

两档取景共用下表中心。北向上，1280×720，区域方位等距投影。区域档 4500 米／像素，目标 Z4。近景档 1000 米／像素，目标 Z6。实际层级以渲染记录为准。
