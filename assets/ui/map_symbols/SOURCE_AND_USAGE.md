# WWO R47 地图符号

原创图形。未采集第三方图标、历史图例扫描或模型截图。图形源按CC0-1.0提供；此许可仅适用于本目录图标美术，不改变原历史GIS、国旗或古迹模型的许可。

运行只读`map_symbols.png`共享图集、`symbols.json`图集与LOD表、`place_bindings.json`既有身份对应。15张128×128独立RGBA PNG保留作为可编辑输出，地图不逐地点读取它们。图集576×576，单格144×144、图形128×128、四边各8像素透明隔离。

制作源：`tools/map/build_map_symbols_r47.py`及`tools/map/art_sources/map_symbols_r47/*.svg`。Pillow为离线依赖，不进入游戏。修改脚本后运行Python生成；SVG也可独立编辑，但随后重新运行脚本会覆盖SVG和PNG。脚本内统一几何为可再生成的主源。

象牙金#D7C7A2、古铜#A88A52、深褐#493D2D、银灰#D9DDE0。128像素主描边6像素、外缘9像素；没有全图底板、厚阴影或金属浮雕。6倍采样后Lanczos缩小；零Alpha像素RGB清零。图集Godot导入开启Mip和fix_alpha_border，保持直Alpha，不预乘。原图和图集均无白底、黑底或棋盘内容。

正常状态原色，悬停轻微增亮，选中用底部8像素细金线；不可选择记录可降亮且不加入图标拾取表。不为这些状态另建材质或独立纹理。

`capital_links`只连接已有明确历史capital声明与已登记地点：名称对应且已有坐标相距小于10公里、唯一匹配才收录；记录两个来源。10公里是别名核对范围，不是地理准确度。24项对应中，16项沿用independent_state/belligerent_state关系，8项是controlled_territory/protected_territory行政驻地，后者用菱形，不画国家首都星。并非凭普通城市名称或rank认定首都；运行时还检查当前政治显示快照的capital名和有效期。未匹配地点不补造ID。

一级首府来自既有`capital_place_id`；当前法国明确链接巴黎与凡尔赛。区县中心只使用当前行政显示请求中已有的`capital_lon_lat`与原行政ID，不把省形心当城市。没有定位的首府不生成地点。125个既有图鉴chief-city ID共用城市图形；巴黎由首都优先覆盖。Creil依据已存Baedeker巴黎指南正文第377页的town表述使用城镇图形。rank不反推村庄、人口或行政等级。

`religious_temple`用于已登记天坛祈年殿，`religious_dome`用于圣索菲亚既有奥斯曼时期建筑参考；不把欧洲教堂图标套到这些地点。城堡、普通教堂和村庄图形已制成，但当前缺少可安全自动对应的已准入类型时不强行使用。旧`symbol_kind=monument`过宽，一般退到历史遗址；只有明确塔/纪念性类型使用纪念柱。

原世界事实、行政成员、实际控制、人口、交通与经济计算均不由图标改变。模型许可隔离保持。缩略接触图在工具源目录，仅供美术查看，不进入运行包。
