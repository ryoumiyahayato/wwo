# DEBOER2009

[Modeling household behavior in a CGE model: linear expenditure system or indirect addilog?](https://repub.eur.nl/pub/18250/EI%202009-16.pdf)

实际阅读：§II Theory; printed4–7/PDF3–6。版本：Econometric Institute Report EI2009-16。

比较LES与间接addilog(IAS)的需求限制。假设预算可行、价格给定、连续商品与效用最大化；分析者校准家庭参数，不涉及局部搜寻。输入m,p，状态为系数c与β（或LES最低量/份额），输出预算份额s_i=c_i(m/p_i)^βi/Σc_j(m/p_j)^βj及x_i=ms_i/p_i；参数满足正文非负/弹性限制。IAS弹性模式更灵活，LES最低量非负时存在强弹性限制；不是任意现实偏好保证。商品单位和价格归一化须一致，参数不能跨单位直接复制。证据为解析比较；未读完整实验。复杂度原文UNKNOWN；独立一次份额归一化O(n)。

WWO反例（独立）：软份额可能低于明确生理最低量；多弹性参数不自动实现需要层级或缺货替代。可作LES限制性对照，DEFER运行需求系统：当前没有校准家庭数据，不能凭作者推荐挑选机制。
