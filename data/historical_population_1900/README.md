## 开局、原统计与差额

旧 50 个经济单元合计 1,411,020,000 人。逐行检查均只有共用方法和估计区间，缺少单元专属普查日及原表定位。另有八个经济残余组，合计 237,600,000，成员列表不足以与原 50 组排重。新世界研究估计较旧 50 项多 184,054,248 人。差额包括旧表缺收地域、来源修订、疆域和日期差异。因原表成员界线不全，无法逐人归因。[50 个单元及八个残余组的核对](legacy_audit.json)

全球工作簿 V5 年中数为 1,601,675,694。用 1899、1900 年两列原始千人数，按相距 365 天中的 184 天内插，再换算成人。V5 汇总列了 160 个单位，明细只找到 159 个。特鲁西尔海岸以 V4 实际列补入并标版次。160 项逐项取整合计 1,595,074,246，比直接内插世界汇总少 2 人。美国人口普查局所列 1900 年历史研究范围为 15.50 亿至 17.62 亿，其中联合国 1999 年版采用 16.50 亿。这个范围反映文献分歧。[逐年逐区差额](collections/world/reconciliation.json) · [存档工作簿](collections/world/raw) · [方法附录 I](https://hdl.handle.net/10016/45843) · [独立世界基准](https://www.census.gov/data/tables/time-series/demo/international-programs/historical-est-worldpop.html)

## 重建、正式查询与存档

从仓库根运行。Python 3.10 及以上，世界研究工作簿使用 `openpyxl`。`--from-sources` 从 Git 已存档的工作簿、原表数字摘录和对照表重建各地区数据，再生成同一版全球产物。来源目录给出出版者、文档、许可或数字摘录范围、印刷页、表号、工作表单元格。需重新采集的文档可按对应来源和地区提取程序取得。

```sh
python data/historical_population_1900/build.py --from-sources
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population us_state_new_york
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population world
```

`population_1900.jsonl.gz` 每行含单位、父级、日期、数值、来源、页表、口径、方法、质量和地域状态。地理有效期与调查日期分别保存。用 `record_id` 从城市和地域索引回查原行，用 `source_id` 查出版资料。研究观测、母项、子项和不同史料可指向同一批人。正式新游戏读取 `opening_v2.json` 及 `opening_structure.json`。完整分区之和等于父级。部分已定位的旧账户中，分区之和加未定位余额等于旧总数。v1 存档继续读取 `opening.json`。

正式游戏沿用 Rust `Population`。迁移、具名化和征召共用人口余额。模拟出生及死亡进入同一人口日志，旧原生存档和旧平面快照按原开局恢复。`inspect-population city:<key>` 返回原日期城市参考。以正式存档查询世界或地区时，报告区分开局依据、当前人数和运行期间的人口。全球历史年龄分层、消费篮子、城乡与地图边界仍待核。[Rust 入口和存档说明](../../rust/strategic-host/README.md) · [正式人口读取器](../../rust/strategic-host/src/formal_population/opening.rs)

Windows 调试版由 `--play` 新建法国开局并写原生手动档，恢复世界总量 1,457,759,052，含 150,314,637 名年龄和性别均可报告的群体居民。一年期测试分别运行正式开局及另加 4,900 个合成群体的世界，两次均恢复完整快照。仅执行人口相关局部测试。全仓库回归为 `NOT_RUN`，未独立复核的档案为 `UNVERIFIED`。
