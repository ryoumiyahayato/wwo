# 1900 年全球人口数据综合报告

**状态：PARTIAL。** 开局日为 1900-01-01。同一版资料包含全球统计目录、逐表摘录、地域对应、城市与人口结构、差额，以及正式世界实际读取的人口。全球研究基准为 **1,595,074,248 人**。已从有定位出处的资料接入 **548,691,244 人（34.399%）**。其中 393,051,890 人有可互斥相加的开局分区。按此基准，仍有 **1,046,383,004 人**缺少获准用于正式开局的地域账。分母本身也是研究估计。[发布统计](summary.json) · [生产开局](opening.json) · [PR #196](https://github.com/ryoumiyahayato/wwo/pull/196)

## 开局、原统计与差额

旧 50 个经济单元合计 1,411,020,000 人。逐行检查均只有共用方法和估计区间，缺少单元专属普查日及原表定位。另有八个经济残余组，合计 237,600,000，成员列表不足以与原 50 组排重。新世界研究估计较旧 50 项多 184,054,248 人。差额包括旧表缺收地域、来源修订、疆域和日期差异。因原表成员界线不全，无法逐人归因。[50 个单元及八个残余组的核对](legacy_audit.json)

全球工作簿 V5 年中数为 1,601,675,694。用 1899、1900 年两列原始千人数，按相距 365 天中的 184 天内插，再换算成人。V5 汇总列了 160 个单位，明细只找到 159 个。特鲁西尔海岸以 V4 实际列补入并标版次。160 项逐项取整合计 1,595,074,246，比直接内插世界汇总少 2 人。美国人口普查局所列 1900 年历史研究范围为 15.50 亿至 17.62 亿，其中联合国 1999 年版采用 16.50 亿。这个范围反映文献分歧。[逐年逐区差额](collections/world/reconciliation.json) · [存档工作簿](collections/world/raw) · [方法附录 I](https://hdl.handle.net/10016/45843) · [独立世界基准](https://www.census.gov/data/tables/time-series/demo/international-programs/historical-est-worldpop.html)

正式开局使用 39 个历史统计组。其中 17 组采用地域普查、年鉴及其回估，计 257,115,347 人；22 组采用已核对范围的历史研究重建，计 291,575,897 人。25 个原经济单元已替换，另增 14 个独立地域。余下 25 个原单元仍有 863,620,000 人沿用旧估计。新档人口权威合计 **1,412,311,244**，其中同时含历史来源与旧估计。研究总量不参与补齐。市场数量与人口单位数量分别维护。[正式开局](opening.json) · [研究序列选用依据](opening_series.tsv)

## 重建、正式查询与存档

从仓库根运行。Python 3.10 及以上，世界研究工作簿使用 `openpyxl`。`--from-sources` 从 Git 已存档的工作簿、原表数字摘录和对照表重建各地区数据，再生成同一版全球产物。来源目录给出出版者、文档、许可或数字摘录范围、印刷页、表号、工作表单元格。需重新采集的文档可按对应来源和地区提取程序取得。

```sh
python data/historical_population_1900/build.py --from-sources
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population us_state_new_york
```

`population_1900.jsonl.gz` 每行含单位、父级、日期、数值、来源、页表、口径、方法、质量和地域状态。日期精度随原表；地理有效期与调查日期分别保存。可用 `record_id` 从城市和地域索引回查原行，用 `source_id` 查出版资料。研究观测、母项、子项和不同史料均可指向同一批人。实际新开局只读取 `opening.json` 中互斥余额，父级汇总由其分区构成。

正式世界沿用既有 Rust `Population`。已知出生地和居住地使用核实过的分区，迁移、具名化和征召从对应余额扣除。读取旧原生存档或旧平面快照时保留旧初值和原账；新存档带开局版本，重复读取不会补生人口。局部测试覆盖分区、征召冲突、旧档回放及六个正式开局。全球高分辨率人口分布仍未通过生产验收。[Rust 入口和存档说明](../../rust/strategic-host/README.md) · [正式人口读取器](../../rust/strategic-host/src/formal_population/opening.rs)
