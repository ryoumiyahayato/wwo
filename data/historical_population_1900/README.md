## 开局、原统计与差额

旧 50 个经济单元合计 1,411,020,000 人。逐行检查均只有共用方法和估计区间，缺少单元专属普查日及原表定位。另有八个经济残余组，合计 237,600,000，成员列表不足以与原 50 组排重。新世界研究估计较旧 50 项多 184,054,248 人。差额包括旧表缺收地域、来源修订、疆域和日期差异。因原表成员界线不全，无法逐人归因。[50 个单元及八个残余组的核对](legacy_audit.json)

## 重建、正式查询与存档

从仓库根运行。Python 3.10 及以上，世界研究工作簿使用 `openpyxl`。`--from-sources` 从 Git 已存档的工作簿、原表数字摘录和对照表重建各地区数据，再生成同一版全球产物。来源目录给出出版者、文档、许可或数字摘录范围、印刷页、表号、工作表单元格。需重新采集的文档可按对应来源和地区提取程序取得。

```sh
python data/historical_population_1900/build.py --from-sources
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population us_state_new_york
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population world
```

`population_1900.jsonl.gz` 每行含单位、父级、日期、数值、来源、页表、口径、方法、质量和地域状态。地理有效期与调查日期分别保存。用 `record_id` 从城市和地域索引回查原行，用 `source_id` 查出版资料。研究观测、母项、子项和不同史料可指向同一批人。正式新游戏读取 `opening_v4.json` 及 `opening_structure_v4.json`。完整分区之和等于父级。部分分区之和加未定位余额等于对应旧人口或研究控制。v1 至 v3 存档继续读取冻结的对应输入。

正式游戏沿用 Rust `Population`。迁移、具名化和征召共用人口余额。模拟出生及死亡进入同一人口日志，旧原生存档和旧平面快照按原开局恢复。`inspect-population city:<key>` 返回原日期城市参考，`inspect-population history:<unit-id>` 查询同一历史单位的地理、人数和人口结构原表。`inspect-food-history` 查询已录的住户账本。`inspect-age-range <world|unit-id> <min> <max> [<native-save>]` 返回年龄区间确定人数和可能人数，并单列已服役者。年龄区间是人口统计量，职业资格和各地征兵制度仍缺地区参数。全球历史年龄分层、消费篮子、城乡与地图边界仍待核。[Rust 入口和存档说明](../../rust/strategic-host/README.md) · [正式人口读取器](../../rust/strategic-host/src/formal_population/opening.rs)

Windows 调试版由 `--play` 新建法国开局并写原生手动档，恢复世界总量 1,458,689,022。226,362,595 名群体居民有年龄区间和性别，212,117,029 人可计算膳食能量参考。此前 v2 游戏手动档仍恢复 1,457,759,052 人。一年期局部测试分别运行正式开局及另加 4,700 个合成群体的世界，两次均恢复完整快照。全仓库回归为 `NOT_RUN`，未独立复核的档案为 `UNVERIFIED`。
