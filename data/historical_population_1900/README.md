## 开局、原统计与差额

旧 50 个经济单元合计 1,411,020,000 人。逐行检查均只有共用方法和估计区间，缺少单元专属普查日及原表定位。另有八个经济残余组，合计 237,600,000，成员列表不足以与原 50 组排重。新世界研究估计较旧 50 项多 184,054,248 人。差额包括旧表缺收地域、来源修订、疆域和日期差异。因原表成员界线不全，无法逐人归因。[50 个单元及八个残余组的核对](legacy_audit.json)

全球工作簿 V5 年中数为 1,601,675,694。用 1899、1900 年两列原始千人数，按相距 365 天中的 184 天内插，再换算成人。V5 汇总列了 160 个单位，明细只找到 159 个。特鲁西尔海岸以 V4 实际列补入并标版次。160 项逐项取整合计 1,595,074,246，比直接内插世界汇总少 2 人。美国人口普查局所列 1900 年历史研究范围为 15.50 亿至 17.62 亿，其中联合国 1999 年版采用 16.50 亿。这个范围反映文献分歧。[逐年逐区差额](collections/world/reconciliation.json) · [存档工作簿](collections/world/raw) · [方法附录 I](https://hdl.handle.net/10016/45843) · [独立世界基准](https://www.census.gov/data/tables/time-series/demo/international-programs/historical-est-worldpop.html)

## 城市、城乡与人口结构

俄罗斯帝国的基辅、波尔塔瓦、萨马拉、沃罗涅日四省分成 46 县，共 12,276,283 人。1900 年官方名录核对县名及隶属。1897 年普查各县的总数、男女及城乡均闭合到省，城市纳入县内。按 1897 年县人口份额在原省开局人口内分配。县级男女结构使用县普查与地区年龄比例，出生、迁移和小范围边界差异的误差未量化。宗教、母语、法定身份等资料继续依原省口径显示。[县目录、日期与原表](collections/russia_1900_districts)

## 重建、正式查询与存档

清末调查章程单列七岁学童及十六岁壮丁，无法给出各年龄段。1912 年重刊的二十省大表有三档印刷合计与男女分项不符，缺同范围分省校准。台湾 1905 年现住普查有按性别的虚岁原表，原表 3,039,751 人含 7 人年龄未报。1899 年末户籍 2,759,453 人与 1905 年调查缺少互相兼容的居住范围和辖区对应。清帝国及台湾暂未分配年龄性别。[清末调查章程](https://ctext.org/wiki.pl?chapter=2300409&if=gb) · [1912 年重刊表](https://fileserver-az.core.ac.uk/download/41449644.pdf#page=6) · [台湾 1905 年原表](https://dl.ndl.go.jp/pid/805872/1/17) · [台湾 1899 年原卷](https://www.digital.archives.go.jp/item/750223)

从仓库根运行。Python 3.10 及以上，世界研究工作簿使用 `openpyxl`。`--from-sources` 从 Git 已存档的工作簿、原表数字摘录和对照表重建各地区数据，再生成同一版全球产物。来源目录给出出版者、文档、许可或数字摘录范围、印刷页、表号、工作表单元格。需重新采集的文档可按对应来源和地区提取程序取得。

```sh
python data/historical_population_1900/build.py --from-sources
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-pop empire_of_japan
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population us_state_new_york
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population world
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-population-structure region:Asia
cargo run --locked --manifest-path rust/strategic-host/Cargo.toml --bin wwo-formal-state -- inspect-market-livelihood russian_empire
```

`population_1900.jsonl.gz` 每行含单位、父级、日期、数值、来源、页表、口径、方法、质量和地域状态。地理有效期与调查日期分别保存。用 `record_id` 从城市和地域索引回查原行，用 `source_id` 查出版资料。研究观测、母项、子项和不同史料可指向同一批人。正式新游戏读取 `opening_v16.json`、`opening_structure_v16.json` 和 `opening_social_v16.json`。完整分区之和等于父级。部分分区之和加未定位余额等于相应开局控制。v1 至 v15 存档继续读取冻结的对应输入。

正式游戏沿用 Rust `Population`。迁移、具名化和征召共用人口余额。模拟出生及死亡进入同一人口日志，旧原生存档和旧平面快照按原开局恢复。`inspect-population city:<key>` 返回原日期城市参考，`inspect-population history:<unit-id>` 查询同一历史单位的地理、人数和人口结构原表。`inspect-food-history` 查询已录的住户账本。`inspect-age-range <world|unit-id> <min> <max> [<native-save>]` 返回年龄区间确定人数和可能人数，并单列已服役者。年龄区间是人口统计量，职业资格和各地征兵制度仍缺地区参数。全球历史年龄分层、消费篮子、城乡与地图边界仍待核。[Rust 入口和存档说明](../../rust/strategic-host/README.md) · [正式人口读取器](../../rust/strategic-host/src/formal_population/opening.rs)
