# 朝鲜半岛开局年龄与性别估计

韩国保健社会研究院在附表 5 列出 1925 年普查两性的互斥年龄档，共 19,020,030 人。其中男 9,726,150、女 9,293,880。75 岁以上、80 岁以上及 85 岁以上保留为小计。各互斥档与两性总数闭合。[普查数据刊表，第 96 页](https://repository.kihasa.re.kr/bitstream/201002/6100/1/%EC%97%B0%EA%B5%AC_2010-30-6.pdf)

普查包括整个半岛。这张年龄表的总数对应朝鲜人，普查另外登记了 502,915 名非朝鲜人。使用其联合年龄性别分布估计既有 1900 年朝鲜帝国人口池，保留开局总人口。25 年间的人口变化及小群体分布未量化。[Cha 与 Kim，2012，表 3](https://wid.world/document/koreas-first-industrial-revolution-1911-1940-explorations-in-economic-history-2012/) · [1925 年普查原件目录](https://lib1.mods.go.kr/search/detail/STSSTM000000003245)
