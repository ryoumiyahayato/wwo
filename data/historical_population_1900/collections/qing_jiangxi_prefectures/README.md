# 江西府州人口

曹树基《中国人口史》第五卷《清时期》第 535 页表 12–13。黄志繁和杨金鹏在《江西社会科学》2016 年第 6 期第 124 页表 1 复列。CSV 存 1865 和 1910 年人口重建值，原表最小刻度为千人。十三府和宁都直隶州分别闭合到 12,566,000 和 14,961,000。[复列表](https://yangtze.silkroadinfo.org.cn/2016/9/18/20160918094227.pdf#page=2)

江西开局省额保持 14,385,490 人。省额由 1880 年 13,316,000 与 1910 年 14,961,000 插值。1910 年府州合计匹配省额晚锚。按 1910 年的各府州占比和最大余数法分配至 1900 年。以 1865 年份额计算敏感性，最大单项差额为吉安府的 160,873 人。府州范围和时间误差无校准区间。1880 年府州原表、年龄和性别仍缺。[省级原表](https://www.tup.tsinghua.edu.cn/upload/books/yz/096340-01.pdf#page=31) [分府附录书目](https://doi.org/10.1163/9789004688933_025)

婺源属安徽。景德镇归饶州府浮梁县。九江商埠和租界沿用公布分母，无独立加项。虔南厅设于 1903 年，沿用析置前赣州府范围。铜鼓营在开局时属南昌府义宁州。1907 年当地瑞州同知扩治安权限，1910 年奏准民政改隶南昌府，钱粮一直归义宁州。两期发布表沿用府级统计域。地名库标识用于历史地域定位。[清史稿](https://zh.wikisource.org/zh-hans/%E6%B8%85%E5%8F%B2%E7%A8%BF/%E5%8D%B766) [饶州府](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_32621) [宁都州](https://tgaz.fudan.edu.cn/tgaz/placename/hvd_32578) [虔南厅](https://www.ganzhou.gov.cn/gzszf/c100172/201205/ef9972d8947947a2ae48144fe51994f9.shtml) [铜鼓厅民政部会奏](https://zh.wikisource.org/zh-hans/%E7%94%B3%E5%A0%B1/1910/12/19)
