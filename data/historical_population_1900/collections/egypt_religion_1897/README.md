# 埃及三省 1897 年宗教

取棚田博文在一桥大学发表的 1897 年普查转录。Faiyum、Gharbiya、Jirja 三省宗教分项闭合。三省的总人数和男女数也分别与 1907 年普查表 5 所列 1897 年比较控制闭合。其余省的对读发现范围差或分类差，保留未知。

开局维持各省 1897 年的宗教比例，按已有 1900 年省人口控制取整。教派使用三省可比较的基督宗教合计。1897 至 1900 年宗教构成的变化无可用误差区间。F7 可查原表人数、开局分配及宗教饮食规范适用人数。实际遵守人数未知。
