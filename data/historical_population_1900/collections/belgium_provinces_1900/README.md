# 比利时九省人口普查

1890 和 1900 年末均用九省通常居民数，包括暂时离开者。疆域包含当时未拆分的布拉班特。按两期人口内插至 1900 年元旦，得 6,631,330 人。[来源](sources.json) · [省人口原数](observations.jsonl)

1900 年末的年龄、所讲语言和婚姻均逐省、逐性别闭合至 6,693,548 人。年龄是 0–14、15–54、55 岁及以上，共三档。所讲语言有八种全国语言组合，原表明示三种全国语言都不说者 350,263 人。婚姻分四类。三项各按各省比例分配到元旦开局，结构变化未量化。[年龄](age_sex.csv) · [语言](spoken_languages.csv) · [婚姻](marital_status.csv)

国籍与出生地交叉表属于历史参考。原表外籍 206,061 人。正式 POP 尚未分配国籍与出生地。[原表摘录](citizenship_by_birthplace.csv)
