# 印度地方普查年龄与性别（1891、1901）

`age_sex.csv` 保留两期统计摘要和 1901 年中央省地方原卷的数据。`panels.json` 记录原表行、统计范围和已知差额。日期为 1891-02-26 和 1901-03-01。两次普查的开局内插只在同范围男女总数闭合时使用。 [1891 摘要原表](https://dsal.uchicago.edu/statistics/1885_excel/1885.18.XLS) · [1901 摘要原表](https://dsal.uchicago.edu/statistics/1894_excel/1894.014.XLS)

| 开局范围 | 开局人口 | 年龄和性别已分组 | 方法 |
| --- | ---: | ---: | --- |
| 布莱尔港定居区 | 16,181 | 16,181 | 两期年龄性别分档内插，保持定居区范围 |
| 朗普尔和特赫里土邦合计 | 800,983 | 800,685 | 两期年龄性别分档内插，保留 298 人年龄未知 |
| 中央省土邦 | 2,015,423 | 2,015,423 | 两期男女总数内插，按 1901 年地方原卷七档分配 |

布莱尔港和联合省土邦的摘要高龄栏定义不一致，两期归到 45 岁及以上后内插。中央省统计摘要的 1891 年女性年龄档少 90,000 人，1901 年男性年龄档少 2,000 人，两表仅用于保留史料和核对总数。1901 年中央省普查卷 XIII-A 表 VII 第 58–61 页的土邦行合计为男 988,830、女 1,007,553。孟买土邦的年龄表涵盖原始调查范围，较开局的匹配辖区多 22,809 人，年龄表留档。 [中央省普查原卷](https://archive.org/details/in.gov.ignca.31011) · [印度同范围人口资料](../india_comparable)
