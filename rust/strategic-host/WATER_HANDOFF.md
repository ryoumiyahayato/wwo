## 实现与加载过程

已有 QWG 页按视野和移动方向预取。缺页时保留 QPK。新页发布时从本帧开始计算 80 毫秒过渡，地表、城市和景观共用水陆状态。视口静止时复用已分类的水域缓冲。近景河线查询实测水面和两组横向邻点，在弯道抑制局部叠绘，并保留单独横穿的水道。草地和裸地继续使用 Z6/Z7 材质，叠加低幅度的世界坐标变化并保留细颗粒。

正式 `wwo-map-lab --play` 在 NVIDIA RTX 3050 Laptop GPU 上以 Vulkan、1280×720 运行。录像用 `--observe` 保存的 231 张实际游戏帧按采集时间拼接。使用独立存档配置，底图库由正式入口自动选择。录制包含挪威、密西西比、巴黎和古巴的冷跳转，前三地的近景平移，密西西比的跨层缩放，以及撒哈拉裸地和蒙古草原。

- 挪威 `5.035, 60.425`，36 米/像素。首帧的中心是 `5/32/5`。第二帧混合 `7/131/21` 25%、`6/65/10` 34%、`5/32/5` 41%。稳定后为 `7/131/21`。岛岸细节变化可见。
- 密西西比 `-89.302, 29.166`，缩放约 1700 至 28 米/像素。1284 米/像素时中心为 `6/32/21`。733 米/像素时混合 `7/64/43` 39% 和 `6/32/21` 61%。316 和 28 米/像素时为 `7/64/43`。河口主汊连续。28 米/像素仍能看见潮滩边缘的阶梯和矩形色差。
- 巴黎 `2.295, 48.862`，15 米/像素，中心 `7/129/29`。同机位观察中部分叠绘短线消失。主河面和实际分汊仍在。西侧个别弯道仍有偏离河面的细线，15 米/像素可见 30 米水面掩膜的台阶。
- 本轮查看的冷跳转和固定画面未见整块海面变成矩形。四次冷跳转在首张采集帧已分别驻留 `4/4`、`2/2`、`2/2`、`4/4` 个视口 QWG 页。录像确认 QPK 父级过渡，尚未逐帧确认 QWG 从缺页到驻留的过程。

## 帧时间和恢复

同机位单次短测的全帧中位数约 6.9 毫秒。与本阶段优化前版本相比，静止和拖动的 P95 如下。

| 场景 | 静止 P95 毫秒 | 拖动 P95 毫秒 |
| --- | --- | --- |
| 巴黎 | 14.4 → 7.4 | 13.5 → 7.6 |
| 密西西比 | 9.0 → 7.4 | 9.4 → 7.4 |
| 阿尔卑斯 | 9.2 → 7.3 | 9.2 → 7.4 |
| 蒙古草原 | 10.4 → 7.3 | 7.4 → 7.5 |

1280×720 的视口分类缓冲为 3.52 MiB，水域几何缓冲为 12 MiB。巴黎和阿尔卑斯的景观实例分别为 21,533 和 48,238。模型 GPU 计时约为 2.31 和 2.46 毫秒。帧时间涵盖整个游戏帧。水域分类的独立 GPU 时间和长期负载未测得。
